Improv via BLE

The Improv via BLE integration sends your Wi-Fi network name and password to a Wi-Fi device over Bluetooth, so the device can join your Wi-Fi network. It works with Wi-Fi devices that support the open Improv via BLE standard, such as many devices with an ESP32 chip that run ESPHome. After the device is on your Wi-Fi network, it communicates with Home Assistant over Wi-Fi.
