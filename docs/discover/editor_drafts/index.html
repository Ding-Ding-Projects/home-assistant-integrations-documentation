From edit to recovery

  1. The editor sends updated automation, script, or scene state.
  2. Editor drafts records changed states in its temporary Git repository.
  3. After a crash or restart, the editor can offer the draft again.
  4. Saving or discarding removes the draft.

Inside the guide

  • Autosaves preserve successive draft states as commits, with a history of up to 100 versions available to inspect or restore.
  • Draft data stays under .cache/editor_drafts, a location Home Assistant does not load as configuration; live items change only when the owner saves.
  • Drafts are removed when saved or discarded, and drafts untouched for 30 days are purged; Git must be installed for drafts to be kept.
