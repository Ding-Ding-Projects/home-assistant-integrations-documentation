Bring ecobee comfort controls into Home Assistant

Connect your ecobee account to control thermostat modes, target temperatures, and comfort settings, while bringing thermostat sensor readings into Home Assistant. Since Home Assistant 2026.3, setup uses your ecobee username and password without requiring a newly registered developer API key; an existing key can still be used.
