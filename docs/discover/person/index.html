Person

Combine device trackers into a person’s presence

The Person integration connects one or more device tracker entities to a person entity, so automations can use a person’s home, away, or zone state. Tracker priority matters: connected connection trackers take precedence; when none are connected, the most recently updated position tracker is used; otherwise, the latest tracker reporting `not_home` is used.
