Airzone

Bring Airzone HVAC zones into Home Assistant

Connect Home Assistant to the Local API of an Airzone HVAC zoning system to represent its systems and thermostat zones. Parent zones control HVAC mode, while child zones can enable or disable the selected mode and adjust their own desired temperature.

Open the Airzone guide →

From Airzone WebServer to zone controls

  1. Find the Airzone WebServer network IP address and port
  2. Add the integration and enter the host and port, plus a System ID if required by the device
  3. Use parent zones for HVAC mode changes and child zones for enable or disable and temperature adjustment

Inside the guide

  • Set up the connection with the Airzone WebServer host and port; provide an Airzone System ID only when the device does not support System ID 0
  • Use the parent zone for HVAC mode changes; child zones can enable or disable the current mode and adjust the desired temperature
  • Monitor system and zone warnings, air and floor demand, thermostat battery, humidity, temperature, and signal strength where available
