HDMI-CEC

To test if HDMI-CEC will work on your Home Assistant OS installation, you can use the official CEC Scanner app for Home Assistant (formerly known as CEC Scanner add-on). Run this app to see if your hardware has HDMI-CEC capabilities and which devices are connected. Do not have this app Start on boot, as it will interfere with the integration. To turn off Start on boot, refer to Changing the options of an app.
