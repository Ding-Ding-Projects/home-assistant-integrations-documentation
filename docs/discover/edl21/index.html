EDL21

Read your meter’s live telegrams

EDL21 connects a smart meter over a serial port and turns its SML telegrams into Home Assistant sensors for household electricity readings.

Open the EDL21 guide →

From meter to measurements

  1. Select the meter’s serial port
  2. Receive SML telegrams
  3. Match readings by electricity ID
  4. Update sensors from OBIS values

Inside the guide

  • Choose the serial port in the setup form; the integration prevents the same port from being configured twice.
  • The meter’s electricity ID links telegrams to the matching device, while new OBIS readings can add sensors as they arrive.
  • Track total and tariff energy alongside instantaneous power, voltage, current, frequency, and phase measurements when the meter reports them.
