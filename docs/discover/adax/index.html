Bring Adax heating into Home Assistant

Connect Adax heaters through a local or cloud interface and manage them from Home Assistant. Newer heaters with Bluetooth and Wi-Fi can be configured locally; cloud setup uses your Adax Account ID and a generated Remote API password. Cloud connections also provide heater energy sensors.
