AEMET OpenData

Bring Spanish weather data into Home Assistant

Connect to AEMET OpenData with a free API key obtained through registration. Choose a latitude and longitude to create weather entities for daily forecasts up to 6 days or hourly forecasts up to 3 days, alongside sensors for available conditions. AEMET OpenData is limited to Spanish territory; enable the radar option to create a weather radar image entity.
