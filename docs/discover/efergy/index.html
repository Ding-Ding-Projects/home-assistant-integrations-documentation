From API key to readings

  1. Enter the Efergy API key
  2. Home Assistant checks the connection and hub ID
  3. Load power, energy, and cost sensors

Inside the guide

  • The setup form checks the API key against Efergy and identifies the monitor by its hub ID.
  • Sensor readings include instantaneous power and energy and cost totals for day, week, month, and year; month totals are enabled by default.
  • Current power readings are created for each sensor ID, with per-sensor entities enabled by default when the monitor has multiple sensors.
