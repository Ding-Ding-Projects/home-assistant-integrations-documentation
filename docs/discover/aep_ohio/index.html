AEP Ohio

Bring AEP Ohio energy usage into Home Assistant

AEP Ohio support in Home Assistant is provided by the Opower integration. AEP Ohio devices are rebranded devices or share a common communication protocol, so they can be used with Opower. Add AEP Ohio from Settings > Devices & services, then follow the on-screen setup instructions; see the Opower documentation for more on using it.
