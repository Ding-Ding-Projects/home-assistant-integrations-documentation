Connect TwinCAT devices through ADS

The ADS integration connects Home Assistant with Beckhoff automation devices running TwinCAT through the device-independent, fieldbus-independent ADS interface. Configure the device AMS NetId and AMS server port, then map ADS variables to entities for binary sensors, lights, sensors, switches, covers, selects, and valves.

Open the ADS guide →

From ADS connection to Home Assistant entities

  1. Set the ADS device NetId and AMS server port in configuration.yaml
  2. Add entity platforms and identify the ADS variables they use
  3. Restart Home Assistant to load the configuration

Inside the guide

  • Connect using the device AMS NetId and AMS server port
  • Read numeric ADS variables as sensors, with supported data types from BOOL through LREAL
  • Control supported lights, covers, switches, selects, and valves through configured ADS variables
