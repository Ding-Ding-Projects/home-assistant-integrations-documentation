aerosmart

Monitor an aerosmart ventilation and heat-pump system

The aerosmart integration connects locally to the ventilation and heat-pump controllers over Modbus TCP or serial Modbus RTU. It represents the combined installation as one Home Assistant device and provides sensors for operating values, filter information, and controller status.

Open the aerosmart guide →

Connect both aerosmart controllers

  1. Choose a reachable Modbus TCP gateway or a serial Modbus RTU connection
  2. Set the connection details and the ventilation and heat-pump unit addresses
  3. Review sensor readings from the combined aerosmart installation

Inside the guide

  • Connect through a Modbus TCP gateway or a serial Modbus RTU port; the integration does not use a cloud service
  • Configure the ventilation and heat-pump unit addresses, which default to 1 and 2 respectively
  • Monitor temperatures, fan speeds, airflow, filter counters, heat-pump status, and controller information with sensor entities
