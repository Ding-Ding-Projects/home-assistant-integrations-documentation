FRITZ!Box Call Monitor

The FRITZ!Box Call Monitor integration monitors the call monitor exposed by FRITZ!Box routers (by FRITZ!, formerly AVM) on TCP port 1012. It will assume the values idle, ringing, dialing or talking with the phone numbers involved contained in the state attributes. It can also access the internal phone book of the router to look up the names corresponding to the phone numbers and store them in the state attributes.
