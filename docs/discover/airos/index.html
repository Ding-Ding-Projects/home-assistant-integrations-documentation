Ubiquiti airOS

Keep an eye on airOS links

Ubiquiti airOS brings device status and network metrics into Home Assistant for wireless links between buildings, remote sites, and other locations.

Open the Ubiquiti airOS guide →

From device to link metrics

  1. Configure an airOS 6 or 8 device in a browser or the UISP app
  2. Add Ubiquiti airOS in Home Assistant
  3. Review device status and wireless metrics

Inside the guide

  • Connects to devices running airOS 6 or 8 that have already been configured in a browser or the UISP app
  • Provides binary sensors, buttons, sensors, and update entities, including link capacity, throughput, wireless frequency, and SSID
  • Device data is polled every 60 seconds; firmware availability is checked daily, and updates are supported on firmware v8
