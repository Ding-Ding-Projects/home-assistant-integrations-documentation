Nuki Matter

To use this integration, you need a Thread border router that supports Matter. For more information, refer to the Thread documentation. You can turn your Home Assistant installation into a Thread border router, for example, by using the Home Assistant Connect ZBT-2. For more information on setting this up, go to the Turning Home Assistant into a Thread border router section.
