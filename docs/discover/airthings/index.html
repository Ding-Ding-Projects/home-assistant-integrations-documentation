Follow Airthings readings from sensor to Home Assistant

Connect Airthings sensors to Home Assistant with a valid Airthings Dashboard login and API credentials. An Airthings SmartLink hub provides live updates; without one, the Airthings mobile app syncs data over Bluetooth and uploads it to the cloud.

Open the Airthings guide →

From Airthings API credentials to sensor readings

  1. Request and save an API Client in Airthings Dashboard to generate an ID and Secret
  2. Add Airthings from Settings → Devices & services and enter the credentials
  3. Wait for a new radon sensor to appear if its value is initially unknown

Inside the guide

  • Create an API connection in the Airthings Dashboard and use its generated ID and Secret to activate the integration
  • Use an Airthings SmartLink hub for live sensor updates, or sync through the Airthings mobile app over Bluetooth and the cloud
  • Allow time for a new radon sensor to appear when the Airthings API initially reports its value as unknown
