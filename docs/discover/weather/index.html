Weather

Let the forecast shape your home

Weather is a building block in Home Assistant: it defines a shared weather entity, while a provider integration connects to the service that supplies the data. Choose a provider, then use its current conditions and supported forecasts in dashboards, templates, and automations.

Inside the guide

  • Read a standard condition such as rainy, snowy, or partly cloudy from the weather entity state

  • Request hourly or daily forecasts with weather.get_forecasts and use the response in a template sensor
