Edifier Infrared

Put Edifier speaker controls within reach

Edifier Infrared turns selected Edifier speaker commands into Home Assistant controls through an infrared emitter. Choose the emitter and speaker model during setup, then use the media player and button entities to send the commands supported by that model.
