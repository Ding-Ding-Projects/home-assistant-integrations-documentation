Samsung TV via ExLink

The Samsung TV via ExLink integration lets you control Samsung consumer TVs by connecting to their RS-232 serial port, which Samsung markets as ExLink (also written EX-Link or EXT Link). Because Home Assistant talks straight to the TV, control is local and fast, and it also works on TVs that lack smart features or a network connection.
