Discord

The Discord integration lets you send notifications from Home Assistant to Discord channels and users via a bot. You can add channels or users as notification targets to send messages from the UI. You can use the notify action to attach files (such as images or videos) from local paths or remote URLs, and use Discord embeds for rich formatting.
