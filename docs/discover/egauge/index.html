Inside the guide

  • Setup checks the monitor's serial number and hostname; the serial number prevents adding the same device twice.
  • Choose whether to use SSL and verify its certificate. Certificate verification is off by default because eGauge devices use a self-signed certificate unless a custom one is installed.
  • Home Assistant creates sensors for supported power, energy, voltage, and current registers, and refreshes measurements and counters every 30 seconds.
