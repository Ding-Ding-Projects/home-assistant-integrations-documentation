OpenWeatherMap

Bring local weather and air quality into Home Assistant

Use an OpenWeatherMap API key to add current conditions, forecasts, or air quality sensors for a chosen location. Pick from the free current weather, five-day forecast, and air pollution modes, or use One Call API 3.0 for hourly and daily forecasts. One Call API 3.0 requires a subscription; its free tier includes 1,000 calls per day, so set a daily call limit in your OpenWeatherMap billing settings to manage usage.
