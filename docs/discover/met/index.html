Meteorologisk institutt (Met.no)

Bring Norway’s forecast into your home

Met.no connects Home Assistant to the Norwegian Meteorological Institute and NRK forecast service. Set a location and elevation to create a weather entity with current conditions plus daily and hourly forecasts, without an API key.

Open the Meteorologisk institutt (Met.no) guide →

From location to local forecast

  1. Choose location and elevation
  2. Met.no forecast service
  3. Weather entity
  4. Current conditions and forecasts

Inside the guide

  • Use the home location by default, or add the integration again with coordinates for another place
  • Read temperature, dew point, humidity, pressure, visibility, wind, cloud coverage, and UV index from each weather entity
  • Use forecast precipitation and precipitation probability; data refreshes on a randomized 55-to-65-minute interval
