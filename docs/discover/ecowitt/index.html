Bring Ecowitt weather readings into Home Assistant

Ecowitt sends station readings to Home Assistant through a local webhook. Add the integration to get a server address, port, and generated path, then enter those details in the station’s Ecowitt upload settings so it can push data to Home Assistant.

  • Entities are organized under station devices and update when the station sends new data
