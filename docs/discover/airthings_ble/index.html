Airthings BLE

Read Airthings sensors over Bluetooth

Connect a supported Airthings device to Home Assistant over Bluetooth LE and add sensor entities according to its model. Devices need Bluetooth connectivity, current firmware, and range of the Home Assistant host or a Bluetooth proxy that supports active connections.

Open the Airthings BLE guide →

From Airthings device to Home Assistant sensors

  1. Enable Bluetooth and ensure the device is within range of the host or an active-connection Bluetooth proxy
  2. Update device firmware in the Airthings app and switch connectivity from SmartLink to Bluetooth if needed
  3. Add Airthings BLE from Settings → Devices & services and follow the on-screen setup
  4. Review the sensor entities available for the device model

Inside the guide

  • Monitor readings such as humidity, illuminance, pressure, radon, temperature, VOC, CO2, and battery where the device provides them
  • Support Wave Gen. 1, Wave Radon, Wave Mini, Wave Plus, Wave Enhance, and Corentium Home 2
  • Use Bluetooth connectivity; devices configured for SmartLink do not provide live readings to Home Assistant over Bluetooth
