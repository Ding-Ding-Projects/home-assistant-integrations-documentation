Mobile App

Keep mobile apps connected to Home Assistant

The Mobile App integration is the generic platform that lets Home Assistant mobile apps integrate with your server. It is enabled by default, and Home Assistant recommends keeping it enabled when you use an app that integrates with Home Assistant.

Open the Mobile App guide →

Keep the mobile app platform available

  1. Check whether default_config: is enabled
  2. If it is absent, add mobile_app: to configuration.yaml
  3. Consult Companion documentation for app guidance
