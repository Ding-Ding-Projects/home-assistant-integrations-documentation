Egardia

Egardia alarm and sensor controls

Connect an Egardia or Woonveilig alarm panel on your local network to control its alarm state and monitor the panel’s discovered sensors in Home Assistant.

Open the Egardia guide →

From panel to entities

  1. Provide the panel host, username, and password.
  2. Set optional panel version, name, and port values as needed.
  3. Home Assistant creates an alarm control panel and discovers binary sensors.
  4. Optionally enable the report server for status events instead of polling.

Inside the guide

  • Arm the system at home or away, and disarm it from the alarm control panel.
  • Discover binary sensors for panel inputs, including motion sensors and door contacts.
  • Use local polling for alarm status, or optionally enable the report server to receive status events and map configured status codes.
