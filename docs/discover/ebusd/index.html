Bring eBUS heating data into view

Connect Home Assistant to an ebusd daemon to read selected eBUS heating circuit values as sensors and send property writes.

Open the ebusd guide →

From ebusd to Home Assistant

  1. Set the ebusd host, port, and circuit.
  2. Select monitored conditions supported by that circuit.
  3. Read the conditions as sensors or send a property write.

Inside the guide

  • Choose a circuit and monitored conditions; every condition must be supported by that circuit.
  • Configure the ebusd host and port; the default port is 8888. Sensor updates are throttled to 15 seconds, and reads use a 900-second cache TTL.
  • A write service sends a named property and value to ebusd.
