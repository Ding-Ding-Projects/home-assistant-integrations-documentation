Proxmox VE

The integration is tested with the latest version of Proxmox VE (currently Proxmox VE 9), both on a standalone node and in a cluster. Earlier versions should also work, because the integration uses the Proxmox VE API, which has been available since Proxmox VE 2.0. Some features need a more recent version. For details, see Known limitations.
