Bring Airobot floor heating into Home Assistant

Connect an Airobot Smart Thermostat TE1 (firmware 1.8 or later) through its local REST API to control heating and monitor room conditions. Set HOME and AWAY temperatures, use the one-hour BOOST preset, and view optional CO₂ and floor temperature readings when those sensors are installed.

Connect an Airobot thermostat locally

  1. Use a Smart Thermostat TE1 with firmware 1.8 or later and enable Local API in Connectivity settings.
  2. Add the integration through discovery or enter the host, Device ID, and password from the thermostat's Mobile app screen.
  3. Set the heating mode and temperature, then use available sensor readings in automations.

Inside the guide

  • Control the heating setpoint from 5°C to 35°C and choose Home, Away, or Boost; Boost runs for 1 hour before returning to the previous mode.
  • Monitor air temperature, humidity, and, when fitted, floor temperature, carbon dioxide, and an air quality index based on CO₂.
  • Set up through DHCP discovery on the same network or add the thermostat manually; data is polled every 30 seconds.
