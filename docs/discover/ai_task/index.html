AI Task

Give AI one focused job

AI Task lets Home Assistant automations, scripts, and the interface send a single job to an AI integration and receive a result. Depending on the entity, that job can generate text or structured data, create an image, or evaluate a question.

Inside the guide

  • AI task entities come from AI integrations such as OpenAI, Google Gemini, and Ollama; available actions vary by entity
  • When an action does not specify an entity, Home Assistant uses the preferred AI task entity for that kind of task
  • The Suggest button uses the preferred entity for data generation, including suggestions for an automation name, description, category, and labels
