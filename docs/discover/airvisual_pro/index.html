AirVisual Pro

Bring AirVisual Pro readings into Home Assistant

The AirVisual Pro integration retrieves data from an AirVisual Node/Pro unit over the local network. The device’s Samba password is required and can be found on the unit.

Open the AirVisual Pro guide →

From AirVisual Pro to Home Assistant sensors

  1. Find the device’s Samba password on the AirVisual Pro unit
  2. In Home Assistant, open Settings → Devices & services and add AirVisual Pro
  3. Provide the device IP address and password when prompted, then view available sensors

Inside the guide

  • Retrieve data from an AirVisual Node/Pro unit over the local network
  • Use the device’s Samba password, found on the unit, to configure access
  • View sensors for Air Quality Index (AQI), Carbon Dioxide (CO2), PM0.1, PM2.5, PM10, and more
