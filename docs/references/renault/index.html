Renault

Instructions on how to integrate your Renault, Dacia, or Alpine vehicle into Home Assistant using the My Renault service.

Overview

The Renault integration connects your Renault, Dacia, or Alpine vehicle to Home Assistant through the My Renault cloud service. It uses the same account as the My Renault app on your phone.

Data updates

The Renault integration polling polls the Renault servers for data. The vehicle data is split into several groups, such as battery, location, and air conditioning. The integration makes on average one request per minute, so each value is updated about every N minutes, where N is the total number of data groups across all your vehicles. For example, if your vehicle supports 6 groups, each value is updated every 6 minutes. With 2 such vehicles on the same account, each value is updated every 12 minutes.

Description

The Renault servers no longer accept the stored sign-in. For example, the login expired, you changed your password in the My Renault app, or two-factor authentication was turned on for your account.

Symptom: The integration fails to set up and retries

The Renault integration shows that it failed to set up and retries automatically, with a message such as Failed to connect to the Renault servers or Failed to retrieve vehicle details from the Renault servers.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Renault.

The kamereon configuration step lists kamereon_account_id.

The reauth confirm configuration step lists password.

The two factor code configuration step lists code.

The two factor email configuration step lists email.

The user configuration step lists locale, password, username.
