Victron GX

Instructions for connecting Victron Energy GX devices to Home Assistant using MQTT

Supported devices

This integration supports Victron Energy devices that run Venus OS and have MQTT enabled, including:

Prerequisites

When Home Assistant discovers your Victron GX device, it first tries to connect using TLS on port 8883. If TLS is unavailable, it tries an unencrypted connection on port 1883.

Reauthentication

If your MQTT password changes or the security profile on your Victron device is updated, Home Assistant prompts you to re-authenticate:

Data updates

Entities are updated only when new values are received from the device. The integration uses an automatic update cadence chosen by metric type.

Reduce Recorder storage

The Recorder integration stores state changes in the database, so Victron GX entities can generate a lot of history data.

Supported functionality

The integration automatically discovers and creates entities for all supported Victron devices on your system. The exact entities available depend on your specific Victron hardware configuration.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Victron GX.

The reauth confirm configuration step lists password, ssl, username.

The reconfigure configuration step lists host, password, port, ssl, username.

The ssdp auth configuration step lists password, ssl.

The user configuration step lists host, password, port, ssl, username.
