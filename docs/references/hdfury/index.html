HDFury

Instructions on how to integrate HDFury devices within Home Assistant.

Overview

The HDFury integration allows you to control and monitor your HDFury device.

Supported functionality

The integration will fetch data from each device. Below is a complete overview of the entities this integration provides.

Data updates

This integration uses local polling, meaning it checks for changes to all entities by regularly communicating with the HDFury device.
