Integration reference

Backup

Create and restore backups of your Home Assistant installation.

Overview

The Backup integration creates and restores backups across all installation types.

Restoring a backup

To restore a backup, follow the steps described in Restoring a backup.

Event entity

The Backup integration provides the Automatic backup Event entity (event.backup_automatic_backup). It shows the state of the last backup that Home Assistant created. Despite its name, it also reports manual backups and the backups that Home Assistant creates before an update. You can use its attributes in automations, for example, to get notified when a backup fails. To react to the result of a backup, use the Event received trigger, and select the event type.

Sensors

The Backup integration provides the following sensors.

Backup Manager state

What the backup system is doing. The sensor has one of the following states:

Next scheduled automatic backup

The date and time of the next scheduled automatic backup.

Last attempted automatic backup

The date and time of the last automatic backup that Home Assistant tried to create, even if it failed.

Last successful automatic backup

The date and time of the last automatic backup that Home Assistant created successfully.

Last successful automatic backup size

The size of the last successful automatic backup, as it was created. You can use it to follow how the size of your backups changes over time, for example after changing what is included in them.

Automation: Get notified when a backup fails

When a backup fails, send a notification to your phone with the reason.

Configuration details

The domain used to identify Backup in Home Assistant is backup.
