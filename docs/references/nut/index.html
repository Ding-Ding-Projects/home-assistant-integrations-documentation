Network UPS Tools (NUT)

Instructions on how to set up NUT sensors within Home Assistant.

Overview

The Network UPS Tools (NUT) integration allows you to monitor and manage an Uninterruptible Power Supply (UPS) for battery backup, a Power Distribution Unit (PDU), or other similar power device using a NUT server. It lets you view the status, receive notifications about important events, and execute commands as device actions for one or more such devices.

Supported devices

This integration supports hardware devices compatible with NUT. NUT's hardware compatibility list is available from the Network UPS Tools website.

Prerequisites

You must have a NUT server configured to monitor one or more supported power device(s).

Supported functionality

This NUT integration uses the NUT protocol to retrieve "variables" from the NUT server. Only sensors and diagnostic sensors available for your device are added to Home Assistant.

Sensors

Sensors provide information about a NUT device.

Diagnostic sensors

Diagnostic sensors provide additional information about a NUT device.

Buttons

This NUT integration will add buttons for NUT server commands available for your device.

Switches

This NUT integration will add switches for NUT server commands available for your device.

Data updates

The integration uses polling to retrieve data from the NUT server. The default polling interval is once every 60 seconds. You can also define a custom polling interval if needed.

NUT device commands

The username and password configured for the device must be granted instcmds permissions on the NUT server to use buttons, switches, and device actions. These entities and device actions will not be available if user credentials are not specified. See the NUT server documentation for configuration information.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Network UPS Tools (NUT).

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists host, password, port, username.

The reconfigure ups configuration step lists alias.

The ups configuration step lists alias.

The user configuration step lists host, password, port, username.
