Integration reference

Countdown

Counts down to any number of named dates, repeating yearly (birthdays, anniversaries, renewals) or one-off.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Countdown.

The user configuration step lists name, date, yearly.
