Date/Time

Instructions on how to set up date/time entities within Home Assistant.

Overview

The Date/Time integration is built for the controlling and monitoring of timestamps on devices.

Date/time states

The state of a date/time entity is the actual date and time value. The state value is in UTC, in the format YYYY-MM-DDTHH:MM:SS+00:00. For example, 2020-01-01T12:00:00+00:00. The Home Assistant interface shows the date and time in your local date and time format.

Configuration details

The domain used to identify Date/Time in Home Assistant is datetime.
