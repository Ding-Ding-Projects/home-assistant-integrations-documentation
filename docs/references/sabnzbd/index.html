SABnzbd

Instructions on how to integrate SABnzbd with Home Assistant.

Overview

The SABnzbd integration allows you to monitor and control your downloads with SABnzbd from within Home Assistant and set up automations based on download status and activity.

Data updates

The SABnzbd integration polling polls data from your SABnzbd server every 30 seconds by default. This provides near real-time updates of download progress, queue status, and system information without putting excessive load on your SABnzbd instance.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for SABnzbd.

The user configuration step lists api_key, url.
