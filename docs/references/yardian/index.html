Yardian

Instructions on how to integrate Yardian device within Home Assistant.

Overview

The Yardian integration allows you to control your Yardian Smart Sprinkler Controller.

Supported functionality

The Yardian integration provides the following entities.

Removing the integration

To remove Yardian from Home Assistant, delete its integration entry. You can continue to use your controller in the Yardian app.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Yardian.

The user configuration step lists access_token, host.
