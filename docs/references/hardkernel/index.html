Hardkernel

Shows information about your Hardkernel ODROID board in Home Assistant.

Overview

The Hardkernel integration shows which Hardkernel ODROID board Home Assistant is running on. This includes the Home Assistant Blue, which is based on the ODROID-N2+.

Supported devices

The integration recognizes these boards when they run Home Assistant Operating System:

Configuration

This integration is set up automatically. There is nothing to configure.

Removing the integration

You don't need to remove this integration. If you do, Home Assistant adds it again the next time it starts on an ODROID board.

Configuration details

The domain used to identify Hardkernel in Home Assistant is hardkernel.
