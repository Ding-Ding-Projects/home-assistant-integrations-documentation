Overview

Stream URL Template

For advanced usecases, this behavior can be changed with the Stream URL template option. When set, this string will override the default stream address that is derived from the default behavior described above. This option supports jinja2 templates and has the camera dict variables from motionEye (example) available for the template. Note that no Home Assistant state is available to the template, only the camera dict from motionEye.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for motionEye.

The user configuration step lists admin_password, admin_username, surveillance_password, surveillance_username, url.
