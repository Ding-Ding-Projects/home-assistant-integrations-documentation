Vera

Instructions on how to set up Vera Z-Wave hubs and configure devices within Home Assistant.

Overview

The Vera hub is a controller mainly for connecting to Z-Wave devices.

Options

Once the Vera integration is configured, you can set additional options in the integration, click the gear icon.

Sensor

The vera platform allows you to get data from your Vera sensors from within Home Assistant.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Vera.

The user configuration step lists exclude, lights, vera_controller_url.
