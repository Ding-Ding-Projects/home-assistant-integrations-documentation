Palazzetti

Instructions on how to integrate Palazzetti within Home Assistant.

Overview

The Palazzetti integration integrates pellet stoves manufactured by Palazzetti and OEM or rebranded stoves using the same hardware architecture (such as Jøtul, TurboFonte, and others) equipped with a Connection Box. It accesses the device's local API. Third-party bridges such as WPalaControl implement a compatible API and are supported by this integration as well.

Supported devices and brands

This integration supports pellet stoves equipped with a Palazzetti Connection Box, an OEM equivalent, or a compatible bridge (such as WPalaControl). Many manufacturers share this electronic architecture (Fumis controller).

Identifying compatible hardware

Compatible Wi-Fi modules connect directly to the stove's serial interface (RJ11/RJ12), communicate over local network HTTP (typically with hostname connbox or initial setup Wi-Fi SSID connboxXXXXX), and do not require a cloud service.

Climate

The Palazzetti integration offers a climate entity that allows you to read the room temperature, start and stop the stove, set the target temperature, and set the fan speed.
