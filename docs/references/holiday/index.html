Holiday

Instructions on how to use holiday calendars in Home Assistant.

Overview

The Holiday integration adds a calendar with the public holidays for a country, and optionally a region within that country, to Home Assistant. You can use it to view upcoming holidays on your calendar dashboard and to power automations, for example, to keep the blinds closed on public holidays or turn on festive lights on a specific holiday.

Supported countries

The integration supports all countries and regions that the holidays library supports. When you add the integration, the Country list only shows supported countries. For the full list of countries, regions, and holiday categories, refer to the supported entities list of the holidays library.

Supported functionality

Each entry of the Holiday integration creates a service device with one entity.

Calendar

A calendar entity has a state and attributes that represent the next upcoming event (only). A calendar trigger is a much more flexible way to power automations with fewer limitations than using the entity state.

Holiday automation examples

Each holiday date is a calendar event, so you can use a calendar trigger to start an automation when a holiday begins or ends. Holidays on the same date share one event with a combined title, so check whether the title contains the holiday name instead of matching the full title. You can also use the calendar state in a condition to check whether today is a holiday. For an overview, refer to calendar automations. You can use calendar trigger variables, such as the event summary and location, in conditions and actions.

Automation: Turn on the Christmas lights on Christmas Day

Turn on your festive lights when Christmas Day starts. The condition checks the name of the holiday, so the automation only runs on Christmas Day and not on other holidays. It also works when another holiday falls on the same date. The holiday name must match the name shown on your calendar, which depends on your language.

Automation: Keep the covers closed on public holidays

Open your covers in the morning on regular days, but let you sleep in on public holidays. The condition checks that the holiday calendar is Off, which means today is not a holiday.

Data updates

The holiday data is included in the integration, so no data is fetched from the internet. The calendar updates its state at the start of each day. New holidays and corrections come from updates of the holidays library, which are included in Home Assistant updates.

Symptom: The country is not available when adding the integration

When you add the integration, your country does not show up in the Country list.

Description

The Country list only shows countries supported by the holidays library.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Holiday.

The options configuration step lists categories, province.

The reconfigure configuration step lists categories, province.

The user configuration step lists country.
