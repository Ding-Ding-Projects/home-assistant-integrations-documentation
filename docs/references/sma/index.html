SMA Solar

Instructions on how to connect your SMA Solar Inverter to Home Assistant.

Overview

The SMA Solar integration will poll a SMA (US) solar inverter, energy meter or battery inverter and present the values as sensors in Home Assistant.

Installation details

When Home Assistant discovers a new SMA device, or when you manually add one, the following form is presented:

Supported Devices

Not all inverters, energy meters and batteries from SMA are supported.

Sensors

The SMA WebConnect module supports a wide variety of sensors, but not all of these have been mapped in the pysma library. Currently available sensors can be found below. Feel free to submit additional sensors to be added as standard sensors to the pysma library.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for SMA Solar.

The discovery confirm configuration step lists group, password, ssl, verify_ssl.

The reauth confirm configuration step lists password.

The reconfigure configuration step lists group, host, password, ssl, verify_ssl.

The user configuration step lists group, host, password, ssl, verify_ssl.
