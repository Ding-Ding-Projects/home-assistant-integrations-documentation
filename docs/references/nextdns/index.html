NextDNS

Instructions on how to integrate NextDNS within Home Assistant.

Overview

The NextDNS integration is used to integrate with NextDNS, a DNS service that protects you from security threats, blocks advertisements and trackers on websites and in apps, and provides a safe and supervised internet for kids on all devices and on all networks. The integration lets you monitor NextDNS statistics and control its configuration.

Prerequisites

1. Sign in to your NextDNS account. 2. Copy the API key shown on the account page.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for NextDNS.

The profiles configuration step lists profile_id.

The reauth confirm configuration step lists api_key.

The reconfigure configuration step lists api_key.

The user configuration step lists api_key.
