NRGkick

Integrate the NRGkick Gen2 mobile EV charger using the local REST JSON API.

Overview

The NRGkick integration allows you to monitor the NRGkick mobile EV charger (Wallbox) by DiniTech with Home Assistant. It enables real-time monitoring of charging status, tracking energy consumption, controlling charging behavior, and integrating EV charging data into the Home Assistant energy dashboard.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for NRGkick.

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists host.

The reconfigure auth configuration step lists password, username.

The user configuration step lists host.

The user auth configuration step lists password, username.
