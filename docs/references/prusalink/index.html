PrusaLink

Instructions on monitoring Prusa 3D printers using PrusaLink.

Overview

The PrusaLink integration allows you to monitor your Prusa 3D printer and its progress with your Home Assistant installation. This integration works with Prusa MINI/MINI+, Prusa MK3.9/MK4, Prusa XL, Prusa CORE One, and with the older Raspberry Pi-based Prusa MK2.5/MK3.

Data updates

The integration polling polls the printer every 30 seconds. After you press one of its job buttons, such as pause or resume, it polls every 5 seconds for the next 30 seconds, so the new state shows quickly.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for PrusaLink.

The user configuration step lists host, password, username.
