Whirlpool Appliances

Instructions on how to integrate Whirlpool appliances with Home Assistant.

Overview

The Whirlpool Appliances integration allows you to connect Whirlpool, Maytag, KitchenAid, and Consul appliances to Home Assistant.

Supported devices

The following appliances are confirmed to be working, but other models may also work.

Supported functionality

This integration maps appliances to entities in Home Assistant. A single appliance may be represented by one or more entities.

Sensor

The whirlpool sensor platform integrates Whirlpool Washer and Dryer systems into Home Assistant, allowing views of the machine state, time remaining, and the "wash & go" tank fill status as sensors for each device.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Whirlpool Appliances.

The reauth confirm configuration step lists brand, password, region.

The user configuration step lists brand, password, region, username.
