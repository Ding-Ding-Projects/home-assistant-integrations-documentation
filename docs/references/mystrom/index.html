myStrom

Instructions on how to integrate myStrom WiFi Switches, Bulbs and Motion Sensors into Home Assistant.

Overview

There is currently support for the following device types within Home Assistant:

Lights, switches and motion sensors

The myStrom integration allows you to control your myStrom Wi-Fi Bulbs, Wi-Fi Switches and Wi-Fi Motion Sensors. Make sure that you have enabled the REST API under Advanced in the web frontend of the switch.

Binary sensor

The mystrom binary sensor platform allows you to use myStrom Wifi Buttons with Home Assistant. The myStrom Wifi Buttons support three and the myStrom WiFi Button + four different push pattern:

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for myStrom.

The user configuration step lists host, name.
