RESTful Command

Instructions on how to integrate REST commands into Home Assistant.

Overview

This integration can expose regular REST commands as actions. Actions can be called from a [script] or in [automation].

Using REST command Response in automations

REST commands provide an action response in a dictionary containing status (containing the HTTP response code), content containing the response body as text or JSON and headers containing the response headers. This response can be accessed in automations using response_variable.

Using templates to change the payload based on entities

The commands can be dynamic, using templates to insert values of other entities. Actions support variables for doing things with templates.
