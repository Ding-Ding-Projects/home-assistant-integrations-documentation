Chef iQ

Instructions on how to integrate Chef iQ wireless probes with Home Assistant.

Overview

The Chef iQ integration lets you read the temperatures from Chef iQ wireless cooking probes directly over Bluetooth Low Energy. No cloud account, base station, or hub is required: the probe broadcasts its readings and Home Assistant listens passively.

Prerequisites

This integration requires a working Bluetooth setup, either a local Bluetooth adapter or an ESPHome Bluetooth proxy. The probe is battery-powered and only broadcasts while it is awake, so make sure it is awake (for example, by taking it off its charging dock) before adding it.

Supported functionality

The Chef iQ integration provides the following entities.

Automation: Notify when the food is done

Waiting next to the grill is no fun. Send a notification when the food core temperature reaches the target, 63 °C for a roast in this example.

Automation: Warn when the smoker drifts out of range

A fire that dies down or runs away ruins a long cook. Send a notification when the ambient temperature stays below or above your smoking range for five minutes.

Automation: Remind yourself to charge the probe

A flat probe on cook day is annoying. Send a notification when the battery drops below 20%.

Known limitations

The integration is passive and read-only. It reports the probe's broadcast readings, but cannot start cooks, set target temperatures, or change probe settings. Those features require the Chef iQ app.

The sensors are unavailable

The probe only broadcasts while it is awake. Once it has stopped broadcasting for a few minutes, for example because it is back on its dock, its sensors become unavailable. They recover on their own with the probe's next advertisement, so wake the probe or bring it back into range of a Bluetooth adapter or proxy.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Chef iQ.
