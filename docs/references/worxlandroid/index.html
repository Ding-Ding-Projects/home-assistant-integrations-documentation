Worx Landroid

Instructions on how to integrate Worx Landroid WG796E.1 or WG797E as sensors within Home Assistant.

Overview

The Worx Landroid integration allows you to get the current state, battery level and error status Worx Landroid WG796E.1 or WG797E.

Configuration details

The domain used to identify Worx Landroid in Home Assistant is worxlandroid.
