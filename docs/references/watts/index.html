Data updates

The Watts Vision + integration polling polls data from the cloud API every 30 seconds. After sending commands (temperature changes, mode changes, or switch operations), the integration waits 7 seconds before refreshing to allow the device to process the change.

Use cases

Watts Vision+ supports a wide range of heating systems, including underfloor heating and cooling. By integrating with Home Assistant, the Watts Vision ecosystem becomes fully interoperable with other IoT devices from any brand in your connected home, unlocking powerful automation possibilities.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Watts Vision +.
