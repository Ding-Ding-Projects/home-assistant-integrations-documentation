Data updates

The CentriConnect/MyPropane integration polling polls data from the API every 6 hours.

Known limitations

The tank monitor only provides new data 2-3 times a day so more frequent polling is not configurable.

Troubleshooting

Before reporting an issue, enable debug logging and restart the integration. As soon as the issue recurs, stop the debug logging again (_a download of the debug log file will start automatically_). Additionally, download the diagnostics data. Once you have collected the debug log and the diagnostics data, include them in the issue report.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for CentriConnect/MyPropane.

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists password, username.

The user configuration step lists device_id, password, username.
