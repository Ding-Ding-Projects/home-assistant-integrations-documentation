Sky Hub

Instructions on how to integrate Sky Hub routers into Home Assistant.

Overview

The Sky Hub integration offers presence detection by looking at connected devices to a Sky Hub router.

Supported functionality

For each device it finds connected to the router, the integration creates a device tracker entity that shows whether the device is home or away. Each entity also exposes the device's hostname and MAC address.

Data updates

The integration polling polls the Sky Hub router every 30 seconds.

Symptom: "Remove leftover known devices for Sky Hub"

Home Assistant displays a repair issue titled Remove leftover known devices for Sky Hub, and some of the device trackers created by this integration are missing or have stopped updating.

Description

Earlier versions of this integration stored tracked devices in the known_devices.yaml file. Although the integration now creates its own entities directly, leftover entries in that file retain the same entity IDs. Consequently, Home Assistant drops the new entities upon startup.

Resolution

1. Open the known_devices.yaml file located in your Home Assistant configuration directory (in the same directory as your configuration.yaml file). 2. Remove the specific entries listed in the repair issue. 3. Restart Home Assistant.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Sky Hub.

The user configuration step lists host.
