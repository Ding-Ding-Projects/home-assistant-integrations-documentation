WattTime

Instructions on how to set up the WattTime integration within Home Assistant.

Overview

The WattTime integration allows users to get real-time emissions data for a latitude/longitude from WattTime.

Registering an account

You need a WattTime account before you can set up this integration. Registration is done via the WattTime API. The simplest way to register is by using cURL on the command line:

Sensors

The sensors available to you will depend on the type of WattTime subscription you have. You can reach out to WattTime to upgrade your subscription via their website.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for WattTime.

The coordinates configuration step lists latitude, longitude.

The location configuration step lists location_type.

The reauth confirm configuration step lists password.

The user configuration step lists password, username.
