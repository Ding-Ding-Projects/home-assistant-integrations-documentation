Door

This integration provides door automation triggers and conditions.

Overview

The Door integration provides automation triggers and conditions for entities that represent doors. Use it to react when a front door opens, check whether a patio door is still open, or build automations around a garage door.

Supported entities

The Door integration works with the following entity types when they use the door device class:

Configuration

The Door integration does not require any configuration.

Known limitations

Only entities that use the door device class appear in these triggers and conditions. If your device is exposed with a different entity type or device class, it will not be available here.

Configuration details

The domain used to identify Door in Home Assistant is door.
