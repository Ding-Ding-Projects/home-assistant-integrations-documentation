Climate

Instructions on how to set up climate control devices within Home Assistant.

Overview

The Climate integration allows you to control and monitor HVAC (heating, ventilating, and air conditioning) devices and thermostats.

Climate states

A climate entity can have the following states, depending on the specific climate device and its capabilities. Each item shows the label you see in the Home Assistant interface, followed by the state as Home Assistant stores it. If you write templates or edit automations in YAML, use the stored state.

Attributes

A climate entity has the attributes below. Which ones appear depends on the features the device supports. State attributes show what the device is doing right now. Capability attributes describe what the device can do.

Configuration details

The domain used to identify Climate in Home Assistant is climate.

Documented actions

  • set fan mode
  • set humidity
  • set hvac mode
  • set preset mode
  • set swing horizontal mode
  • set swing mode
  • set temperature
  • toggle
  • turn off
  • turn on
