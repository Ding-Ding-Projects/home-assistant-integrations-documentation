Manual MQTT alarm control panel

Instructions on how to integrate manual alarms into Home Assistant with MQTT support.

Overview

The MQTT integration extends the manual alarm by adding support for MQTT control of the alarm by a remote device. It can be used to create external keypads which simply change the state of the manual alarm in Home Assistant.

MQTT control

The state of this alarm can be controlled using MQTT. Ensure you've configured that before adding this component.

Configuration details

The domain used to identify Manual MQTT alarm control panel in Home Assistant is manual_mqtt.
