Plant Monitor

Instructions on how to set up plant monitoring with Home Assistant.

Overview

This Plant Monitor integration lets you merge moisture, conductivity, light intensity, temperature and battery level for a plant into a single UI element. It also supports setting minimum and maximum values for each measurement and will change its state to "problem" if it is not within those limits.

Configuration

To use your plant sensor in your installation, add the following to your configuration.yaml file.

Using plain MQTT sensor to get the data

This is a practical example that uses a multiple of MQTT sensors to supply the readings used by the plant sensor. Another good source of this data would be the Mi Flora integration.

Data source

The main sources of the data will usually be a MiFlora sensor or a MQTT sensor receiving the data from a PlantGateway.

Configuration details

The domain used to identify Plant Monitor in Home Assistant is plant.
