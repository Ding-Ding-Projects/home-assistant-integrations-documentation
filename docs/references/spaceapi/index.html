SpaceAPI

Instructions on how to configure the SpaceAPI for Home Assistant.

Overview

The Space API integration allow Hackerspaces and Makerspaces to expose information to web apps or any other application with the SpaceAPI. It does this by exposing an API on Home Assistant that hosts the JSON payload that SpaceAPI uses.
