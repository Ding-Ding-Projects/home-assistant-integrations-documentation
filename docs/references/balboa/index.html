Balboa Spa Client

Instructions on how to integrate Balboa Spa WiFi within Home Assistant.

Overview

The Balboa Spa Client integration adds support for Balboa Spa WiFi Modules to be used within Home Assistant.

Compatible hardware

Balboa Spa Client integration support local control of hot tub spas equipped with a Balboa BP system and a bwa™ Wi-Fi Module (50350).

Debugging integration

If you have problems with Balboa or the integration you can add debug prints to the log.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Balboa Spa Client.

The user configuration step lists host.
