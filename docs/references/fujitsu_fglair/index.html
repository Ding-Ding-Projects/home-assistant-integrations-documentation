Integration reference

FGLair

Control your Fujitsu heat pump or air conditioner that uses the FGLair app

Overview

The FGLair integration provides support for Fujitsu heat pumps and air conditioners that use the FGLair app. To find out which app to use for your heat pump, check the Fujitsu FGLair FAQ.

Supported devices

This integration supports a subset of devices that work with the FGlair app and other external integrations.

Prerequisites

First, set up your device in the FGLair app before using this integration. To configure this integration, you will need the credentials (login and password) used to connect to the FGLair application.

Climate

This integration supports the following functionalities (if the devices support them):

Outside temperature

On units that support it, this integration will expose a temperature sensor that reports the outside temperature that the unit is sensing.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for FGLair.

The reauth confirm configuration step lists password.

The user configuration step lists password, region, username.
