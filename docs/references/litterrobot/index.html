Whisker

Instructions on how to integrate Whisker's lineup of Wi-Fi-enabled, automatic, self-cleaning litter boxes and pet feeders to Home Assistant.

The Whisker integration allows you to monitor and control your Wi-Fi-enabled, automatic, self-cleaning litter box and pet feeders. If you have pet profiles set up, you can also track your pet's weight.

Supported devices

Any Wi-Fi connected Whisker device that can be onboarded via the Whisker app should work with this integration.

Prerequisites

Before using this integration, you’ll need a Whisker account and a Wi-Fi-enabled Litter-Robot or Feeder-Robot linked to it. You can do this via the Whisker app.

Configuration

To add the Whisker hub to your Home Assistant instance, use this My button:

Config flow start

Manual configuration steps

If the above My button doesn't work, you can also perform the following steps manually:

  • Browse to your Home Assistant instance.

  • Go to Settings > Devices & services.

  • In the bottom right corner, select the Config flow start button.

  • From the list, select Whisker.

  • Follow the instructions on screen to complete the setup.

List of actions

This integration does not provide any documented actions yet. See the actions reference for actions from other integrations.

Data updates

This integration subscribes to updates from Feeder-Robot and Litter-Robot devices to receive new data as soon as it is available.

Additionally, this integration polling polls for updated device and pet data every 5 minutes.

Examples

Clean area(s) when a Litter-Robot cycles

blueprint:
  name: Clean area(s) when a Litter-Robot cycles
  description: >
    Trigger a vacuum to clean selected area(s) when a Litter-Robot from the
    Whisker (Litter-Robot) integration begins a cleaning cycle.

    Useful for automatically vacuuming around the litter box after it runs.
  domain: automation
  author: natekspencer
  homeassistant:
    min_version: 2026.3.0

  input:
    litter_robot_entity:
      name: Litter-Robot
      description: >
        Select the Litter-Robot vacuum entity to monitor. The automation will
        trigger when the device state changes to "cleaning".
      selector:
        entity:
          filter:
            - integration: litterrobot
              domain: vacuum

    vacuum_entity:
      name: Vacuum cleaner
      description: >
        The robot vacuum that should clean the selected area(s). Only vacuums
        that support the `vacuum.clean_area` service are shown.
      selector:
        entity:
          filter:
            - domain: vacuum
              supported_features:
                - vacuum.VacuumEntityFeature.CLEAN_AREA

    clean_area:
      name: Area(s) to clean
      description: >
        Select one or more Home Assistant areas for the vacuum to clean when
        the Litter-Robot begins a cleaning cycle.
      selector:
        area:
          multiple: true

mode: single

trigger:
  - trigger: state
    entity_id: !input litter_robot_entity
    to: cleaning

action:
  - service: vacuum.clean_area
    target:
      entity_id: !input vacuum_entity
    data:
      cleaning_area_id: !input clean_area

Known limitations

The following features are not currently supported by the integration:

  • Access to cameras on Litter-Robot 5 Pro models.
  • Configuring sleep schedules on Litter-Robot 4 and newer models.
  • Certain device settings, including renaming devices, filter replacement resets, and cycle count resets.
  • Reassigning pet visits.

Troubleshooting

Device becomes unavailable or unresponsive

The device shows as unavailable when it cannot reach the Whisker cloud service. Check your internet connection first, then open the Whisker app and see if you can still control the device from there. If the app also cannot connect, the Whisker service may be down or your device may be offline.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

To remove an integration instance from Home Assistant

  1. Go to Settings > Devices & services and select the integration card.
  2. Next to the entry you want to remove, select the three dots menu. Then, select Delete.
    • Depending on the integration, the entries are listed under one of the following headings:
      • Devices
      • Hubs
      • Services
      • Integration entries
  3. To confirm, select Delete.
    • Home Assistant also deletes the devices and entities of the entry.
  4. If Home Assistant asks you to restart, restart Home Assistant.
  5. If Home Assistant asks whether to also delete the application credentials, select Remove or Keep.
    • If you keep them, Home Assistant uses them automatically when you add the integration again.
    • To delete them later, refer to Deleting application credentials.
