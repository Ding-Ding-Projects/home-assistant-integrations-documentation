Google Sheets

Instructions on how to use Google Sheets in Home Assistant.

Overview

The Google Sheets integration allows you to connect your Google Drive to Home Assistant. The integration adds an action to allow you to append rows to a Sheets document. The idea is that you can store data on there for further processing. When you set up a config entry, your drive will have a new sheet called Home Assistant. You can then rename this to whatever you like.

Prerequisites

You need to configure developer credentials to allow Home Assistant to access your Google Account. These credentials are the same as the ones for Nest, YouTube, and Google Mail. These are not the same as *Device Auth* credentials previously recommended for Google Calendar.

Troubleshooting

If you have an error with your credentials you can delete them in the Application Credentials user interface.

Video tutorial

This video tutorial explains how to set up the Google Sheets integration and how you can add data from Home Assistant to a Google Sheet.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Google Sheets.

The pick implementation configuration step lists implementation.
