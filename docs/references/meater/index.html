Meater

Instructions on how to integrate the Meater Temperature Probe within Home Assistant.

Overview

The Meater integration allows for communicating with the Meater Temperature Probe from Apption Labs.

Troubleshooting

Devices will only be returned from the Meater Cloud API after the following criteria are met. There may be a delay between the Meater Cloud seeing your device and it being returned by the API.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Meater.

The reauth confirm configuration step lists password.

The user configuration step lists password, username.
