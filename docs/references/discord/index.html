Discord

Instructions on how to add Discord notifications to Home Assistant.

Overview

The Discord integration lets you send notifications from Home Assistant to Discord channels and users via a bot. You can add channels or users as notification targets to send messages from the UI. You can use the notify action to attach files (such as images or videos) from local paths or remote URLs, and use Discord embeds for rich formatting.

Add Discord integration to Home Assistant

When adding the Discord integration, enter the bot token from the Discord application's Bot page when asked for the API key.

Notification targets

A notification target is a Discord channel, user, or direct message that the bot can send messages to. Each target you add becomes a entity of the type notify, so you can send a message to it from the UI, an automation, or a script without needing the channel or user ID each time.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Discord.
