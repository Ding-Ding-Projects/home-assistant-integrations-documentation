Kaleidescape

Control Kaleidescape movie players from Home Assistant, and use their playback and video sensors in automations.

Overview

The Kaleidescape integration lets you control and automate Kaleidescape movie players from Home Assistant. You can see what is playing, send remote commands to the player, and use the playback and video information of the current movie in automations.

Supported devices

The integration supports Kaleidescape players with a movie zone, such as Strato, Alto, Cinema One, and Premiere movie players. Strato players support auto-discovery in Home Assistant.

Supported functionality

The Kaleidescape integration provides the following entities for each player.

Media player

The integration creates a media player entity for the player. It shows the title, cover art, duration, and position of the movie that is playing. You can use it to turn the player on and off, and to play, pause, stop, and skip to the next or previous chapter.

Remote

The integration creates a remote entity for the player. Use it with the Send remote command action to send the following commands.

Sensors

The integration creates the following sensor entities. All of them are enabled by default. All except Media location, Play status, and Play speed are diagnostic entities.

Automation: Turn up the lights when the movie content ends

This automation activates a lighting scene when the Media location sensor changes from content to another value, such as credits or intermission.

Data updates

The player pushes changes to Home Assistant as soon as they happen, so the integration does not need to polling poll the player. If the connection to the player drops, the integration tries to reconnect every 5 seconds. While it is disconnected, the media player entity is unavailable.

Description

Home Assistant discovers players on your local network, and then connects to the player to check that it has a movie zone. A player that cannot be reached, or a component without a movie zone, is not shown.

Resolution

1. Make sure the player is turned on and connected to the same network as Home Assistant. Discovery does not work across different networks or VLANs. 2. Make sure Home Assistant can reach the player on TCP port 10000, for example through a firewall. 3. Check that the player is a supported device.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Kaleidescape.

The user configuration step lists host.
