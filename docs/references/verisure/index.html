Verisure

Instructions on how to set up Verisure devices within Home Assistant.

Overview

Home Assistant has support to integrate your Verisure devices.

Alarm control panel

The Verisure alarm control panel platform allows you to control your Verisure Alarms.

Troubleshooting

If you get an error message stating something like *"The code for lock.XXX doesn't match pattern ^\d{0}$."*, make sure the number of digits for your code matches the number defined in the configuration options.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Verisure.

The installation configuration step lists giid.

The mfa configuration step lists code, description.

The reauth confirm configuration step lists description, email, password.

The reauth mfa configuration step lists code, description.

The user configuration step lists description, email, password.
