Genius Hub

Instructions on how to integrate a Genius Hub with Home Assistant.

Overview

The Genius Hub integration links Home Assistant with your Genius Hub CH/DHW system, including its zones, devices, and issues.

Prerequisites

You can configure the integration either via the cloud API or the local API.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Genius Hub.

The cloud api configuration step lists token.

The local api configuration step lists host, password, username.
