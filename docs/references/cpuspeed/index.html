CPU Speed

Instructions on how to integrate CPU speed within Home Assistant.

Overview

The CPU Speed integration allows you to monitor the current CPU speed.

Known issues and limitations

Not all CPUs are supported. For example, some ARM CPUs are known not to work with this integration.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for CPU Speed.
