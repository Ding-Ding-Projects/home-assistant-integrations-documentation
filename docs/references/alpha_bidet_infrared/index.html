Alpha Bidet Infrared

Integration to control Alpha Bidet bidet seats using an infrared transmitter.

Overview

The Alpha Bidet Infrared integration lets you control an Alpha Bidet bidet seat using any infrared transmitter previously configured in Home Assistant. It sends the same infrared commands as the bidet's wireless remote.

How you can use the integration

After setup, you can start and stop a wash, run the dryer, adjust the water pressure, dryer temperature, and nozzle position, and set the water and seat temperature from Home Assistant. For example, you can use an automation to start a pre-wash when the bathroom door closes, turn the seat heating off overnight, or add the wash buttons to a dashboard.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Alpha Bidet Infrared.

The reconfigure configuration step lists infrared_emitter_entity_id.

The user configuration step lists infrared_emitter_entity_id, model.
