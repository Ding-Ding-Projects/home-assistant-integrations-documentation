Subaru

Instructions on how to set up your Subaru account with Home Assistant.

Overview

This integration retrieves vehicle information and actuates remote services provided by MySubaru Connected Services(formerly known as Subaru STARLINK). This service is currently only available in the USA and Canada.

Sensors

Available sensors will vary by model, year, and subscription type. The integration will add all supported sensors for your vehicle. Sensor data is usually only updated when the vehicle is turned off unless the polling option is enabled.

Binary sensors

Binary sensors are added for Gen 2 and newer vehicles. Most are derived from data the vehicle pushes after engine shutdown, so a sensor may show unknown until the first push has been received.

Openings

Each door and window reports open or closed:

Per-door lock status

Read-only lock state for each door (front left/right, rear left/right, tailgate) — independent of the controllable lock entity, which reflects the last command sent rather than the vehicle's actual state.

EV

PHEV vehicles get two additional binary sensors:

Vehicle health

The vehicle's warning indicators (Malfunction Indicator Lamps, or MILs) are exposed as diagnostic binary sensors. Vehicle health is enabled by default and reflects the overall rollup. The individual indicators below are disabled by default; enable the ones you want to track. Only indicators your vehicle actually reports are created.

Lock

This integration supports remote locking and unlocking of vehicle doors. If doors are remotely unlocked, they will automatically relock if a door is not opened within a minute. There is no remote notification of this automatic relock.

Unlock specific door

In addition to the standard actions built into the lock entity, this integration also provides a subaru.unlock_specific_door action to specify a door to unlock.

Device tracker

Tracks the most recently reported location of the vehicle. The vehicle reports its location when it is turned off. If enabled, the polling option will also update the vehicle location.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Subaru.

The pin configuration step lists pin.

The reauth confirm configuration step lists password.

The two factor configuration step lists contact_method.

The two factor validate configuration step lists validation_code.

The user configuration step lists country, password, username.
