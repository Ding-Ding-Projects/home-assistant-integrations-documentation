Panasonic Viera

Instructions on how to integrate a Panasonic Viera TV with Home Assistant.

Overview

The Panasonic Viera integration allows you to control a Panasonic Viera TV.

Manual configuration

If you prefer to use YAML to set up your Panasonic Viera TV, you can still do it. It also allows for some extra settings. To enable the integration via YAML, add it to your configuration.yaml file.

Example `turn_on_action`

This example uses a turn_on_action, to turn on the TV using a magic wake on LAN packet. This example requires the Wake on LAN integration to be set up.

Example `play_media` script

The play_media function can be used to open web pages and other media types (images, movies) via URLs in the TV web browser.

Remote

When the integration is configured, two entities will be created: a media_player and a remote. The remote allows you to send key commands to your TV with the remote.send_command action.

Currently known supported models

If your model is not on the list, give it a test. If everything works correctly, then add it to the list on GitHub.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Panasonic Viera.

The pairing configuration step lists pin.

The user configuration step lists host.
