Home Connect

Instructions on how to set up the Home Connect integration within Home Assistant.

Overview

The Home Connect integration allows users to integrate their home appliances supporting the Home Connect standard for Bosch and Siemens using the official cloud API.

Use cases

Note that it depends on the appliance and on API permissions which of the features are supported.

Supported devices

You can find information about supported devices on the Home Connect website.

Prerequisites

1. Visit https://developer.home-connect.com and sign up for a developer account. 2. Enter the email of your login for the original Home Connect App from Bosch/Siemens under "Default Home Connect User Account for Testing" in the sign up process. 3. Go to the Applications page and select Register Application:

Programs

Both entities can use these options, but the availability of these will depend on the appliance.

Sensor

This sensor will be available only if the program is running

Event sensors

The integration adds all the event sensors supported by the appliance type, but they are disabled by default because not every appliance supports all of them.

Switch

Some devices only have the state on and turn off is not supported by the appliance, check power state availability at Home Connect API documentation for more information.

Automation examples

Get started with these automation examples

Start a program when electricity is cheap

Because electricity is typically cheaper at night, this automation will activate the silent mode when starting the program at night.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Home Connect.

The pick implementation configuration step lists implementation.
