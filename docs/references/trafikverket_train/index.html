Trafikverket Train

Instructions on how to integrate Trafikverket Train within Home Assistant.

Overview

Retrieve train departure information from Trafikverket.

Retrieved data

The next departure is calculated from actual, estimated, and planned to provide the most accurate information about departure.

Prerequisites

Please click here and register to obtain the API key.

Train station names

Click here to see examples of train station names.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Trafikverket Train.

The initial configuration step lists api_key, filter_product, from, time, to, weekday.

The reauth confirm configuration step lists api_key.

The select stations configuration step lists from, to.
