Pencom

How to use Pencom Designs 8 channel relay boards.

Configuration

The Pencom relays can be daisy-chained to allow for up to 8 boards. To enable Pencom in your installation, add it to your configuration.yaml file.

Configuration details

The domain used to identify Pencom in Home Assistant is pencom.
