FRITZ!Box Tools

Instructions on how to integrate FRITZ!Box routers into Home Assistant.

Overview

The FRITZ!Box Tools integration allows you to control your FRITZ!Box router (by FRITZ!, formerly AVM) and have presence detection for connected network devices.

Supported devices

There is support for the following device families within Home Assistant:

FRITZ!Box

FRITZ!Powerline devices do not validate the Username value. Only the Password value is checked, so you can enter any value in Username.

Supported functionality

The FRITZ!Box Tools integration provides the following main features:

Data updates

This integration fetches the data every 30 seconds from the FRITZ!Box router.

Port forward switches

Due to security reasons, FRITZ! implemented the ability to enable/disable a port forward rule only from the host involved in the rule. As a result, this integration will create entities only for rules that have your Home Assistant host as a destination.

WiFi switches

WiFi switches are created for each SSID the FRITZ!Box is serving. With these switches, one can activate and deactivate each single SSID.

Troubleshooting

In any case, when reporting an issue, please enable debug logging, restart the integration, and as soon as the issue re-occurs stop the debug logging again (_download of debug log file will start automatically_). Further _if still possible_, please also download the diagnostics data. If you have collected the debug log and the diagnostics data, provide them with the issue report.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for FRITZ!Box Tools.

The confirm configuration step lists feature_device_tracking, password, ssl, username.

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists host, port, ssl.

The user configuration step lists feature_device_tracking, host, password, port, ssl, username.
