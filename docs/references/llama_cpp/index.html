llama.cpp

Instructions on how to integrate llama.cpp (and other OpenAI-compatible servers) as a conversation agent.

Overview

The llama.cpp integration allows you to use a local or remote server that implements the OpenAI-compatible chat completions API as a conversation agent in Home Assistant.

Known limitations

This integration requires an external server that implements the OpenAI-compatible chat completions API. Features that depend on specific proprietary API properties (such as billing or usage tracking) are not supported.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for llama.cpp.

The model configuration step lists chat_model.

The reauth confirm configuration step lists api_key.

The user configuration step lists api_key, base_url.
