Collection image

Instructions on how to set up Collection image in Home Assistant.

Overview

The Collection image integration creates an image entity based on one or more media source folders selected during integration setup. From the selected folders, a single image is randomly chosen and shown in the image entity. This image entity can be used to display a dynamic picture in a frontend picture card, or as a dynamic view background.

Example usage

When running the configuration flow, you are prompted to choose one or more media directories. The integration assumes you have already set up either a local media source or another integration providing a media source. In the pop-up media browser, go to the folder containing your desired images. To select a folder, at the top of the dialog, select the Pick option. To finish the configuration flow, select Create. Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Collection image.
