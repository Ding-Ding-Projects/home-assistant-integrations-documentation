Midea

Instructions on how to integrate devices with Midea protocol into Home Assistant.

The Midea integration lets you monitor and control home appliances that use the Midea protocol, communicating with them directly over your local network. Because Midea also manufactures appliances for many other brands, this integration works with rebranded devices that speak the same protocol, not only those sold as "Midea".

All control and status updates happen locally. During setup, you select one of several supported cloud providers, which is only used when needed to obtain the token and key that protocol V3 devices require for their local connection. If you already have these credentials, you can enter them manually and skip the cloud entirely. Once setup is complete, the integration communicates only with the device on your local network.

Use cases

  • Keep a room comfortable automatically by starting your Midea air conditioner or heat pump when the temperature rises, then stopping it once the room has cooled down.
  • Save energy by turning off climate control when a window or door is left open, and turning it back on when the room is closed up again.
  • Hold a target humidity in a basement or bedroom by running your Midea dehumidifier or humidifier on a schedule, or based on the humidity reported by another sensor.
  • Include Midea fans, lights, and the bathroom master in presence- or time-based automations so a room is ready before you walk in.
  • Track diagnostic data such as filter life, water tank level, and energy use, and get notified when a filter needs cleaning or a tank needs emptying.

Manual configuration steps

If the above My button doesn't work, you can also perform the following steps manually:

  • Browse to your Home Assistant instance.

  • Go to Settings > Devices & services.

  • In the bottom right corner, select the Config flow start button.

  • From the list, select Midea.

  • Follow the instructions on screen to complete the setup.

Examples

Turn off climate control when a window or door opens

Heating or cooling a room while a window is open wastes energy. Use this blueprint to turn off a Midea climate device when a window or door opens, and turn it back on once everything is closed again.

blueprint:
  name: Turn off a Midea climate device when a window or door opens
  description: >
    Turn off a Midea air conditioner or heat pump when a window or door is
    opened, and turn it back on once everything is closed again. This avoids
    heating or cooling a room that is being aired out.
  domain: automation
  author: chemelli74
  homeassistant:
    min_version: 2026.8.0
  input:
    opening_sensor:
      name: Window or door sensor
      description: >
        The binary sensor that reports whether the window or door is open. You
        can also select a binary sensor group that combines several openings.
      selector:
        entity:
          filter:
            - domain: binary_sensor
              device_class: window
            - domain: binary_sensor
              device_class: door
    climate_target:
      name: Midea climate device
      description: The Midea climate entity to control.
      selector:
        entity:
          filter:
            - integration: midea
              domain: climate
    open_delay:
      name: Open delay
      description: >
        How long the window or door must stay open before the climate device
        is turned off.
      default: 30
      selector:
        number:
          min: 0
          max: 600
          unit_of_measurement: seconds
          mode: box
    close_delay:
      name: Close delay
      description: >
        How long the window or door must stay closed before the climate device
        is turned back on.
      default: 15
      selector:
        number:
          min: 0
          max: 600
          unit_of_measurement: seconds
          mode: box

mode: restart

triggers:
  - trigger: state
    entity_id: !input opening_sensor
    to: "on"
    for:
      seconds: !input open_delay
    id: opened
  - trigger: state
    entity_id: !input opening_sensor
    to: "off"
    for:
      seconds: !input close_delay
    id: closed

actions:
  - choose:
      - conditions:
          - condition: trigger
            id: opened
        sequence:
          - action: climate.turn_off
            target:
              entity_id: !input climate_target
      - conditions:
          - condition: trigger
            id: closed
        sequence:
          - action: climate.turn_on
            target:
              entity_id: !input climate_target

Cool a room when it gets too warm

Use this blueprint to start cooling with a Midea air conditioner when a temperature sensor rises above a threshold, and stop again once the room has cooled down.

blueprint:
  name: Cool a room with a Midea air conditioner when it gets too warm
  description: >
    Start cooling with a Midea climate device when a temperature sensor rises
    above an upper threshold, and stop again once the room has cooled down
    below a lower threshold.
  domain: automation
  author: chemelli74
  homeassistant:
    min_version: 2026.8.0
  input:
    temperature_sensor:
      name: Temperature sensor
      description: The sensor used to measure the room temperature.
      selector:
        entity:
          filter:
            - domain: sensor
              device_class: temperature
    climate_target:
      name: Midea climate device
      description: The Midea climate entity to control.
      selector:
        entity:
          filter:
            - integration: midea
              domain: climate
    upper_threshold:
      name: Upper temperature threshold
      description: Cooling starts when the measured temperature rises above this value.
      default: 26
      selector:
        number:
          min: 16
          max: 35
          step: 0.5
          unit_of_measurement: "°C"
    lower_threshold:
      name: Lower temperature threshold
      description: Cooling stops when the measured temperature drops below this value.
      default: 23
      selector:
        number:
          min: 16
          max: 35
          step: 0.5
          unit_of_measurement: "°C"
    target_temperature:
      name: Target temperature
      description: >
        The temperature the air conditioner is set to when cooling starts.
      default: 22
      selector:
        number:
          min: 16
          max: 30
          step: 0.5
          unit_of_measurement: "°C"

mode: single

triggers:
  - trigger: numeric_state
    entity_id: !input temperature_sensor
    above: !input upper_threshold
    id: too_warm
  - trigger: numeric_state
    entity_id: !input temperature_sensor
    below: !input lower_threshold
    id: cool_enough

actions:
  - choose:
      - conditions:
          - condition: trigger
            id: too_warm
        sequence:
          - action: climate.set_temperature
            target:
              entity_id: !input climate_target
            data:
              hvac_mode: cool
              temperature: !input target_temperature
      - conditions:
          - condition: trigger
            id: cool_enough
        sequence:
          - action: climate.turn_off
            target:
              entity_id: !input climate_target

Known limitations

This integration requires devices with protocol V1, V2, and V3. It is based on API v1 while some new devices are based on API v2.

Troubleshooting

Device cannot be set up

Symptom

During setup, Home Assistant reports that it is unable to connect to the device.

Description

Midea devices typically accept only one local connection at a time, and protocol V3 devices require a valid token and key. Setup fails if another app is already connected, or if the token and key are missing or incorrect.

Resolution

  1. Close the Midea mobile app, or any other tool that communicates with the device locally, and try again.
  2. When adding the device manually, make sure the token and key match the ones retrieved from the mobile app, and that the protocol version is correct.
  3. Confirm that the device is powered on and reachable on the same network as Home Assistant.

Device becomes unavailable after some time

Symptom

A device that worked before shows as unavailable.

Description

The device's IP address has most likely changed after a DHCP lease renewal.

Resolution

  1. If the device is on the same LAN as Home Assistant, local discovery finds the new address automatically after a minute. Wait, or reload the integration entry from Settings > Devices & services.
  2. If the device is on a separate LAN, discovery broadcasts do not reach it. Update the address manually by reconfiguring the integration entry, and assign a DHCP lease reservation or a fixed IP address to the device so it does not happen again.

Some entities or features are missing

Symptom

The device is set up, but some controls or sensors you expected are not available.

Description

The entities that are created depend on the device type, model, and the capabilities the device reports. Devices based on API v2 are only partially supported.

Resolution

  1. Make sure the device model and subtype entered during setup are correct.
  2. Check the list of supported devices for your device type.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

To remove an integration instance from Home Assistant

  1. Go to Settings > Devices & services and select the integration card.
  2. Next to the entry you want to remove, select the three dots menu. Then, select Delete.
    • Depending on the integration, the entries are listed under one of the following headings:
      • Devices
      • Hubs
      • Services
      • Integration entries
  3. To confirm, select Delete.
    • Home Assistant also deletes the devices and entities of the entry.
  4. If Home Assistant asks you to restart, restart Home Assistant.
  5. If Home Assistant asks whether to also delete the application credentials, select Remove or Keep.
    • If you keep them, Home Assistant uses them automatically when you add the integration again.
    • To delete them later, refer to Deleting application credentials.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Midea.

The auth method configuration step lists login_mode.

The auto configuration step lists device.

The login credentials configuration step lists account, password, server.

The manually configuration step lists device_id, ip_address, key, model, port, protocol, subtype, token, type.

The reconfigure configuration step lists ip_address.

The search configuration step lists ip_address.
