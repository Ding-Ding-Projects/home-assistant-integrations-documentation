SilverCrest Infrared

Integration to control SilverCrest infrared devices using an infrared emitter.

Overview

The SilverCrest Infrared integration lets you control SilverCrest infrared devices with any infrared emitter that has been previously configured in Home Assistant.

How you can use the integration

After setup, you can control your SilverCrest devices from Home Assistant with the created entities. Use it to turn the device on or off or control other features.

Unsupported devices

This integration supports only devices controlled via infrared (IR). Bluetooth- and Wi-Fi-controlled devices are not supported.

Contributing support for additional devices

If you own an unsupported IR-controlled device, you can help extend the integration by capturing its infrared codes and opening a feature request.

Prerequisites

For example, you can use an ESPHome device with an IR LED pointed at your SilverCrest device.

Device state

The integration uses assumed state, meaning Home Assistant cannot read the actual state of the device (for example, whether it is on or off, or what the current fan speed is).

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for SilverCrest Infrared.

The user configuration step lists device_type, infrared_entity_id.
