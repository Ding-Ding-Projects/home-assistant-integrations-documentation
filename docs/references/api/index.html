Home Assistant API

Instructions on how to set up the RESTful API within Home Assistant.

Overview

The Home Assistant API integration exposes a RESTful API and allows one to interact with a Home Assistant instance that is running headless. This integration depends on the HTTP integration.

Configuration details

The domain used to identify Home Assistant API in Home Assistant is api.
