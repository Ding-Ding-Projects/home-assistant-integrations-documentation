NexBlue

Instructions for integrating NexBlue EV chargers with Home Assistant.

Overview

The NexBlue integration connects NexBlue EV chargers to Home Assistant through the NexBlue cloud service. It provides charger status, charging measurements, energy consumption, and diagnostic information.

Supported devices

The integration supports NexBlue EV chargers that are associated with your NexBlue account.

Local Modbus TCP

Compatible NexBlue chargers can also be configured locally using Home Assistant's built-in Modbus integration. This is a separate YAML configuration and does not add local control or discovery to the NexBlue cloud integration.

Supported functionality

The NexBlue integration provides sensor entities, binary sensor entities, and a charging switch for each charger in your account.

NexBlue and automations

NexBlue does not provide integration-specific triggers, conditions, or actions in this initial version. You can still use its sensor entities with standard Home Assistant automations, such as sending a notification when charging completes.

Data updates

The NexBlue integration uses cloud polling and updates charger data every minute.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for NexBlue.

The reauth confirm configuration step lists password.

The user configuration step lists password, username.
