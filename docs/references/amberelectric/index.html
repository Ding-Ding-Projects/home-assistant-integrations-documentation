Amber Electric

Instructions on how to integrate Amber Electric live prices within Home Assistant.

Overview

Using the Amber Electric integration, customers can go a step further - setting up devices to automatically shift energy usage to cheaper and greener times, based on real-time electricity prices and forecasts

Getting an API Key

To use this integration, you will need to generate an API key.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Amber Electric.

The site configuration step lists site_id, site_name.

The user configuration step lists api_token, site_id.
