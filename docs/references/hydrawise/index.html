Hunter Hydrawise

Instructions on how to integrate your Hunter Hydrawise Wi-Fi irrigation control system within Home Assistant.

Overview

The Hunter Hydrawise integration allows you to integrate your Hunter Hydrawise Wi-Fi irrigation controller system in Home Assistant.

Supported functionality

The integration adds a device for each controller, and a device for each irrigation zone of a controller.

Zones

When Automatic watering is turned on, the zone follows the Smart Watering schedule set in the Hydrawise mobile or web app. When it's turned off, the schedule of the zone is suspended for 1 year.

Automation: Skip watering when it rains

If you have a rain gauge or a weather station in Home Assistant, you can use it to pause the watering schedule of a zone for a day once it starts raining.

Data updates

The Hunter Hydrawise integration polling polls the Hydrawise cloud service for the state of your controllers and zones every 5 minutes, and for the water use every hour.

Symptom: "Invalid authentication"

When trying to set up the integration, the form shows the message "Invalid authentication".

Description

Hydrawise didn't accept the username, password, or API key.

Resolution

1. Make sure you can sign in to the Hydrawise app with the same username and password. 2. Generate a new API key in the Account Details section of the Hydrawise app, and use that one.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Hunter Hydrawise.

The reauth confirm configuration step lists api_key, password, username.

The reconfigure configuration step lists api_key, password, username.

The user configuration step lists api_key, password, username.
