Husqvarna Automower BLE

Instructions on how to integrate Husqvarna Automower BLE lawn mowers into Home Assistant.

Overview

The Husqvarna Automower BLE integration provides connectivity with Husqvarna Automowers lawn mowers via a local Bluetooth connection. This allows connecting and controlling an Automower without any accounts, cloud, or network connection.

Prerequisites

1. Set up a Bluetooth controller. An ESPHome Bluetooth proxy works well and allows locating a device close to the mower. 2. Enter the pairing mode on the mower. Different models will do this in different ways. For the 305, for example, the mower will enter pairing mode for the first 3 minutes after powering on. Ensure the mower is in pairing mode when adding the integration. This only needs to be done once per BLE controller (so changing the ESPHome device will require a repair). 3. When manually adding the integration to Home Assistant, you will need to enter the mower BLE Mac address. You can find this in the ESPHome logs, on an Android phone, or by some other means.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Husqvarna Automower BLE.

The bluetooth confirm configuration step lists pin.

The reauth confirm configuration step lists pin.

The user configuration step lists address, pin.
