eQ-3 MAX!

Instructions on how to integrate eQ-3 MAX! components with Home Assistant via eQ-3 MAX! Cube.

Overview

The eQ-3 MAX! integration for Home Assistant allows you to connect eQ-3 MAX! components via the eQ-3 MAX! Cube. The components connects to the eQ-3 MAX! Cube via TCP and automatically makes all supported integrations available in Home Assistant. The name for each device is created by concatenating the MAX! room and device names.

Problems connecting or setting up

Due to the connection limits of the eQ-3 MAX! Cube, Home Assistant will not be able to connect to the gateway if another application is still connected. It may result in timeout errors like _Error: timed out You will need to restart Home Assistant after fixing._ and _The following integrations and platforms could not be set up: maxcube Please check your configuration._

Configuration details

The domain used to identify eQ-3 MAX! in Home Assistant is maxcube.
