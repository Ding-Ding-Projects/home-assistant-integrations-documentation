Integration reference

FYTA

Instructions on how to integrate FYTA sensors within Home Assistant.

Overview

The FYTA integration uses the open API of FYTA to obtain the data from your plant sensors and integrate these into Home Assistant.

Supported devices

The integration should work with any FYTA Sensor.

Prerequisites

For the integration to work, you need a FYTA Sensor and a FYTA account.

Configuration

The integration has no additional configuration options.

Data updates

The integration fetches data from the device every 4 minutes.

Actions

The integration provides no additional actions.

Known limitations

The integration provides the data exposed by means of the plant API. The light measurement as current daily light integral (DLI) is not yet available (currently only the PAR value is provided).

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for FYTA.

The reauth confirm configuration step lists password, username.

The user configuration step lists password, username.
