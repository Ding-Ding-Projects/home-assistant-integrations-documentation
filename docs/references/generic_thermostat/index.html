Generic Thermostat

Turn Home Assistant into a thermostat

Overview

The Generic Thermostat integration is a thermostat implemented in Home Assistant. It uses a sensor and a switch connected to a heater or air conditioning under the hood. When in heater mode, if the measured temperature is cooler than the target temperature, the heater will be turned on and turned off when the required temperature is reached. When in air conditioning mode, if the measured temperature is hotter than the target temperature, the air conditioning will be turned on and turned off when required temperature is reached. One Generic Thermostat entity can only control one switch. If you need to activate two switches, one for a heater and one for an air conditioner, you will need two Generic Thermostat entities.

YAML configuration

Alternatively, this integration can be configured and set up manually via YAML as well. To enable the integration, you need to add it to your configuration.yaml file.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Create helper, and search for Generic Thermostat.

The presets configuration step lists activity_temp, away_temp, comfort_temp, eco_temp, home_temp, sleep_temp.

The user configuration step lists ac_mode, cold_tolerance, cycle_cooldown, heater, hot_tolerance, keep_alive, max_cycle_duration, max_temp, min_cycle_duration, min_temp, name, precision, target_sensor, target_temp_step.
