PG LAB Electronics

Instructions on how to integrate PG LAB Electronics with Home Assistant.

Overview

The PG LAB Electronics integrations allows you to control PG LAB Electronics devices in Home Assistant.

Supported devices

Each E-BOARD device can be connected to a maximum of 8 E-RELAY boards. E-BOARD can control up to 64 relays or 32 shutters or a mixed configuration.

Prerequisites

Once the device is connected to your MQTT broker, it should be discovered by Home Assistant. Add PG LAB Electronics integration.

Supported features

PG LAB Electronics relays, sensors, and switches are supported.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for PG LAB Electronics.
