Obihai

Instructions on how to integrate your Obihai device into Home Assistant.

Overview

The Obihai integration allows you to view the call status for your Obihai devices.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Obihai.

The dhcp confirm configuration step lists host, password, username.

The user configuration step lists host, password, username.
