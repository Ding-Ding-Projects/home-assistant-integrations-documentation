Home Assistant Supervisor

Control Supervisor Apps and OS from Home Assistant

Overview

The Home Assistant Supervisor integration allows you to monitor and control Supervisor apps and operating system from Home Assistant. This integration is already installed if you run Home Assistant Operating System. It cannot be installed on Home Assistant Container.

Update entities

For all your installed apps, Home Assistant Core, Home Assistant Supervisor, and for the Home Assistant Operating System (if you are running that), this integration will provide update entities that provide information about pending updates, and will allow you to update to them.

Configuration details

The domain used to identify Home Assistant Supervisor in Home Assistant is hassio.
