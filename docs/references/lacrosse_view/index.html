LaCrosse View

Get data for LaCrosse View-connected sensors

Overview

It is also available in Europe as TFA View.

Supported sensors

All of the sensors on this page are supported by this integration.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for LaCrosse View.

The location configuration step lists location.

The user configuration step lists password, username.
