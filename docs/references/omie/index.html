OMIE - Spain and Portugal electricity prices

Monitor OMIE day-ahead electricity market prices for Spain and Portugal directly in Home Assistant.

Overview

Having the wholesale electricity prices within Home Assistant enables a range of use cases, such as:

Sensors

The OMIE integration retrieves the results of the day-ahead market for Spain and Portugal daily and exposes them as the following sensors.

Data updates

The OMIE integration polling polls OMIE for new data at the start of each quarter-hour (in Central European Time).

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for OMIE - Spain and Portugal electricity prices.
