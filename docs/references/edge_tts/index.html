Integration reference

Edge TTS

Reads any text aloud on your speakers with the Microsoft Edge online voices. No account or key.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Edge TTS.

The user configuration step lists voice.
