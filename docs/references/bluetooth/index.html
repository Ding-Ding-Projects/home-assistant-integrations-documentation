Bluetooth

Discover, connect, and monitor bluetooth devices.

Overview

This page documents the Bluetooth integration. To learn more about Bluetooth, refer to Bluetooth.

Configuration

While this integration is part of default_config: to enable automatic discovery of the Bluetooth Adapter, it will only be enabled by setting up the configuration flow, or manually adding it to your configuration.yaml file.

Additional details for Container

Home Assistant Container requires specific configuration to access Bluetooth adapters.

Description

Home Assistant can use your Bluetooth adapter, but only with limited functions. For example, it can't reset an adapter that stops responding, and updates from your devices can be less reliable. This happens when Home Assistant runs in a container that doesn't have the permissions it needs to manage Bluetooth.

Resolution

For problems with your Bluetooth connections, such as slow connections or interference, refer to Troubleshooting Bluetooth connections.

Integrations that require exclusive use of the Bluetooth Adapter

While newer integrations can share the Bluetooth Adapter, some legacy integrations require exclusive use of the adapter. Enabling this integration may prevent an integration that has not been updated to use newer methods from functioning.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Bluetooth.

The user configuration step lists address.
