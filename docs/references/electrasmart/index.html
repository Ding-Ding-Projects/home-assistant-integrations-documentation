Electra Smart

Instructions on how to integrate Electra Smart air conditioners with Home Assistant.

Overview

The Electra Smart integration lets you control air conditioners from Electra Air that are registered in the Electra Smart mobile app. Every air conditioner on your Electra account is added to Home Assistant as a climate entity.

Supported devices

Any air conditioner that can be added to the Electra Smart app is supported. The air conditioner needs to be online in the Electra Smart app for Home Assistant to control it.

Prerequisites

1. The air conditioner must be added and working in the Electra Smart app. 2. You need the phone number that is registered to your Electra Smart account. During setup, Electra sends a one-time password to that number by SMS.

Supported functionality

Each air conditioner on your Electra account is added as a climate entity.

Data updates

The integration polling polls the Electra cloud every 30 seconds and uses the settings that are reported there. The air conditioner only reports to the cloud when its network module wakes up, so a change made with the remote control or in the Electra Smart app can take a moment to appear in Home Assistant.

Symptom: the climate entity is unavailable

Home Assistant reports the air conditioner as unavailable and the entity cannot be controlled.

Description

Home Assistant has not received an update from the Electra cloud for the unit. This usually means the air conditioner itself is offline: it is powered off at the breaker, it has lost its network connection, or the vendor's cloud service is temporarily unavailable.

Symptom: the one-time password is rejected

During setup, the form reports that the phone number or the one-time password is invalid.

Resolution

1. Make sure the phone number matches the number registered in the Electra Smart app. 2. Cancel the current setup and start adding the integration again to request a new one-time password. Enter the new code as soon as it arrives.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Electra Smart.

The one time password configuration step lists one_time_password.

The user configuration step lists phone_number.
