Bryant Evolution

Instructions for how to integrate a Bryant Evolution HVAC system using a System Access Module.

Overview

The Bryant Evolution integration lets you control Bryant Evolution HVAC systems.

Prerequisites

1. Connect the System Access Module to the device running Home Assistant, for example, by using an RS-232-to-USB adapter. 2. Install the Bryant Evolution integration in Home Assistant, passing the name of the serial port to which the device is connected (for example, /dev/ttyUSB0)

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Bryant Evolution.
