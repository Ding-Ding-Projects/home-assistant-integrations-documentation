Flexit

Instructions on how to integrate a Flexit air handling unit into Home Assistant.

Overview

The Flexit integration connects Flexit air handling units equipped with a CI66 Modbus adapter to Home Assistant.

Your Flexit unit needs a CI66 Modbus adapter. Depending on how the adapter is connected, you need one of the following:

Migrating from YAML configuration

If you previously configured this integration through configuration.yaml, it can't be imported automatically. The Modbus connection details used to live in a separate modbus: section, which isn't accessible from the climate platform configuration.

Climate

The integration adds a climate entity for the Flexit unit. You can set a target temperature and choose a fan mode (Off, Low, Medium, or High). The current activity, such as heating, cooling, or idle, is shown as the entity's HVAC action.

Data updates

The Flexit integration polling polls the unit every 30 seconds.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Flexit.

The reconfigure configuration step lists baudrate, device, host, port, unit.

The serial configuration step lists baudrate, device, unit.

The tcp configuration step lists host, port, unit.
