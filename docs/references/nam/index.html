Nettigo Air Monitor

Instructions on how to integrate Nettigo Air Monitor within Home Assistant.

Overview

The Nettigo Air Monitor integration allows you to read temperature, humidity, pressure, and air quality data from Nettigo Air Monitor devices. Nettigo Air Monitor is a DIY air quality monitoring system with open source firmware, based on an open hardware project.

Prerequisites

Make sure your device is powered on and connected to the same network as Home Assistant. If you enabled authentication in the web interface of the device, have the username and password ready.

Supported functionality

The Nettigo Air Monitor integration provides the following entities. Entity names start with the name of the sensor module, for example BME280 temperature. Only entities for the sensors your device reports are created, so which entities you get depends on the hardware and firmware configuration of your device.

Data updates

The Nettigo Air Monitor integration polling polls data from the device every 4 minutes. The device is polled over your local network, and no cloud is involved.

Symptom: "Failed to connect"

When you try to set up the integration, Home Assistant shows the message "Failed to connect".

Description

Home Assistant cannot reach the device. The device may be powered off, the host may be wrong, or the device may not be on the same network as Home Assistant.

Resolution

1. Check that the device is powered on and connected to your Wi-Fi network. 2. Check that the host name or IP address you entered is correct. 3. Check that the device and Home Assistant are on the same network. 4. Try again.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Nettigo Air Monitor.

The credentials configuration step lists password, username.

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists host.

The user configuration step lists host.
