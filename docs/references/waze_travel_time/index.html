Waze Travel Time

Instructions on how to add Waze Travel Time to Home Assistant.

Overview

The Waze Travel Time integration provides travel time from the Waze.

Using the flexible option to set a sensor value to the Destination, you can set up a single Waze integration that will calculate travel time to multiple optional locations on demand.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Waze Travel Time.

The user configuration step lists destination, name, origin, region.
