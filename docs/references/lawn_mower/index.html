Lawn mower

Instructions on how to set up and use lawn mowers in Home Assistant.

Overview

The Lawn mower integration lets you bring compatible robotic lawn mowers into Home Assistant. Use it to monitor whether your mower is mowing, paused, idle, returning to dock, docked, or reporting an error, and build automations around those states.

Lawn mower states

A lawn mower entity can have the following states. Each item shows the label you see in the Home Assistant interface, followed by the state as Home Assistant stores it. If you write templates or edit automations in YAML, use the stored state.

Lawn mower automation examples

You can use lawn mower triggers and conditions to react when mowing starts, pauses, or finishes. You can also combine them with weather, time, and notifications to keep your yard routine simple.

Automation: Send a notification when mowing is done

When the mower returns to dock, send a message so you know the job is finished without checking the app.

Automation: Return the mower to dock when rain starts

If rain starts while the mower is active, you can stop the run early and send it back to the dock.

Configuration details

The domain used to identify Lawn mower in Home Assistant is lawn_mower.
