Snapcast

Instructions on how to integrate Snapcast into Home Assistant.

Overview

The Snapcast integration allows you to control Snapcast from Home Assistant.

Playback controls

Snapcast media player entities can expose playback controls for the player providing the currently selected Snapcast stream.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Snapcast.

The user configuration step lists host, port.
