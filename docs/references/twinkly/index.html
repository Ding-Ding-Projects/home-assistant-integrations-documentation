Twinkly

Instructions on how to integrate Twinkly LED string to Home Assistant.

Overview

The Twinkly integration allows you to control Twinkly LED string from Home Assistant.

Effects

The Twinkly devices do not initially have any effects stored locally. Effects must be added from the Twinkly application before they become visible in Home Assistant.

Operation Modes

Modes can be switched using the select entity.

Removing the integration

Twinkly follows the standard removal steps in Home Assistant.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Twinkly.

The user configuration step lists host.
