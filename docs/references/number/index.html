Number

Instructions on how to manage your Number entities with Home Assistant.

Overview

Keeps track on number entities in your environment, their state, and allows you to control them. This integration allows other integrations to get a value input from user within a range.

Number states

The state of a number entity is a number, stored without its unit, for example, 21.5. The Home Assistant interface shows the number in your local number format, with its unit if it has one, for example, 21.5 °C.

Device class

The device class tells Home Assistant what a number stands for, such as a temperature or a duration. Home Assistant uses the device class to choose the icon, the default name, the units you can select, and how the value is shown. The device class also decides whether you can use the number as a threshold in triggers and conditions for that measurement.

List of available device classes

A number without a device class is a generic number.

Configuration details

The domain used to identify Number in Home Assistant is number.
