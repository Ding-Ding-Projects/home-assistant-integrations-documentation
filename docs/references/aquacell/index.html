AquaCell

Instructions on how to integrate AquaCell with Home Assistant.

Overview

AquaCell is a water-softening device made by Culligan. The AquaCell integration allows you to monitor your AquaCell device in Home Assistant. You will need your Aquacell account information as used in the AquaCell app.

Supported devices

This integration only works for softener models which have an i-Lid and are configured through the 'Mijn AquaCell' or 'myHarvey' mobile app. These models are also recognizable by the required curved salt blocks.

Prerequisites

The softener needs to be set up with the official app before being able to integrate it in Home Assistant.

Use cases

The integration provides sensors to monitor the salt level of the softener. You can use this information to create automations, for example, to notify you when the salt level is low and a refill is needed.

Known limitations

There are no known limitations for this integration.

Troubleshooting

There are no commonly known issues with this integration.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for AquaCell.

The reauth confirm configuration step lists password.

The user configuration step lists brand, email, password.
