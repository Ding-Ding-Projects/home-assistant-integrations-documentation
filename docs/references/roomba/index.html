iRobot Roomba and Braava

Instructions on how to integrate your Wi-Fi enabled Roomba and Braava within Home Assistant.

Overview

The Roomba integrations allows you to control your iRobot Roomba vacuum or iRobot Braava m-series mop.

Integration entities

The Roomba integrations will add the following sensors.

Retrieving your credentials

Home Assistant discovers the robot's BLID (its device identifier) and tries to retrieve its password during setup. Your iRobot account password is not the password requested by the integration.

Using a third-party tool to retrieve the robot password

The third-party dorita980 tool offers a cloud method for retrieving robot credentials. Home Assistant does not maintain, review, or support this tool. Its instructions require you to provide your iRobot account credentials to it. If you choose to use it, review the instructions and security implications in its repository before proceeding. You do not need to install the tool on your Home Assistant device.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for iRobot Roomba and Braava.

The link manual configuration step lists password.

The manual configuration step lists host.

The user configuration step lists host.
