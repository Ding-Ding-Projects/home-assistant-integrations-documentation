Local IP Address

Instructions on how to integrate the Local IP Address sensor into Home Assistant.

Overview

The Local IP Address integration will expose the local (LAN) IP address of your Home Assistant instance. This can be useful when your instance has a static public hostname (for example, if you use the Nabu Casa service), but have a dynamically allocated local LAN address (for example, configured via DHCP).

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Local IP Address.
