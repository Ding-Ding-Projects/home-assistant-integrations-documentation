ekey bionyx

Instructions on how to integrate ekey bionyx devices into Home Assistant.

Overview

The ekey bionyx integration allows Home Assistant to receive events from your ekey fingerprint reader.

Prerequisites

Prefer using local IPs when setting up the integration instead of domain names because the events will be more responsive.

Supported functionality

The ekey bionyx integration provides the following entities.

Events

The functions defined during setup are represented in Home Assistant as events. You can use these events as triggers in automations.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for ekey bionyx.

The choose system configuration step lists system.

The webhooks configuration step lists url, webhook1, webhook2, webhook3, webhook4, webhook5.
