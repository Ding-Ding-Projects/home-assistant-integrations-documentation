SolarEdge

Instructions on how to integrate SolarEdge sensor within Home Assistant.

Overview

The SolarEdge integration allows you to get details from your SolarEdge solar power setup and integrate these in your Home Assistant installation. It provides two main features:

Site sensors (API key)

To get sensors for your installation, you need your installation's site ID and an API key. You can get these by logging in to your SolarEdge web portal. Note: if your portal is not in English, the labels will be different.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for SolarEdge.

The reconfigure configuration step lists api_key, password, username.

The user configuration step lists api_key, name, password, site_id, username.
