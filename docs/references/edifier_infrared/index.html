Edifier Infrared

Integration to control Edifier speakers using an infrared transmitter.

Overview

The Edifier Infrared integration lets you control an Edifier speaker using any infrared transmitter previously configured in Home Assistant.

Prerequisites

For example, you can use an ESPHome device with an IR LED pointed at your Edifier speaker.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Edifier Infrared.

The user configuration step lists infrared_entity_id, model.
