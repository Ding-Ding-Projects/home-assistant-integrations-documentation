Harbor Sleep

Instructions on how to set up Harbor Sleep baby monitors in Home Assistant.

Overview

The Harbor Sleep integration lets you monitor a Harbor Sleep baby monitor in Home Assistant.

Supported functionality

The Harbor Sleep integration provides select, sensor, and switch entities for the connected Harbor device.

Data updates

The Harbor Sleep integration uses local push. Home Assistant keeps a local connection to the Harbor device and updates entities when the device sends new data.

Actions

This integration does not provide additional actions.

Known limitations

The integration does not provide a camera entity. To get the camera stream, you must set up a WHIP endpoint on go2rtc, frigate, or similar and then add a camera entity connecting to the server that is ingesting the WHIP endpoint. See the Harbor Python README for more information.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Harbor Sleep.

The discovery confirm configuration step lists cert_pem, key_pem.

The user configuration step lists cert_pem, ip_address, key_pem, serial.
