Xiaomi

Instructions on how to integrate a video feed (via FFmpeg) as a camera as well as a router within Home Assistant.

Overview

This section shows you how to integrate a Xiaomi router or a Xiaomi camera into Home Assistant.

Camera

The Xiaomi camera integration allows you to use Xiaomi cameras within Home Assistant.

Preparing the device

1. To integrate the camera with Home Assistant, it is necessary to install a custom firmware on the device.

Configuration

To enable the camera, add the following lines to your configuration.yaml file:

Image quality

Any option supported by ffmpeg camera can be utilized via the ffmpeg_arguments configuration parameter.

Hostname template

The hostname/IP address can be provided either a value or from the existing entity attributes.

Router

The Xiaomi router integration offers presence detection by looking at connected devices to a Xiaomi router.

Compatibility test

To ensure that your router is compatible, navigate to http://YOUR_ROUTER_IP/api/misystem/devicelist. You should see a listing of the device currently connected to your router.

Configuration details

The domain used to identify Xiaomi in Home Assistant is xiaomi.
