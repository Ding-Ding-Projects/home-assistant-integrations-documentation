Tailscale

Instructions on how to integrate Tailscale within Home Assistant.

Overview

The Tailscale integration monitors the devices in your Tailscale network (Tailnet) from Home Assistant. Tailscale is a VPN service that creates secure connections between your devices using WireGuard.

To set up the integration, you need your Tailnet name and an OAuth client from the Tailscale admin console:

Supported functionality

The integration creates a device in Home Assistant for each device in your Tailnet, with the following entities.

Send a notification when an update becomes available for one of your devices, so you can keep your Tailscale clients up to date:

Data updates

The integration polling polls the Tailscale API every minute for the latest device and network information.

Integration fails to connect

Home Assistant asks you to re-authenticate after an update

The integration uses an OAuth client to connect to Tailscale. If you set it up with a Tailscale API access token, Home Assistant asks you to re-authenticate.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Tailscale.

The reauth confirm configuration step lists oauth_client_id, oauth_client_secret.

The user configuration step lists oauth_client_id, oauth_client_secret, tailnet.
