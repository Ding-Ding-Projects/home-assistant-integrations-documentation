Midea ccm15 AC Controller

Instructions on how to integrate a Midea CCM15 module into Home Assistant.

Overview

The CCM15 integration allows you to integrate Midea CCM15 devices in Home Assistant.

Climate

Each data controller can support up to 64 climate devices.

Data updates

The integration polling polls the CCM15 controller every 30 seconds.

Removing the integration

This integration follows standard integration removal, no extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Midea ccm15 AC Controller.

The user configuration step lists host, port.
