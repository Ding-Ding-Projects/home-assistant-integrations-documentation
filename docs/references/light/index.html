Light

Instructions on how to set up your lights with Home Assistant.

Overview

The Light integration allows you to track and control various light bulbs. Read the integration documentation for your particular light hardware to learn how to enable it.

State and attributes of a light entity

Light entities can have the following states: on or off. The list of available attributes depends on the device. Refer to the integration documentation of your light.

Default turn-on values

To set the default color, brightness and transition values when the light is turned on, create a custom light_profiles.csv, normally located in the default configuration folder where you find configuration.yaml.

Configuration details

The domain used to identify Light in Home Assistant is light.

Documented actions
