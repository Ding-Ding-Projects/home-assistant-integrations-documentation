Airobot

Instructions on how to integrate Airobot smart thermostats for intelligent floor heating control into Home Assistant.

Overview

Use case: Create presence-based heating automations, use BOOST to quickly warm rooms before arrival, monitor air quality to trigger ventilation alerts, and track heating runtime patterns for energy optimization.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Airobot.

The dhcp confirm configuration step lists password.

The reauth confirm configuration step lists password.

The reconfigure configuration step lists host, password, username.

The user configuration step lists host, password, username.
