OSRAM Infrared

Instructions on how to control OSRAM and LEDVANCE RGB lights using an infrared emitter.

Overview

The OSRAM Infrared integration lets you control compatible OSRAM and LEDVANCE RGB lights using an infrared emitter previously configured in Home Assistant.

Supported devices

The integration supports OSRAM and LEDVANCE RGB lights that use the supported infrared remote command set. The supported remote has 24 buttons and includes controls for power, brightness, preset colors and effects and a mode button.

Prerequisites

Before setting up the OSRAM Infrared integration, you need a working infrared emitter already set up in Home Assistant. The emitter must expose an Infrared entity and be positioned so that its infrared LED can reach the light.

Data updates

The integration does not polling poll the light. After sending a command, it updates the light entity to reflect the expected result.

The integration cannot be set up

Make sure that an infrared emitter entity is already available in Home Assistant. The emitter is required during setup.

The light does not react to commands

Make sure that the infrared emitter is positioned within range and pointed toward the light. If the emitter is unavailable, verify the hardware integration that provides the infrared entity.

Commands from the physical remote do not update the light state

Make sure that you selected an infrared receiver during setup and that the receiver is positioned so that it can capture signals from the physical remote.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for OSRAM Infrared.

The user configuration step lists infrared_emitter_entity_id, infrared_receiver_entity_id.
