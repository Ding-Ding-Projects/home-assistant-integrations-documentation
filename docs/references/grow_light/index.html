Grow light

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Grow light.

The user configuration step lists doors, dry_below, hours, moisture, name, notify, plant, planted_on, plug, power, price, resow_days, start, water_days, water_minutes, water_switch, watts.
