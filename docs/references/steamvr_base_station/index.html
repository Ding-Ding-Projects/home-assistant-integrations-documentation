SteamVR Base Station

Instructions on how to control Valve Index base stations with Home Assistant over Bluetooth.

Overview

The SteamVR Base Station integration lets you control Valve Index base stations over Bluetooth Low Energy.

Prerequisites

Base stations in range are discovered automatically.

Switch

Each base station has a switch named after the station. Turn it on to wake the station. Turn it off to put it to sleep, which stops its motors and lasers.

Automation: Put the base stations to sleep at night

Make sure the base stations are asleep at night, even if you forgot to turn them off.

Data updates

The base stations broadcast their power state and channel over Bluetooth, so Home Assistant updates the entities without polling. Connections are opened briefly to read device information during setup and when the integration loads, and to send commands.

Resolution

Make sure the base station is within range of a Bluetooth adapter or proxy with a free connection slot, then try again.

Diagnostics

The diagnostics download includes the station's device information, its last known state, and the raw data of its last Bluetooth broadcast, which can help developers reproduce issues without access to the hardware. The station name, serial number, and Bluetooth address are redacted. Attach the downloaded file when reporting an issue. For more information, see Download diagnostics.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for SteamVR Base Station.

The user configuration step lists address.
