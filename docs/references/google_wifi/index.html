Google Wifi

Monitor the network status and firmware of a Google Wifi or OnHub router.

Overview

The Google Wifi integration lets you monitor the status of a Google Wifi or OnHub router. It creates sensors for the router's connection status, IP address, firmware versions, and restart information.

The integration polls the router every 30 seconds.

Known limitations

The integration provides status sensors only. It does not provide controls for changing router settings.

The domain used to identify Google Wifi in Home Assistant is google_wifi.
