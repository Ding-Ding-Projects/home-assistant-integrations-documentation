CoolMasterNet

Instructions on how to integrate CoolMasterNet within Home Assistant.

Overview

The CoolMasterNet integration lets you control HVAC through CoolMasterNet.

Data updates

The integration polling polls the CoolMasterNet device every 60 seconds.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for CoolMasterNet.

The reconfigure configuration step lists cool, dry, fan_only, heat, heat_cool, host, off, swing_support.

The user configuration step lists cool, dry, fan_only, heat, heat_cool, host, off, swing_support.
