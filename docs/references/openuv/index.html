OpenUV

Instructions on how to integrate OpenUV within Home Assistant.

Overview

The OpenUV integration displays UV and Ozone data from openuv.io.

Generating an API Key

To generate an API key, log in at the OpenUV website.

Updating data

OpenUV does _not_ automatically update data for its entities! Users must manually update data via the homeassistant.update_entity action.

Protection window

The Protection Window binary sensor will be on when sunblock protection should be used.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for OpenUV.

The reauth confirm configuration step lists api_key.

The user configuration step lists api_key, elevation, location.
