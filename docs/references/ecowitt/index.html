Ecowitt

Instructions on how to integrate Ecowitt Weather Station within Home Assistant.

Overview

The Ecowitt integration allows you to integrate Ecowitt devices into Home Assistant.

Supported devices

The following devices have been reported to work with the Ecowitt integration:

Ecowitt Weather Station configuration

The Ecowitt integration works by first creating a callback endpoint on your Home Assistant instance and then adding this configuration to the Ecowitt console so that it starts sending data.

Supported functionality

The Ecowitt integration provides the following entities. Available entities depend on which sensors are connected to your weather station.

TLS/SSL limitations

Ecowitt devices do not support TLS/SSL connections (HTTPS). If your Home Assistant instance is configured to use HTTPS only, the Ecowitt integration will not work properly. You must ensure your Home Assistant instance is accessible via HTTP (non-secure) for the Ecowitt devices to successfully send data.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Ecowitt.
