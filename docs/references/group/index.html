Group

Instructions on how to set up groups within Home Assistant.

Overview

The Group integration lets you combine multiple entities into a single entity. Entities that are members of a group can be controlled and monitored as a whole.

Binary sensor, light, and switch groups

In short, when any group member entity is on, the group will also be on. A complete overview of how groups behave:

Button groups

The group state is the last time the grouped button was pressed.

Calendar groups

A calendar group shows the events of all its member calendars together.

Cover and valve groups

In short, when any group member entity is open, the group will also be open. A complete overview of how cover and valve groups behave:

Fan groups

In short, when any group member entity is on, the group will also be on. A complete overview of how fan groups behave:

Lock groups

In short, when any group member entity is unlocked, the group will also be unlocked. A complete overview of how lock groups behave:

Group options

To add or remove entities from an existing group, click on Group options, all the existing entities are listed in the members section where you add and remove entities.

YAML configuration

Alternatively, this integration can be configured and set up manually via YAML instead. Here are example of how to configure groups when using the configuration.yaml file.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Create helper, and search for Group.

The binary sensor configuration step lists all, entities, hide_members, name.

The button configuration step lists entities, hide_members, name.

The calendar configuration step lists entities, hide_members, name.

The cover configuration step lists entities, hide_members, name.

The event configuration step lists entities, hide_members, name.

The fan configuration step lists entities, hide_members, name.

The light configuration step lists all, entities, hide_members, name.

The lock configuration step lists entities, hide_members, name.

The media player configuration step lists entities, hide_members, name.

The notify configuration step lists entities, hide_members, name.

The sensor configuration step lists device_class, entities, hide_members, ignore_non_numeric, name, round_digits, state_class, type, unit_of_measurement.

The switch configuration step lists all, entities, hide_members, name.

The valve configuration step lists all, entities, hide_members, name.
