Mochad

Instructions on how to integrate Mochad into Home Assistant.

Overview

The Mochad integration is the main integration to integrate all X10 platforms being controlled by mochad. Besides this integration you will have to set up your X10 devices separately.

Configuration

To integrate your Mochad units with Home Assistant, add the following section to your configuration.yaml file.

Configuration details

The domain used to identify Mochad in Home Assistant is mochad.
