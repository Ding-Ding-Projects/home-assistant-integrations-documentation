Flic

Connect Flic smart buttons to Home Assistant over Bluetooth.

Overview

The Flic integration allows you to connect Flic smart buttons to Home Assistant over Bluetooth Low Energy (BLE). Flic buttons are wireless buttons that trigger automations with pushes, double-pushes, holds, swipe gestures, and rotation.

Supported functionality

The Flic integration provides the following entities.

Numbers

In Continuous mode, the Twist has no number entities. Its LED ring shows the raw rotation of the dial in that mode, so a position set from Home Assistant would not show on the device.

Data updates

Flic buttons push their events to Home Assistant over Bluetooth the moment they happen, so pushes, holds, and rotations are reported immediately. There is no polling interval to configure.

Known limitations

The Flic Twist does not store its rotation position itself. Home Assistant holds the position and sends it back to the button every time they connect. If you turn the dial while the button is disconnected, that movement is not reported, and the position is restored to the last value Home Assistant saw once the button reconnects.

Button not discovered

Make sure the button is in pairing mode before you start discovery. If it is connected to something else, disconnect it first, then push and hold the button for 6 seconds, or 1.5 seconds if it is new or was factory reset. Keep the button close to your Bluetooth adapter and try again.

Pairing failed

1. Make sure the button is not connected to anything. 2. Make sure the button is still in pairing mode. It leaves pairing mode after 30 seconds, so put it back in pairing mode right before you try again. 3. Move the button closer to the Bluetooth adapter. 4. If you see an "invalid signature" error, the button might not be a genuine Flic device. 5. If you are still having issues, try a factory reset. Remove and reinsert the battery, then within 5 seconds push and hold the button for 10 seconds (the small button on Flic Duo). A factory reset removes all pairings.

Button disconnects frequently

Flic buttons use BLE and might disconnect when idle to save battery. The integration automatically reconnects when the button advertises over Bluetooth. If disconnections are frequent, check that the button is within range and that there is no Bluetooth interference.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Flic.
