OpenWeatherMap

Instructions on how to integrate OpenWeatherMap within Home Assistant.

The OpenWeatherMap integration uses OpenWeatherMap as a source for meteorological and air quality data for your location.

There is currently support for the following device types within Home Assistant:

  • Sensor
  • Weather

You need to register for an API key: Sign up here.

Supported modes

There are currently two types of OpenWeatherMap services supported by this integration, with several corresponding modes.

One Call API 3.0

  • v3.0 : current weather, hourly forecast for 48 hours, daily forecast for 8 days

The One Call API 3.0 service requires a subscription. The subscription has a free tier with 1000 calls/day. Consider setting the limit on the OpenWeatherMap website to stay under the threshold where API usage incurs a cost. This is done in the Billing plans page, under "Calls per day".

Important

Select mode v3.0 to use One Call API 3.0. Although OpenWeather promotes One Call API 4.0, this integration does not support its endpoints. OpenWeather's migration guide states that both endpoint versions are included in the same One Call API subscription. If your API key cannot access the 3.0 endpoint, contact OpenWeather support to check your account's access. Alternatively, use the free modes below for current weather, a 5-day forecast in 3-hour steps, or air quality data.

Free

  • current : current weather
  • forecast : weather forecast, in 3-hour steps for 5 days
  • air_pollution : current air pollution

The Free services require a registration but no subscription. Once signed up, the API key can be found from your profiles' My API keys page.

⚠️ Important Deprecation Notice

One Call API 2.5 deprecation

One Call API 2.5 is no longer supported by this integration. To use One Call data, select mode v3.0 and make sure your account has access to One Call API 3.0. The free current, forecast, and air_pollution modes are separate services and remain supported.

To continue using the service if you were previously using One Call API 2.5:

  • Visit the OpenWeatherMap website and activate a subscription that provides access to One Call API 3.0.
  • During activation, you will be prompted for a credit card, but you will not be charged unless you exceed the free tier limits.
  • Configure your OWM integration to select mode v3.0.
  • Note: Subscription activation may take up to 2 hours.

For more details, set limits on your usage to avoid charges at OpenWeatherMap Subscriptions.

Important

If you register a new API key with OpenWeatherMap, it will be activated automatically. This typically takes between 10 minutes and 2 hours.
Keep in mind when configuring this integration that your new API key might not be active yet.
Invalid API-key errors can also occur if you use a key which doesn't match the corresponding service (One Call API 3.0 versus Free).

Configuration

To add the OpenWeatherMap service to your Home Assistant instance, use this My button:

Config flow start

Manual configuration steps

If the above My button doesn't work, you can also perform the following steps manually:

  • Browse to your Home Assistant instance.

  • Go to Settings > Devices & services.

  • In the bottom right corner, select the Config flow start button.

  • From the list, select OpenWeatherMap.

  • Follow the instructions on screen to complete the setup.

The **OpenWeatherMap** {% term integration %} uses [OpenWeatherMap](https://openweathermap.org/) as a source for meteorological and air quality data for your location.

There is currently support for the following device types within Home Assistant:

- Sensor
- Weather

You need to register for an API key: [Sign up here](https://home.openweathermap.org/users/sign_up).

## Supported modes

There are currently two types of OpenWeatherMap services supported by this integration, with several corresponding modes.

### [One Call API 3.0](https://openweathermap.org/price#onecall)

- `v3.0` : current weather, hourly forecast for 48 hours, daily forecast for 8 days

The One Call API 3.0 service requires a [subscription](https://openweathermap.org/api/one-call-3). The subscription has a free tier with 1000 calls/day. Consider setting the limit on the OpenWeatherMap website to stay under the threshold where API usage incurs a cost. This is done in the [Billing plans](https://home.openweathermap.org/subscriptions) page, under "Calls per day".

{% important %}
Select mode `v3.0` to use One Call API 3.0. Although OpenWeather promotes One Call API 4.0, this integration does not support its endpoints. OpenWeather's [migration guide](https://openweathermap.org/api/one-call-3-migration#billing) states that both endpoint versions are included in the same One Call API subscription. If your API key cannot access the 3.0 endpoint, contact OpenWeather support to check your account's access. Alternatively, use the free modes below for current weather, a 5-day forecast in 3-hour steps, or air quality data.
{% endimportant %}

### [Free](https://openweathermap.org/price#freeaccess)

- `current` : current weather 
- `forecast` : weather forecast, in 3-hour steps for 5 days
- `air_pollution` : current air pollution

The Free services require a registration but no subscription. Once signed up, the API key can be found from your profiles' [My API keys](https://home.openweathermap.org/api_keys) page.
