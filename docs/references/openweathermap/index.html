OpenWeatherMap

Instructions on how to integrate OpenWeatherMap within Home Assistant.

Overview

The OpenWeatherMap integration uses OpenWeatherMap as a source for meteorological and air quality data for your location.

Supported modes

There are currently two types of OpenWeatherMap services supported by this integration, with several corresponding modes.

[One Call API 3.0](https://openweathermap.org/price#onecall)

The One Call API 3.0 service requires a subscription. The subscription has a free tier with 1000 calls/day. Consider setting the limit on the OpenWeatherMap website to stay under the threshold where API usage incurs a cost. This is done in the Billing plans page, under "Calls per day".

[Free](https://openweathermap.org/price#freeaccess)

The Free services require a registration but no subscription. Once signed up, the API key can be found from your profiles' My API keys page.

One Call API 2.5 deprecation

One Call API 2.5 is no longer supported by this integration. To use One Call data, select mode v3.0 and make sure your account has access to One Call API 3.0. The free current, forecast, and air_pollution modes are separate services and remain supported.

Current Weather Conditions

Details about the API are available in the OpenWeatherMap documentation.

Current Air Quality Sensors

More details can be found at the OpenWeatherMap Air Pollution API documentation.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for OpenWeatherMap.

The user configuration step lists api_key, language, location, mode, name.
