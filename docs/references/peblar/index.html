Peblar

Instructions on how to integrate Peblar Rocksolid EV Charger with Home Assistant.

Overview

The Peblar integration integrates the [Peblar Rocksolid EV Charger] into your smart home ecosystem. It enables real-time monitoring of charging status, tracking energy consumption, controlling charging behavior, and integrating EV charging data into the Home Assistant energy dashboard.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Peblar.

The reauth confirm configuration step lists password.

The reconfigure configuration step lists host, password.

The user configuration step lists host, password.

The zeroconf confirm configuration step lists password.
