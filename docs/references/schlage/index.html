Schlage

Instructions on how to integrate Schlage WiFi smart locks into Home Assistant.

Overview

The Schlage integration provides connectivity with Schlage WiFi smart locks through Schlage's cloud API.

Known working devices

Other devices not listed above have not been tested and may not function as expected.

Data updates

The Schlage integration fetches updated lock state data every 30 seconds.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Schlage.

The reauth confirm configuration step lists password.

The user configuration step lists password, username.
