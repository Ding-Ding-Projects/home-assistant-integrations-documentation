Ruuvi Gateway

Support for Ruuvi Gateway devices acting as BLE remote scanners.

Overview

Integrates Ruuvi Gateway devices as polling BLE remote scanners via the /history endpoint.

Setup

Make sure to enable Bearer Token authentication on the Ruuvi Gateway device (and take note of the token).

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Ruuvi Gateway.

The user configuration step lists host, token.
