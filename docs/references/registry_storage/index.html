Container registry storage

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Container registry storage.

The user configuration step lists registry, address.

The sign in configuration step lists username, token.

The password configuration step lists password, password_confirmation, understand.

The repository configuration step lists repository.

The restore key configuration step lists password.
