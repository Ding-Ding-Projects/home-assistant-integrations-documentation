SMTP

Instructions on how to add email notifications to Home Assistant.

Overview

The SMTP integration allows you to deliver notifications from Home Assistant to an email recipient.

How you can use the integration

The SMTP integration allows Home Assistant to send email notifications through an SMTP server. You can use it in automations and scripts to send information, alerts, or other notifications by email.

Prerequisites

You need an email account with SMTP access. Your email provider must allow you to connect to its SMTP server and authenticate with your account.

Configuration options

The integration provides the following configuration options:

Adding recipients

You need to add at least one recipient email address. During the integration setup, you will be asked to add your first recipient email address. Additional recipients can be added later. Recipients are managed separately and can be added, edited, or removed at any time.

Specific email provider configuration

Check below some configurations examples for specific email providers. If you are in doubt about the SMTP settings required, check your email provider configuration or help pages for more information about its specific SMTP configuration.

Google Mail

Google has some extra layers of protection that need special attention. You must use an application-specific password in your notification configuration.

Notifiers

The SMTP integration will add a notify entity for each configured recipient. To send a notification, you can use the Send a notification message (notify.send_message) action. For more customizable notifications, use the Send message (smtp.send_message) instead.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for SMTP.

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists encryption, password, port, sender, sender_name, server, username, verify_ssl.

The user configuration step lists encryption, password, port, sender, sender_name, server, username, verify_ssl.
