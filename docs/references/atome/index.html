Atome Linky

Integrate Atome Linky consumption data within Home Assistant.

Overview

The Atome Linky integration is retrieving the consumption of your home from the Direct Energy Atome electric meter. This special little device is connected to a Linky Electric Meter, and sends live data to a cloud platform.

Configuration

To use it, you need to order the device directly from "Total Direct Energie" Mobile App. Then you need to follow up the installation (covered in the Atome App). The configuration (see below) needs your Atome username & password you created during the initialization of the Atome device.

Configuration details

The domain used to identify Atome Linky in Home Assistant is atome.
