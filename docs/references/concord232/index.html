Concord232

Instructions on how to integrate Interlogix/GE Concord4 into Home Assistant.

Overview

The Concord232 integration provides integration with GE, Interlogix (and other brands) alarm panels that support the RS-232 Automation Control Panel interface module (or have it built in). Supported panels include Concord 4.
