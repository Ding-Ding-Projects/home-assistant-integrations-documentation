Todoist

Instructions on how to integrate Todoist into Home Assistant.

Overview

This integration allows you to connect to your Todoist projects as todo or calendar entities. All tasks get updated roughly every minute.

Custom projects

You can manually configure the Todoist calendar (only) integration using configuration.yaml which can specify "custom" projects which match against criteria you set. You should prefer the above instructions for configuring Todoist from the UI.

To-do list entity

See the todo integration for details on how to manage items on the Todoist to-do list, including actions for creating and deleting to-do items.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Todoist.

The user configuration step lists token.
