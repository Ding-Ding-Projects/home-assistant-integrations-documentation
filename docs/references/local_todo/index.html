Local to-do

Instructions on how to use local to-do lists in Home Assistant.

Overview

The Local to-do list integration allows you to create to-do lists in Home Assistant. To-do lists are shown on the To-do list dashboard for tracking items and whether or not they have been completed.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Local to-do.

The user configuration step lists todo_list_name.
