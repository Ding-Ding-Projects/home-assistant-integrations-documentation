Washington State Department of Transportation (WSDOT)

Instructions on how to integrate WSDOT data into your home.

Overview

The Washington State Department of Transportation (WSDOT) integration will give you travel time information from the Washington State Department of Transportation (WSDOT).

Prerequisites

First, you need to get a free Traveler Information api_key from the WSDOT API webpage. Just enter your email address to instantly get the key.

Advanced configuration

If you would like to manually curate the sensors provided by WSDOT, you can edit your configuration.yaml file to remove, rename, or re-add routes.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Washington State Department of Transportation (WSDOT).

The user configuration step lists api_key.
