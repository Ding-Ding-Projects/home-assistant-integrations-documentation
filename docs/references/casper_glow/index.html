Casper Glow

Instructions on how to integrate Casper Glow lights into Home Assistant.

The Casper Glow integration allows you to control your Casper Glow light from Home Assistant over Bluetooth. The Casper Glow is a portable dimmable light designed as a sleep aid, featuring a gentle dimming sequence that gradually lowers brightness to help you fall asleep. You can incorporate it into your bedtime automations to control brightness levels.

Supported devices

The following devices are supported:

  • Casper Glow (identified as "Jar" over Bluetooth)

Prerequisites

Before setting up the integration, make sure:

  1. Your Home Assistant host has a Bluetooth adapter.
  2. The Casper Glow is powered on and within Bluetooth range.

Configuration

To add the Casper Glow device to your Home Assistant instance, use this My button:

Config flow start

Manual configuration steps

If the above My button doesn't work, you can also perform the following steps manually:

  • Browse to your Home Assistant instance.

  • Go to Settings > Devices & services.

  • In the bottom right corner, select the Config flow start button.

  • From the list, select Casper Glow.

  • Follow the instructions on screen to complete the setup.


Bluetooth address:
  description: "The Bluetooth address of your Casper Glow light. Discovered devices are shown automatically."

Supported functionality

Entities

The Casper Glow integration provides the following entities.

Binary sensors

  • Dimming paused
    • Description: Indicates whether the Glow's dimming sequence is currently paused.
  • Charging
    • Description: Indicates whether the Glow is currently charging.

Buttons

  • Pause dimming

    • Description: Pauses dimming, holding the current brightness level until resumed.

  • Resume dimming

    • Description: Resumes dimming from where it left off.

Lights

  • Casper Glow
    • Description: Controls the on/off state and brightness of the Glow light. Brightness is mapped to five levels.

Sensors

  • Battery

    • Description: Reports the current battery level of the Glow as a percentage.

  • Dimming end time (disabled by default)

    • Description: Shows the projected time when the current dimming sequence will end. This value is a timestamp that updates only when there is a significant change during a poll interval. Such as pausing or resuming dimming, or manually adjusting the physical light.

Selects

  • Dimming time
    • Description: Configures how long the dimming sequence lasts before the light turns off. You can choose between 15, 30, 45, 60, or 90 minutes. The new dimming time takes effect the next time the light is turned on.

Examples

Bedtime routine

Start a dimming sequence at a set time each night. This blueprint lets you pick your bedtime and how long the light takes to dim, so your Glow is ready when you are.

blueprint:
  name: "Casper Glow bedtime routine"
  description: "Turns on the Casper Glow at a set time with a configured dimming duration for bedtime."
  domain: automation
  input:
    bedtime:
      name: Bedtime
      selector:
        time:
    glow_device:
      name: Casper Glow
      selector:
        device:
          filter:
            - integration: casper_glow
    dimming_minutes:
      name: Dimming duration
      default: "30"
      selector:
        select:
          options:
            - "15"
            - "30"
            - "45"
            - "60"
            - "90"
variables:
  glow_device: !input glow_device
triggers:
  - trigger: time
    at: !input bedtime
actions:
  - action: select.select_option
    target:
      entity_id: >
        {{ device_entities(glow_device)
           | select('match', 'select\\..*')
           | first }}
    data:
      option: !input dimming_minutes
  - action: light.turn_on
    target:
      entity_id: >
        {{ device_entities(glow_device)
           | select('match', 'light\\..*')
           | first }}

Pause on motion

Keep the light from dimming while you're still up. This blueprint pauses the dimming sequence whenever motion is detected, so the light holds its brightness until you settle in.

blueprint:
  name: "Pause Casper Glow on motion"
  description: "Pauses the Casper Glow dimming sequence when motion is detected in the room."
  domain: automation
  input:
    motion_sensor:
      name: Motion sensor
      selector:
        entity:
          domain: binary_sensor
          device_class: motion
    glow_light:
      name: Casper Glow light
      selector:
        entity:
          filter:
            integration: casper_glow
            domain: light
variables:
  glow_light: !input glow_light
  pause_button: >
    {{ device_entities(device_id(glow_light))
        | select('match', 'button\\.')
        | select('search', 'pause')
        | first }}
triggers:
  - trigger: state
    entity_id: !input motion_sensor
    to: "on"
conditions:
  - condition: state
    entity_id: !input glow_light
    state: "on"
actions:
  - action: button.press
    target:
      entity_id: "{{ pause_button }}"

Turn on and hold at nightlight level

Turn on the Glow and let it dim down to a soft nightlight, then hold it there. This blueprint starts the dimming sequence and automatically pauses it when a set number of minutes remain, leaving a gentle glow in the room through the night.

Note

The sensor.jar_dimming_end_time sensor is disabled by default. You must enable it manually for this blueprint to work correctly.

blueprint:
  name: "Turn on Casper Glow and pause at nightlight level"
  description: "Turns on the Casper Glow at a set time, then pauses the dimming sequence when a specified number of minutes remain, holding the light at a dim nightlight level. Requires the Dimming End Time sensor to be enabled."
  domain: automation
  input:
    bedtime:
      name: Turn-on time
      selector:
        time:
    glow_device:
      name: Casper Glow
      selector:
        device:
          filter:
            - integration: casper_glow
    dimming_minutes:
      name: Dimming duration
      default: "15"
      selector:
        select:
          options:
            - "15"
            - "30"
            - "45"
            - "60"
            - "90"
    pause_at_remaining:
      name: Pause when this many minutes remain
      default: 10
      selector:
        number:
          min: 1
          max: 89
          unit_of_measurement: min
mode: restart
variables:
  glow_device: !input glow_device
  dimming_minutes: !input dimming_minutes
  pause_at_remaining: !input pause_at_remaining
  light_entity: >
    {{ device_entities(glow_device) | select('match', 'light\\.') | first }}
  select_entity: >
    {{ device_entities(glow_device) | select('match', 'select\\.') | first }}
  pause_button: >
    {{ device_entities(glow_device)
        | select('match', 'button\\.')
        | select('search', 'pause')
        | first }}
  sensor_entity: >
    {{ device_entities(glow_device)
        | select('match', 'sensor\\.')
        | select('search', 'dimming_end_time')
        | first }}
triggers:
  - trigger: time
    at: !input bedtime
actions:
  - action: select.select_option
    target:
      entity_id: "{{ select_entity }}"
    data:
      option: !input dimming_minutes
  - action: light.turn_on
    target:
      entity_id: "{{ light_entity }}"
  - wait_for_trigger:
      - trigger: template
        value_template: >-
          {% set end = states(sensor_entity) | as_datetime %}
          {% if end is not none %}
            {{ ((end - now()).total_seconds() / 60) | round(0) <= pause_at_remaining | int }}
          {% else %}
            false
          {% endif %}
    timeout:
      minutes: "{{ dimming_minutes | int }}"
    continue_on_timeout: false
  - action: button.press
    target:
      entity_id: "{{ pause_button }}"

Data updates

The Casper Glow integration detects the device through passive Bluetooth advertisements. All state updates are retrieved by actively polling the device every 30 seconds — for example, to detect changes made directly on the light or through the Casper app.

Known limitations

  • Brightness is limited to five discrete levels. The integration maps these to the Home Assistant 0-255 brightness scale, snapping to the nearest supported level.
  • The integration communicates over Bluetooth, so the light must remain within range of the Home Assistant Bluetooth adapter.
  • Only one Bluetooth connection to the Glow can be active at a time. If the Casper app is connected, Home Assistant may not be able to reach the device.

Troubleshooting

The device is not discovered

Make sure the Glow light is powered on and within Bluetooth range. If it still doesn't appear, try toggling the light off and on by flipping it over. Ensure no other Bluetooth device (like the Casper app) is actively connected to it.

The light shows as unavailable

This typically means the Bluetooth connection was lost. Check that the light is powered on and within range. Moving the light closer to the Bluetooth adapter may help.

Resetting the light

If the light remains unresponsive, a reboot or factory reset may help.

  • To reboot, hold both buttons on the Glow until it briefly turns on. This takes about 30 seconds.
  • To factory reset the Glow, press one of the buttons 6 times while holding the other button down.
    • This returns the device to default settings and removes it from any configured Glow light groups (configured outside Home Assistant in the Casper app).

Removing the integration

This integration follows standard integration removal. No extra steps are required.

To remove an integration instance from Home Assistant

  1. Go to Settings > Devices & services and select the integration card.
  2. Next to the entry you want to remove, select the three dots menu. Then, select Delete.
    • Depending on the integration, the entries are listed under one of the following headings:
      • Devices
      • Hubs
      • Services
      • Integration entries
  3. To confirm, select Delete.
    • Home Assistant also deletes the devices and entities of the entry.
  4. If Home Assistant asks you to restart, restart Home Assistant.
  5. If Home Assistant asks whether to also delete the application credentials, select Remove or Keep.
    • If you keep them, Home Assistant uses them automatically when you add the integration again.
    • To delete them later, refer to Deleting application credentials.
