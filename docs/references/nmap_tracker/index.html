Nmap Tracker

Instructions on how to integrate Nmap into Home Assistant.

Overview

As an alternative to the router-based device tracking, it is possible to directly scan the network for devices by using Nmap. The IP addresses to scan can be specified in any format that Nmap understands, including the network-prefix notation (192.168.1.1/24) and the range notation (192.168.1.1-255).

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Nmap Tracker.

The user configuration step lists exclude, home_interval, hosts, mac_exclude, scan_options.
