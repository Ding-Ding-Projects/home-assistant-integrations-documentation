Tilt Pi

Instructions on how to configure a Tilt Pi.

Overview

The Tilt Pi integration allows you to connect a Tilt Pi to Home Assistant to automatically discover Tilt Hydrometer devices.

Prerequisites

1. Have a Raspberry Pi with the Tilt Pi software installed. 2. Have a Tilt Hydrometer in range of the Tilt Pi. 3. Have the IP address or hostname of the Tilt Pi.

Entities

After adding the integration, you can add the Tilt Pi device to your Home Assistant. If the Tilt Pi was found and there are Tilt Hydrometers in its range, then entities will be created for each Tilt Hydrometer.

Data updates

The Tilt Pi integration polling polls the Tilt Pi for data every 60 seconds. This interval is currently not configurable.

Configuration details
