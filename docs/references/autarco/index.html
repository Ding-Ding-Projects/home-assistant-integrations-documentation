Integration reference

Autarco

Instructions on how to integrate Autarco solar system within Home Assistant.

Overview

The Autarco integration allows you to gather data from the cloud API of Autarco and use it in Home Assistant.

Data updates

The integration will update its information by polling Autarco every 5 minutes. This ensures the data in Home Assistant is up to date.

Actions

This integration does not provide additional actions.

Supported functionality

The Autarco platform mainly provides sensors that you can use in your energy dashboard.

Solar

Gain insight into how much solar energy your site produces.

Inverters

Gain insight into how much energy an inverter produces. The integration will create a device for each inverter linked to your account.

Battery

If you have a battery connected to your system, you can monitor the battery status and see how much energy it charges or discharges.

Automation: Act when solar production is high

This example sends a notification when solar power production remains above 2 kW for two minutes.

Automation: Act when battery charge is low

This example sends a notification when the battery state of charge drops below 20%.

Known limitations

The integration does not show data about your self-sufficiency or CO2 savings.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Autarco.

The reauth confirm configuration step lists password.

The user configuration step lists email, password.
