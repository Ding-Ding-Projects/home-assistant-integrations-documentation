Elmax

Instructions on how to integrate Elmax panels within Home Assistant.

Overview

The Elmax integration enables Home Assistant integration with

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Elmax.

The cloud configuration step lists password, username.

The direct configuration step lists panel_api_host, panel_api_port, panel_pin, use_ssl.

The panels configuration step lists panel_id, panel_name, panel_pin.

The reauth confirm configuration step lists panel_pin, password, username.

The zeroconf setup configuration step lists panel_pin, use_ssl.
