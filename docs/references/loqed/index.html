LOQED Touch Smart Lock

Instructions on how to integrate a Loqed Touch Smart Lock

Overview

Integrate your LOQED Touch Smart Lock with Home Assistant. The lock instantly notifies Home Assistant of a lock state change and you can change the lock state yourself.

Actions

Removing the integration

This integration follows standard integration removal. Removing it also removes the webhook that Home Assistant registered on your lock.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for LOQED Touch Smart Lock.

The pick lock configuration step lists lock_id.

The reauth confirm configuration step lists api_token.

The user configuration step lists api_token.
