VIVOTEK

Instructions on how to integrate VIVOTEK cameras within Home Assistant.

Overview

The VIVOTEK integration allows you to integrate a VIVOTEK IP camera into Home Assistant.

Using VIVOTEK cameras in automations

VIVOTEK provides a camera entity. To use a VIVOTEK camera in an automation or script, use one of the shared camera actions and select your VIVOTEK camera as the target.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for VIVOTEK.

The user configuration step lists authentication, ip_address, name, password, port, security_level, ssl, stream_path, username, verify_ssl.
