Harman Luxury Audio

Instructions on how to integrate Harman Luxury Audio streamers into Home Assistant.

Overview

The Harman Luxury Audio integration lets you control network streamers built on the Harman Luxury Audio (StreamUnlimited StreamSDK) platform, such as the Arcam Radia ST5 and ST60, and equivalent JBL and Mark Levinson streamers.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Harman Luxury Audio.

The user configuration step lists host.
