Change device type of a switch

Instructions on how to convert any Home Assistant switch into something else.

Overview

The Change device type of a switch helper integration lets you convert any Home Assistant switch into a Home Assistant Light, Cover, Fan, Lock, Siren, or Valve.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Create helper, and search for Change device type of a switch.

The user configuration step lists entity_id, invert, target_domain.

Entity platforms

  • cover
  • fan
  • light
  • lock
  • siren
  • valve
