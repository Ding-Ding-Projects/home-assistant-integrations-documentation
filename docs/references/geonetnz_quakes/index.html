GeoNet NZ Quakes

Instructions on how to integrate the GeoNet New Zealand Quakes feed into Home Assistant.

Overview

The GeoNet NZ Quakes integration lets you use a GeoJSON feed provided by New Zealand's GeoNet with information about quakes in the New Zealand region that happened within the last 7 days. It retrieves incidents from a feed and shows information of those incidents filtered by distance to Home Assistant's location.

Sensor

This integration automatically creates a sensor that shows how many entities are currently managed by this integration. In addition to that the sensor has some useful attributes that indicate the currentness of the data retrieved from the feed.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for GeoNet NZ Quakes.

The user configuration step lists mmi, radius.
