eGauge

eGauge Energy Monitors

Overview

The eGauge integration is used to integrate with eGauge energy monitors. eGauge provides energy monitors for residential and commercial applications. They are commonly used with solar energy installations. The eGauge integration can expose sensor readings from eGauge devices into Home Assistant, including energy meters that work with the Energy Dashboard.

Supported devices

This integration supports all eGauge energy monitors running firmware version 4.2 or newer. For instructions on how to check and upgrade the firmware on eGauge devices, see the eGauge knowledge base.

Supported functionality

The eGauge integration provides the following entities:

Data updates

The eGauge integration polling polls the device every 30 seconds.

Symptom: "Failed to connect"

When trying to set up the integration, the form shows the message "Failed to connect".

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for eGauge.

The reauth confirm configuration step lists password.

The user configuration step lists host, password, ssl, username, verify_ssl.
