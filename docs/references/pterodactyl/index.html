Pterodactyl

Instructions on how to integrate a Pterodactyl server into Home Assistant.

Overview

The Pterodactyl integration allows you to monitor and control the game servers on your Pterodactyl server from Home Assistant.

Data updates

This integration polling polls each game server on your Pterodactyl server every 60 seconds. If a request for one game server fails, entities for all game servers become unavailable until a refresh succeeds.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Pterodactyl.

The reauth confirm configuration step lists api_key.

The user configuration step lists api_key, url.
