MQTT Eventstream

Instructions on how to set up MQTT eventstream within Home Assistant.

Overview

The MQTT Eventstream integration connects two Home Assistant instances via MQTT.

Configuration

To integrate MQTT Eventstream into Home Assistant, add the following section to your configuration.yaml file.

Multiple instances

Events from multiple instances can be aggregated to a single parent instance by subscribing to a wildcard topic from the parent instance.

Configuration details

The domain used to identify MQTT Eventstream in Home Assistant is mqtt_eventstream.
