Template

Instructions on how to create template entities in Home Assistant.

Overview

The Template integration allows creating entities which derive their values from other data. This is done by specifying templates for properties of an entity, like the name or the state.

Creating a template helper from the user interface

You can create state-based template entities from the user interface. To create a helper of a state-based template entity:

YAML configuration

Entities are defined in your YAML configuration files under the template: key. You can define multiple configuration blocks as a list. Each block can define entities of any of the supported types, and can contain optional update triggers.

State-based template entities

Template entities by default update as soon as any of the referenced data in the template updates.

Trigger-based template entities

If you want more control over when an entity updates, you can define triggers. Triggers follow the same format and work exactly the same as triggers in automations. This feature is a great way to create entities based on webhook data (example), or update entities based on a schedule.

Trigger variables

Some trigger options accept templates, such as the event type of an event trigger. To use your own values in these options, define them under trigger_variables. This works the same way as trigger variables in automations.

Common entity options

Each entity platform has its own set of configuration options, but there are some common options that can be used across all entity platforms.

Alarm Control Panel

The template alarm control panel platform allows you to create alarm control panels with templates to define the state and scripts to define each action.

Binary Sensor

The template binary sensor platform allows you to create binary sensors with templates to define the state and attributes.

State based binary sensor - Washing Machine Running

This example creates a washing machine "load running" sensor by monitoring an energy meter connected to the washer. During the washer's operation, the energy meter fluctuates wildly, hitting zero frequently even before the load is finished. By utilizing delay_off, we can have this sensor only turn off if there has been no washer activity for 5 minutes.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Create helper, and search for Template.

The alarm control panel configuration step lists arm_away, arm_custom_bypass, arm_home, arm_night, arm_vacation, code_arm_required, code_format, device_id, disarm, name, trigger, value_template.

The binary sensor configuration step lists device_class, device_id, name, state.

The button configuration step lists device_class, device_id, name, press.

The climate configuration step lists current_temperature, device_id, hvac_action, hvac_mode, hvac_modes, name, set_hvac_mode, set_temperature, target_temperature, temperature_unit.

The cover configuration step lists close_cover, device_class, device_id, name, open_cover, position, set_cover_position, state, stop_cover.

The device tracker configuration step lists device_id, in_zones, latitude, longitude, name.

The event configuration step lists device_class, device_id, event_type, event_types, name.

The fan configuration step lists device_id, name, percentage, set_percentage, speed_count, state, turn_off, turn_on.

The image configuration step lists device_id, name, url, verify_ssl.

The light configuration step lists device_id, hs, level, name, set_hs, set_level, set_temperature, state, temperature, turn_off, turn_on.

The lock configuration step lists code_format, device_id, lock, name, open, state, unlock.

The media player configuration step lists device_class, device_id, is_volume_muted, media_next_track, media_pause, media_play, media_previous_track, media_stop, name, select_source, source, source_list, state, turn_off, turn_on, volume_down, volume_level, volume_mute, volume_set, volume_up.

The number configuration step lists device_class, device_id, max, min, name, set_value, state, step, unit_of_measurement.

The select configuration step lists device_id, name, options, select_option, state.

The sensor configuration step lists device_class, device_id, name, state, state_class, unit_of_measurement.

The switch configuration step lists device_id, name, turn_off, turn_on, value_template.

The update configuration step lists backup, device_class, device_id, in_progress, install, installed_version, latest_version, name, release_summary, release_url, specific_version, title, update_percentage.

The vacuum configuration step lists clean_spot, device_id, fan_speed, fan_speeds, locate, name, pause, return_to_base, set_fan_speed, start, state, stop.

The water heater configuration step lists current_temperature, device_id, name, operation_list, operation_mode, set_operation_mode, set_temperature, target_temperature, temperature_unit, turn_off, turn_on.

The weather configuration step lists condition, device_id, forecast_daily, forecast_hourly, humidity, name, temperature, temperature_unit.
