FRITZ!Box Call Monitor

Instructions on how to integrate a phone call monitor for FRITZ!Box routers into Home Assistant.

Overview

The FRITZ!Box Call Monitor integration monitors the call monitor exposed by FRITZ!Box routers (by FRITZ!, formerly AVM) on TCP port 1012. It will assume the values idle, ringing, dialing or talking with the phone numbers involved contained in the state attributes. It can also access the internal phone book of the router to look up the names corresponding to the phone numbers and store them in the state attributes.

Setup

To activate the call monitor on your FRITZ!Box, dial #96\*5\* from any phone connected to it. When using a DECT phone, the phone must not be connected via a DECT-Repeater, it must be directly connected to your FRITZ!Box.

Send notifications on state change

This example shows how to send notifications whenever the sensor's state changes. You will get notified both when you receive a call and also when a call is placed.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for FRITZ!Box Call Monitor.

The phonebook configuration step lists phonebook.

The reauth confirm configuration step lists password, username.

The user configuration step lists host, password, port, username.
