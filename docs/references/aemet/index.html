AEMET OpenData

Instructions on how to integrate AEMET OpenData within Home Assistant.

Overview

The AEMET integration uses AEMET OpenData as a source for current meteorological data for your location. AEMET stands for "Agencia Estatal de Meteorología", which is the Spanish Meteorological Agency.

Configuration

The integration creates one weather entity per forecast mode and also sensors for all available conditions. There are two forecast modes, daily for daily forecast up to 6 days or hourly for an hourly forecast up to 3 days.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for AEMET OpenData.

The user configuration step lists api_key, location, name.
