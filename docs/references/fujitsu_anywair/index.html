Fujitsu anywAIR

Connect and control your Fujitsu anywAIR devices using the Advantage Air integration

Port configuration

Fujitsu anywAiR uses port 10211 for API communication. You will need to change the default port provided by the Advantage Air integration to 10211 to use it with Fujitsu anywAiR.

Configuration details

Set up Fujitsu anywAIR through its supporting integration, advantage_air.
