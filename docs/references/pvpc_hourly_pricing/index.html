Spain electricity hourly pricing (PVPC)

Instructions on how to set up the PVPC Hourly Pricing sensor in Home Assistant.

Overview

Specifically, it shows the current __active energy invoicing price (FEU)__ in €/kWh, which is the energy term hourly price applied in the consumers' electrical bill with a contracted power not exceeding 15 kW and which are under the PVPC (Voluntary Price for Small Consumer).

Configuration

To configure PVPC Hourly Pricing, set it up via the integrations panel in the configuration screen.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Spain electricity hourly pricing (PVPC).

The api token configuration step lists api_token.

The reauth confirm configuration step lists api_token, description, use_api_token.

The user configuration step lists name, power, power_p3, tariff, use_api_token.
