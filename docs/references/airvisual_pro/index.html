AirVisual Pro

Instructions on how to use AirVisual Pro devices within Home Assistant

Overview

The AirVisual Pro integration allows users to retrieve data from an AirVisual Node/Pro unit. Communication with the device occurs over the local network.

Determining the Password

You will need the device's Samba password, which can be found on the unit.

Sensor types

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for AirVisual Pro.

The reauth confirm configuration step lists password.

The user configuration step lists ip_address, password.
