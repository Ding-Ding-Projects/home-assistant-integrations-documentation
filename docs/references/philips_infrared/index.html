Philips Infrared

Integration to control Philips TVs using an infrared emitter.

Overview

The Philips Infrared integration lets you control a Philips TV from Home Assistant using any infrared emitter previously configured in Home Assistant. It is a good fit for Philips TVs that aren't connected to your network, or when you prefer to control the TV the same way its remote does.

Supported devices

The integration supports Philips TVs that can be controlled with the standard Philips RC-6 infrared protocol.

Prerequisites

To send commands, you need an infrared emitter. For example, you can use an ESPHome device with an IR LED pointed at your Philips TV.

Media player

The integration creates one media player entity for your TV.

Symptom: The TV doesn't respond to commands

You send a command from Home Assistant, but your TV doesn't react.

Description

The infrared signal is probably not reaching the TV. Infrared relies on a clear line of sight between the emitter and the receiver.

Resolution

Make sure the infrared emitter points at the receiver window of the TV and that nothing blocks the path between them. For more steps, refer to the troubleshooting section of the infrared documentation.

Symptom: The TV turns on when it should turn off

You turn the TV off from Home Assistant, but the TV turns on instead.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Philips Infrared.

The user configuration step lists infrared_entity_id.
