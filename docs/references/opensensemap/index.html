openSenseMap

Instructions on how to set up openSenseMap sensors in Home Assistant.

Overview

The openSenseMap integration queries the open data API of openSenseMap.org to monitor the measurements published by a sensor station.

Setup

To find the ID of a station, open it on openSenseMap and copy the last segment of the URL — for example, 5b450e565dc1ec001bf7cd1d in https://opensensemap.org/explore/5b450e565dc1ec001bf7cd1d.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for openSenseMap.

The user configuration step lists station_id.
