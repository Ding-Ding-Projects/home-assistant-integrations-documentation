Slack

Instructions on how to add Slack notifications to Home Assistant.

Overview

The Slack integration allows you to deliver notifications from Home Assistant to Slack.

Slack App

1. Create a new app under your Slack.com account. 2. Click the OAuth & Permissions link in the sidebar, under the Features heading.

You can easily create a bot with all the permissions needed from an App Manifest.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Slack.

The reauth confirm configuration step lists api_key.

The user configuration step lists api_key, default_channel, icon, username.
