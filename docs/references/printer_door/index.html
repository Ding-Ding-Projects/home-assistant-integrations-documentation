Printer door

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Printer door.

The discovery confirm configuration step lists access_code, name.

The reauth confirm configuration step lists access_code.

The user configuration step lists access_code, host, name, serial.
