AC Defender

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for AC Defender.

The user configuration step lists climate_entity_id, my_temperature, safety_temperature.

The sensors configuration step lists room_sensor, door_sensor, presence_entity, outdoor_entity, power_kw.

The guards configuration step lists enabled_guards.

The reconfigure configuration step lists climate_entity_id, my_temperature, safety_temperature.

The reconfigure sensors configuration step lists room_sensor, door_sensor, presence_entity, outdoor_entity, power_kw.
