Model Context Protocol Client

Instructions on how to give your Home Assistant AI conversation agent extra tools from a Model Context Protocol (MCP) server.

Overview

The Model Context Protocol Client integration gives your AI conversation agent in Home Assistant extra tools from an MCP server of your choice. For example, you can connect the MCP server of a service you already use, such as a project tracker or a note-taking app, and then ask Assist about it. You can also connect to an MCP server that lets Assist remember things between conversations, or search the web in ways Home Assistant can't do on its own.

Configuration options

The integration provides the following configuration options:

Signing in to the MCP server

If the MCP server requires you to sign in, Home Assistant detects this after you enter the URL. The first time, it asks you for an OAuth Client ID and Client Secret for the MCP server and stores them as Application Credentials.

Using the MCP tools in a conversation agent

After you add the integration, your conversation agent doesn't use the new tools until you allow it.

How it works

Home Assistant acts as a client to the MCP server you specify. It connects to the MCP server and asks for the list of tools it offers. These tools are then made available to Home Assistant conversation agents, in the same way as the tools of Device control. For more details on the protocol, refer to the Model Context Protocol introduction.

Authorization

The Model Context Protocol supports OAuth, so you can give Home Assistant access to MCP servers that require you to sign in. Home Assistant stores the MCP server's OAuth client ID and client secret as Application Credentials. For the setup steps, refer to Signing in to the MCP server.

Data updates

Home Assistant checks the MCP server for its list of available tools every 30 minutes.

Known limitations

The Home Assistant Model Context Protocol Client integration currently only supports a subset of MCP features:

Symptom: "The MCP server does not support a required capability (Tools)"

When you add the integration, setup stops with this message.

Resolution

Home Assistant only works with MCP servers that provide tools. Check the documentation of the MCP server to make sure it offers tools, and that the URL points to the MCP endpoint of the server.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Model Context Protocol Client.

The pick implementation configuration step lists implementation.

The user configuration step lists url.
