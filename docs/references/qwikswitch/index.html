QwikSwitch QSUSB

Instructions on how to integrate the QwikSwitch QSUSB Hub into Home Assistant.

Overview

The QwikSwitch QSUSB integration is the main integration to integrate various QwikSwitch devices with Home Assistant. The integration requires the QSUSB Modem device and connects to the QS Mobile application.

Configuration

To use the QwickSwitch integration in your installation, add it to your configuration.yaml file.

Qwikswitch sensors

The sensor configuration is a list of sensors. Depending on the type of sensor, it will be a sensor or binary_sensor.

Switch

The qwikswitch platform allows you to control your QwikSwitch relays as switches from within Home Assistant.

Configuration details

The domain used to identify QwikSwitch QSUSB in Home Assistant is qwikswitch.
