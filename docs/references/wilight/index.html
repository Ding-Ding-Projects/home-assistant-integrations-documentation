WiLight

Instructions on how to integrate WiLight devices into Home Assistant.

Overview

The WiLight integration is to integrate WiLight devices with Home Assistant.

Fan

The WiLight integration allows you to control your Fans from within Home Assistant.

Irrigation

The WiLight integration allows you to control your Irrigation from within Home Assistant. This is exposed via switches in Home Assistant. There are two switch types for Irrigation: watering switch and pause switch. A watering switch can turn on and off the irrigation valve, while the pause switch can disable / enable the action of a watering switch. Triggers activate (turn on) the watering switch (irrigation valve) at the programmed time. The trigger can be set to run on a day of the week or only once (today).

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for WiLight.
