Data updates

The integration polling polls the BSB-LAN device every 12 seconds for state and sensor values, and every 5 minutes for the domestic hot water settings. Each schedule is read at startup and again after Home Assistant writes that schedule.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for BSB-LAN.

The discovery confirm configuration step lists passkey, password, username.

The reauth confirm configuration step lists passkey, password, username.

The reconfigure configuration step lists host, passkey, password, port, username.

The user configuration step lists host, passkey, password, port, username.
