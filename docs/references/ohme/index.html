Ohme

Instructions to configure the Ohme integration into Home Assistant.

Overview

The Ohme integration allows you to connect your Ohme EV charger to Home Assistant.

Tracking energy consumption

The Ohme API does not provide an energy reading. To track cumulative energy usage (kWh) and add your charger to the Energy dashboard, you can use the Integral helper to derive it from the Power sensor.

Automation: Notify when charger status changes

This example sends a notification when the charger leaves the unplugged state.

Entities are shown as unavailable

You may need to power cycle your charger. Please see the manufactuer's guidance for the procedure.

Data updates

This integration fetches data every 30 seconds with the exception of device settings which are fetched every 30 minutes.

Known limitations

The integration does not provide the ability to manage vehicles or routines, which can instead be managed on the manufacturer's app. It also does not provide an energy sensor directly - see Tracking energy consumption for a way to derive one using the Power sensor.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Ohme.

The reauth confirm configuration step lists password.

The reconfigure configuration step lists password.

The user configuration step lists email, password.
