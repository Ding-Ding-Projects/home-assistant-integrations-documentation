Fressnapf Tracker

Instructions on how to integrate Fressnapf GPS Trackers into Home Assistant.

Overview

The Fressnapf Tracker integration allows you to integrate Fressnapf GPS Trackers into Home Assistant.

Entities

The Fressnapf Tracker integration provides the following entities.

Prerequisites

You have to use the mobile app to add the trackers to your Fressnapf Tracker account. The phone number you used to register can then be used to set up the integration.

Defining a custom polling interval

The Fressnapf Tracker polling polls data from the cloud every 15 minutes.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Fressnapf Tracker.

The email configuration step lists email, password.

The reauth confirm configuration step lists email, password, phone_number.

The reauth sms code configuration step lists sms_code.

The reconfigure sms code configuration step lists sms_code.

The sms configuration step lists phone_number.

The sms code configuration step lists sms_code.
