WiZ

Instructions on setting up WiZ within Home Assistant.

Overview

The WiZ integration allows you to control your WiZ lights and smart sockets. The devices are set up through your Wi-Fi network and don't need any additional bridge or gateway.

Connect WiZ devices to your network

To connect a WiZ device to your Wi-Fi network, please follow the instructions in the WiZ app (available for iOS and Android). If you have further questions, please have a look at the WiZ Support Page.

Enable local connectivity

The integration needs to communicate locally with the WiZ device. This setting Allow local communication can be disabled or enabled in WiZ app. This setting should be enabled by default.

Occupancy sensors

The occupancy sensors will only be added once a motion event is detected. Home Assistant can detect the sensors if they turn on at least one device when the room is occupied, and turn off at least one device when the room is not occupied. Sensors that are not linked to a device cannot be detected.

Effect speed

The speed of an effect can be controlled via a number entity. The entity will only be available when an effect has been set that allows the speed to be adjusted.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for WiZ.

The pick device configuration step lists device.

The reconfigure configuration step lists host.

The user configuration step lists host.
