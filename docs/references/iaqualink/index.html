Jandy iAquaLink

Instructions on how to configure Jandy iAquaLink integration.

Overview

The Jandy iAquaLink integration lets you monitor and control supported Jandy pool and spa systems from Home Assistant. Depending on the equipment connected to your controller, you can check water and air temperatures, control auxiliary equipment like pumps and water features, manage compatible pool lights, and adjust supported pool or spa heaters.

Unsupported devices

Other iAquaLink systems are not supported. Equipment that is not exposed in the iAquaLink app or cloud service also cannot be added to Home Assistant.

Prerequisites

1. Create an account and log in using either the iAquaLink app or the iAquaLink website. 2. Add your devices to the account you created in the previous step, typically using their serial numbers.

Examples of automations you can create using the Jandy iAquaLink integration.

Data updates

This integration uses cloud polling to refresh data from your iAquaLink system, like equipment status, sensor readings, and climate values. Home Assistant updates this data approximately every 15 seconds.

Known limitations

Only equipment exposed through the iAquaLink cloud service can be added to Home Assistant. The entities you see depend on the controller model and the pool or spa equipment configured in the iAquaLink app.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Jandy iAquaLink.

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists password, username.

The user configuration step lists password, username.
