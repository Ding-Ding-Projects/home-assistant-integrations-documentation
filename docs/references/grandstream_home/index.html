Grandstream Home

Instructions on how to integrate Grandstream devices with Home Assistant.

Overview

The Grandstream Home integration allows you to integrate Grandstream devices with Home Assistant for monitoring. This integration supports door access control systems (GDS372x, GSC356X).

Supported devices

This integration supports the following Grandstream device types:

GDS/GSC series - door access control systems

Door access control devices with SIP calling capabilities.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Grandstream Home.

The auth configuration step lists password, port, verify_ssl.

The user configuration step lists host.
