Pentair ScreenLogic

Instructions on how to integrate a ScreenLogic gateway within Home Assistant.

Overview

The Pentair ScreenLogic integration allows you to integrate your Pentair IntelliTouch or EasyTouch pool controller with Home Assistant via the Pentair ScreenLogic gateway.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Pentair ScreenLogic.

The gateway entry configuration step lists ip_address, port.

The gateway select configuration step lists selected_gateway.
