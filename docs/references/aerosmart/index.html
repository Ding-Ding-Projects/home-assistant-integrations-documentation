aerosmart

Instructions on how to integrate an aerosmart ventilation and heat-pump system with Home Assistant.

Overview

The aerosmart integration lets you monitor a combined aerosmart ventilation and heat-pump installation. Home Assistant connects locally through a Modbus TCP gateway or a directly connected serial Modbus RTU port, without a cloud service.

Supported devices

The integration supports an aerosmart installation that exposes the expected register map as two Modbus units on one Modbus connection, reached either over TCP or serial RTU:

Supported functionality

The integration provides sensor entities for the complete installation.

Automation: Notify when the CO2 level is high

This automation sends a notification when the measured carbon dioxide level rises above 1000 ppm.

Data updates

The integration polling polls operating values and the controller clock every 60 seconds. It polls filter counters and other slow-changing values every 10 minutes.

Symptom: Setup reports a connection failure

The setup form reports that Home Assistant cannot connect after you submit the connection and unit details.

Resolution

1. For a network setup, confirm that the gateway is powered on and reachable from Home Assistant, then check its host and TCP port. 2. For a serial setup, confirm that the selected serial port and baud rate match the Modbus bus. 3. Check the unit address for both controllers. 4. Stop any other Modbus client temporarily if it shares the same gateway or serial bus.

Symptom: Some or all entities become unavailable

A slow gateway, a busy serial line, or another client can cause a polling cycle to time out. A failure in one subsystem only affects entities from that subsystem.

Symptom: A value does not match the installation

The register map might differ from the map used by the reference installation.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for aerosmart.

The serial configuration step lists baudrate, device, unit_heat_pump, unit_ventilation.

The tcp configuration step lists host, port, unit_heat_pump, unit_ventilation.
