Azure Data Explorer

Setup for Azure Data Explorer integration

Prerequisites

Before you can add Azure Data Explorer to Home Assistant, you need to set up an Azure account, create a Service Principal, create a cluster, and add a database.

Creating a free Azure account

Create a free Azure account. You will be asked for credit card information, but all resources created here are free.

Creating a Service Principal (App registration)

For Home Assistant to authenticate with Azure Data Explorer, it needs a *Service Principal*. 1. To create a Service Principal, follow the guide on Creating Microsoft Entra application registration, steps 1-7. 2. Copy values for later use:

Creating a Free Azure Data Explorer cluster and database

There are two ways of creating an Azure Data Explorer Cluster: Pay as you go (PAYG) or Free. To create a paid cluster, follow the instructions from the Microsoft Quickstart Guide. However, Microsoft has released a free offer, and this guide describes how to set up a free Azure Data Explorer Cluster and database:

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Azure Data Explorer.

The user configuration step lists authority_id, client_id, client_secret, cluster_ingest_uri, database, table, use_queued_ingestion.
