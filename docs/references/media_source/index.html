Media source

Instructions on how to access your media with Home Assistant.

Overview

The Media source integration lets integrations share media with Home Assistant. You can browse this media in the media browser, and play it on supported media players, such as Google Cast devices.

Configuration

Home Assistant sets up this integration automatically. It's part of default_config, and integrations that provide media load it too.

Local media

Your own media files are in your media folder. On Home Assistant Operating System and Home Assistant Container, this folder is /media by default. In the media browser, it's listed as My media.

Using custom or additional media folders

You can add more media folders, for example, from a network storage. For the steps, refer to Adding additional media directories.

Browsing your media

The media browser shows your own media, such as the files in your /media folder. It also shows media from other integrations, such as stations from Radio Browser. To add your own files, refer to Adding your media to Home Assistant.

Playing media from a media source

In an automation or a script, use the Play specified media action. Under Media, select Pick media, and then select the file in the media browser.

Identifying a media source from the media browser

To use a file in YAML, you need its media source ID. The easiest way to find it is to pick the file in the UI, and then look at the YAML.

Symptom: A player is missing from the list of players

You want to open your media on a media player, such as a speaker, but the player isn't in the list of players in the bottom-right corner of the media browser.

Description

The list of players shows Web browser first. After that, it only shows media players that let Home Assistant browse their media. Whether a player supports this depends on its integration. The list also leaves out players whose entity is hidden or disabled.
