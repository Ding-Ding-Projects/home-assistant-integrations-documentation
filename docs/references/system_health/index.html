System Health

System Health integration will report system info and allow you to run system diagnostics.

Overview

The System Health integration provides an API to offer information on the system and its components. It also allows you to run diagnostic tools to diagnose problems.

Configuration details

The domain used to identify System Health in Home Assistant is system_health.
