Electricity Maps

Instructions on how to use the Electricity Maps (formerly known as CO2Signal) data within Home Assistant

Overview

The Electricity Maps integration (formerly known as CO2Signal) queries the Electricity Maps API for the CO2 intensity of a specific region. Data can be collected for your home by using the home location, latitude/longitude, or a zone key.

To configure and use this integration, you need to obtain a free API key from Electricity Maps by activating Home Assistant access on the Electricity Maps Home Assistant page.

Energy Dashboard integration

The Electricity Maps integration is automatically used on the Energy Dashboard when set up. The carbon intensity data appears in the Energy Dashboard as a real-time gauge showing the carbon footprint of your household electricity usage.

Data updates

The integration polling polls data from the Electricity Maps API every 15 minutes by default. The actual update frequency may be limited by your API tier's rate limits.

Symptom: "The given token is invalid" during setup

If you see an invalid token error during setup, your API key may be invalid or expired.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Electricity Maps.

The coordinates configuration step lists location.

The country configuration step lists country_code.

The reauth confirm configuration step lists api_key.

The reconfigure configuration step lists location.

The user configuration step lists api_key, location.
