Rehlko

Support for Rehlko devices (formerly Oncue and Kohler Energy)

Overview

The Rehlko (formerly Kohler Energy Management) integration allows you to monitor the status of your enabled Kohler generator through Home Assistant. This integration replaces the legacy Oncue integration.

Sensors

The sensors exposed by this integration depend on the specific instrumentation installed on your generator and transfer switch. Sensor availability can vary significantly—even between units of the same model.

Data updates

The integration polling polls the Rehlko cloud every 10 minutes.

Removing the integration

This integration follows the standard integration removal process; no extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Rehlko.

The reauth confirm configuration step lists password.

The user configuration step lists email, password.
