Specialized Turbo

Read telemetry from Specialized Turbo e-bikes over Bluetooth Low Energy in Home Assistant.

Overview

The Specialized Turbo integration connects Home Assistant to Specialized Turbo e-bikes over Bluetooth Low Energy. The integration reads battery, motor, ride, and system telemetry from the bike.

Prerequisites

1. Turn on the bike. 2. Make sure that Home Assistant has access to a Bluetooth adapter. 3. If you use an ESPHome Bluetooth proxy, enable active connections on the proxy. 4. Disconnect the Specialized app and other Bluetooth clients from the bike.

Reconfigure an encryption key

You can replace the stored key for an encrypted bike. Use this function after a display replacement or an invalid-key error.

Entities

The Specialized Turbo integration provides 26 sensor entities.

Data updates

The integration keeps an active Bluetooth connection while the bike is awake and in range. The bike sends telemetry changes through Bluetooth notifications.

Move from the custom integration

The built-in integration uses the same domain and entity unique IDs as the custom integration from the Marketplace (formerly known as HACS).

Privacy

The integration can contact Specialized during encrypted bike setup. This request retrieves the wrapped key for the selected bike.

Symptom: The bike is not listed during setup

The bike can be asleep, out of range, or unavailable to the Bluetooth adapter.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Specialized Turbo.

The account configuration step lists email, password.

The manual key configuration step lists wrapped_key.

The user configuration step lists address.
