LibreNMS

Instructions on how to integrate a LibreNMS instance into Home Assistant.

Overview

This integration allows you to add a LibreNMS instance to Home Assistant.

Prerequisites

You need to obtain an API key (token) for your LibreNMS instance.

Data updates

The integration polls data every 60 seconds.

Troubleshooting

When reporting an issue, enable debug logging, restart the integration, and once the issue recurs, disable debug logging again (the debug log download starts automatically). If possible, also download the diagnostics data, and include both the debug log and diagnostics data with your issue report.

Remove the integration

If you no longer use the API key, you can remove it from your LibreNMS instance.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for LibreNMS.

The reauth confirm configuration step lists api_key.

The reconfigure configuration step lists url, verify_ssl.

The user configuration step lists api_key, url, verify_ssl.
