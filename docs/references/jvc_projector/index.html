JVC Projector

Control JVC projectors from Home Assistant, and use their power status, signal information, and picture settings in automations.

Overview

The JVC Projector integration lets you control and automate JVC projectors from Home Assistant. You can turn the projector on and off, send remote commands, change settings such as the input and picture mode, and use the power status and signal information in automations.

Prerequisites

1. Connect the projector's LAN port to the same network as Home Assistant, and note the projector's IP address. 2. Some JVC projectors require a network password before they accept network control. If your projector uses one, have it ready. You set the password in the projector's network settings.

Supported functionality

The JVC Projector integration creates a device for the projector. The device information shows the projector's model code, firmware version, and MAC address. The model code is JVC's internal code for the model, such as B5A2 for the DLA-NZ8.

Data updates

The integration polling polls the projector every 5 seconds while it is on, warming up, or cooling down, and every 10 seconds while it is in standby. The Input select and Light Time sensor are only updated while the projector is on. The other settings and the signal information are only updated while the projector is on and receiving a signal. When the signal is lost, they are cleared until a signal returns.

Symptom: "Failed to connect"

When you set up the integration, the form shows the message "Failed to connect".

Description

Home Assistant cannot reach the projector at the host and port you entered.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for JVC Projector.

The reauth confirm configuration step lists password.

The user configuration step lists host, password, port.
