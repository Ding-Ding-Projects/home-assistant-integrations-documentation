Brother Printer

Instructions on how to integrate a Brother printer into Home Assistant.

The Brother Printer integration allows you to read current data from your local Brother printer.

It provides information about the printer's state, the amount of ink or toner left, and the remaining lifetime of the drum and other parts of the printer. The integration monitors every supported part.

Supported devices

The integration supports Brother printers that expose their status over SNMP. Both ink and laser printers are supported.

Unsupported devices

The following devices are not supported by the integration:

  • MFC-8660DN
  • MFC-8860DN

Prerequisites

The integration reads data from the printer over SNMP, so SNMP must be turned on in the printer.

  1. Open the printer's web interface in a browser, for example http://192.168.5.6.
  2. If the web interface asks for a password, sign in. For some printers, the default password is printed on a sticker on the back of the printer, preceded by Pwd. If there is no password on the sticker, the default password is initpass.
  3. Go to Network > Protocol and turn on SNMP.
  4. For some printers, you also need to select SNMPv3 read-write access and v1/v2c read-only access in the SNMP settings.

Manual configuration steps

If the above My button doesn't work, you can also perform the following steps manually:

  • Browse to your Home Assistant instance.

  • Go to Settings > Devices & services.

  • In the bottom right corner, select the Config flow start button.

  • From the list, select Brother Printer.

  • Follow the instructions on screen to complete the setup.

Brother Printer automation examples

The binary sensors of this integration let you react to printer problems when the integration detects them, for example when the printer jams or runs out of paper. Here is an idea to get you started.

Tip

You don't need to edit YAML to use these examples. Copy a YAML snippet from this page, open the visual automation editor in Home Assistant, and press Ctrl+V (or Cmd+V on Mac). Home Assistant automatically converts the pasted YAML into the visual editor format, whether it's a full automation, a single trigger, a condition, or an action.

Automation: Get notified when the printer jams or runs out of paper

Use the Paper jam and No paper binary sensors to send a notification to your phone when the printer needs attention. Replace the entity IDs in the example with the entity IDs of your printer's binary sensors.

  • Trigger: State changed
    • Target: Your printer's Paper jam and No paper binary sensors
    • To: Problem
  • Action: Send a notification message
    • Target: My Device (notify.my_device)

YAML example for notifying about a paper jam or empty paper tray

Example

automation: | alias: "Notify when the printer jams or runs out of paper" triggers: - trigger: state entity_id: - binary_sensor.hl_l2340d_paper_jam - binary_sensor.hl_l2340d_no_paper to: "on" actions: - action: notify.send_message target: entity_id: notify.my_device data: message: "The printer needs attention: paper jam or out of paper."

Data updates

The Brother Printer integration polling polls data from the printer every 30 seconds by default.

Known limitations

Some very old Brother printers use a different data format and are not supported. The integration shows a message about this during setup.

Troubleshooting

The printer is unavailable after changing the SNMP community

Symptom: The printer becomes unavailable after you change the SNMP community

After you change the SNMP community in the printer's web interface, the printer's entities become unavailable in Home Assistant.

Description

The integration uses the SNMP community stored in its configuration. When the community on the printer changes, Home Assistant can no longer read data from the printer until you update the configuration.

Resolution

  1. Go to Settings > Devices & services.
  2. Select Brother Printer.
  3. Select the three dots menu next to the entry, and select Reconfigure.
  4. Enter the new SNMP community under Additional settings and submit the form.

The integration reports communication or data update problems

Symptom: The integration reports problems with communication or data updates

The printer's entities become unavailable, or Settings > System > Logs contains messages about connecting to the printer or retrieving data from it.

Description

Home Assistant cannot reach the printer over SNMP, or the printer does not answer SNMP requests.

Resolution

  1. Check that the printer is turned on and reachable on your local network.
  2. In the printer's web interface, check that SNMP is turned on.
  3. In the printer's web interface, check that SNMPv3 read-write access and v1/v2c read-only access is selected, if this option is available.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

To remove an integration instance from Home Assistant

  1. Go to Settings > Devices & services and select the integration card.
  2. Next to the entry you want to remove, select the three dots menu. Then, select Delete.
    • Depending on the integration, the entries are listed under one of the following headings:
      • Devices
      • Hubs
      • Services
      • Integration entries
  3. To confirm, select Delete.
    • Home Assistant also deletes the devices and entities of the entry.
  4. If Home Assistant asks you to restart, restart Home Assistant.
  5. If Home Assistant asks whether to also delete the application credentials, select Remove or Keep.
    • If you keep them, Home Assistant uses them automatically when you add the integration again.
    • To delete them later, refer to Deleting application credentials.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Brother Printer.

The reconfigure configuration step lists host.

The user configuration step lists host, type.

The zeroconf confirm configuration step lists type.
