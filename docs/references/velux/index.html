Velux

Instructions on how to integrate the Velux KLF 200 with Home Assistant.

Overview

The Velux integration for Home Assistant allows you to connect to a Velux KLF 200 interface so you can control io-homecontrol devices, such as windows, blinds, lights, and switches. The integration lets you start scenes configured on the KLF 200.

Prerequisites

1. Make sure you have the password for your gateway's wireless access point.

Switch

On/off switches connected to the KLF 200 are exposed as switch entities.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Velux.

The discovery confirm configuration step lists password.

The reauth confirm configuration step lists password.

The user configuration step lists host, password.
