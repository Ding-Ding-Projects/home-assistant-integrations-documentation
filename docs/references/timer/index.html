Timer

Instructions on how to integrate timers into Home Assistant.

Overview

The Timer integration lets you create and manage countdown timers in Home Assistant.

Configuration

If you removed default_config: from your configuration.yaml, add timer: first before creating timers from the UI.

Configuration options

When you create or edit a timer from the UI, the following options are available.

Supported functionality

The Timer integration provides timer entities that you can use in dashboards, scripts, and automations.

Showing when a timer finishes on a dashboard

By default, a tile card or badge for a timer shows the remaining time. To also show the time when the timer finishes:

Automation: turn off the bathroom fan when the timer finishes

Use a timer to keep the fan running for a fixed amount of time after a shower.

Automation: send a reminder when only five minutes remain

Get a reminder shortly before a timer finishes, like when laundry or cooking time is almost done.

Removing the integration

If you configured a timer in YAML, remove it from your configuration.yaml file and reload or restart Home Assistant.

Configuration details

The domain used to identify Timer in Home Assistant is timer.
