Aqvify

Instructions on how to set up Aqvify devices within Home Assistant.

Overview

The Aqvify integration allows users to integrate their Aqvify water well and tank sensors using the official public API.

Supported functionality

The Aqvify integration supports the following entities:

Sensors

There is currently support for sensors measuring the well water level from different perspectives. Please refer to Aqvify's documentation for the exact interpretation of the values.

Data updates

The integration polls the API for device data every 5 minutes, and for the previous hour's aggregated values every 30 minutes. These polling intervals are designed to work within the rate limits of Aqvify APIs while providing timely updates.

The installation went smooth but I can't see my devices

Make sure the devices are visible and controllable via the manufacturer's app. If they are not, check the device's power and network connection and refer to manufacturer's documentation.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Aqvify.

The reauth confirm configuration step lists api_key.

The user configuration step lists api_key.
