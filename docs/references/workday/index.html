Integration reference

Workday

Check whether today, or a day you choose, is a workday, based on your workdays and the public holidays of your country.

Overview

The Workday integration indicates whether a day is a workday or not. By default, it checks today. With the Offset option, it can check a later or earlier day instead, such as tomorrow.

Setup

Check the country list for available subdivisions (such as provinces, states and territories) for each country.

Entities

The Workday integration provides the following entities.

Binary sensor

The binary sensor is On when the checked day is a workday, and Off when it's not. The checked day is today, shifted by the number of days you set in Offset. The sensor updates at midnight.

Calendar

The calendar shows each workday of this year and next year as an all-day event. Like the binary sensor, it takes Offset into account: with an Offset of 1, an event on a day means that the next day is a workday.

Automation: turn on the heater on workdays

This automation turns on the heater at 08:00, but only on workdays.

Data fetching and limitations

Data is loaded completely offline from the holidays library and there is no data fetching.

Troubleshooting

The integration completely relies on the information provided by the holidays library.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Workday.

The options configuration step lists add_holidays, category, days_offset, excludes, language, province, remove_holidays, workdays.

The user configuration step lists country, name.
