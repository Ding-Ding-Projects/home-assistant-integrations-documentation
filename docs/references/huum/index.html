Huum

Instructions on how to integrate Huum saunas into Home Assistant.

Overview

The Huum integration lets you monitor and control your Huum sauna from Home Assistant. Huum manufactures electric sauna heaters with smart connectivity, allowing you to adjust the temperature and, when your sauna controller supports these features, control the light and manage the steamer humidity level right from your dashboard.

Data updates

The Huum integration polling polls the Huum cloud service every 30 seconds for status updates.

Troubleshooting

1. Ensure your Home Assistant instance has an active internet connection. 2. Double-check that you entered the correct username and password. Try logging in to the Huum app to confirm. 3. The Huum cloud service may occasionally be unavailable. Wait a few minutes and try again.

Removing the integration

This integration follows standard integration removal.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Huum.

The reauth confirm configuration step lists password.

The reconfigure configuration step lists password, username.

The user configuration step lists password, username.
