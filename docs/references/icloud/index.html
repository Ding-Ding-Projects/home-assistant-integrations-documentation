Apple iCloud

Instructions on how to use iCloud to track devices in Home Assistant.

Overview

The Apple iCloud integration allows you to detect presence using the iCloud service. iCloud allows users to track their location on iOS devices.

Two-factor authentication

Use your regular Apple Account password when setting up the integration. If Apple requires two-factor authentication, Home Assistant asks you to enter the six-digit verification code displayed on one of your trusted Apple devices or sent to your trusted phone number.

In case of troubleshooting

Delete the integration's configuration (most likely in /config/.storage/icloud), then retry.

Configuration options

The integration provides the following configuration options:

Binary sensor

The iCloud integration adds the following binary sensors for each device on your Apple Account. Some binary sensors are only added if the device supports them.

Button

The iCloud integration adds a button for each device that can play a sound.

Calendar

The iCloud integration adds a calendar entity for each of your iCloud calendars, showing the event in progress or the next one due. Calendars are read-only, so events cannot be created or edited from Home Assistant.

Device tracker

The iCloud integration will track available devices on your iCloud account.

Sensor

The iCloud integration adds the following sensors for each device on your Apple Account. Some sensors are only added if the device supports them.

To-do list

The iCloud integration adds a to-do list entity for each of your Apple Reminders lists. You can add, edit, complete, and delete reminders, including their due date and notes. Changes sync back to your Apple devices. By default, only unfinished reminders are fetched. To also fetch completed reminders, enable Include completed reminders in the configuration options.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Apple iCloud.

The reauth confirm configuration step lists password, username.

The trusted device configuration step lists trusted_device.

The user configuration step lists include_completed, password, username, with_family.

The verification code configuration step lists request_new_code, verification_code.
