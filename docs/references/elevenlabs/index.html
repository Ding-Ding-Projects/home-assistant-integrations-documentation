ElevenLabs

Instructions on how to set up ElevenLabs text-to-speech with Home Assistant.

Overview

The ElevenLabs integrations adds support for ElevenLabs as text-to-speech to read a text with natural sounding voices and speech-to-text to convert speech into text.

Text-to-speech

For an overview of which languages can be used, check the complete list of supported languages.

Speech-to-text

An overview of supported languages is available at complete list of supported languages.

Using ElevenLabs text-to-speech in automations

To use ElevenLabs text-to-speech from an automation or a script, use the Speak action and select your ElevenLabs text-to-speech entity as the target. The entity is named ElevenLabs by default.

Configuration

Below settings can be configured in the options of the integration and in the options parameter of the tts.speak service.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for ElevenLabs.

The reauth confirm configuration step lists api_key.

The user configuration step lists api_key.
