iNELS

Instructions on how to integrate iNELS with Home Assistant.

Overview

The iNELS integration allows you to control and monitor the devices connected to your control units (BUS or eLAN).

Removing the integration

This integration follows standard integration removal.

To remove a setting from eLANRF

1. Launch the IDM application. 2. Select Configuration of the central unit from the menu. 3. Select MQTT settings then choose Not Connect in the mode options and click Save to CU.

To remove a setting from CU3

1. Open the eLANRF web interface. 2. Go to Settings and disable MQTT under MQTT connection.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for iNELS.
