LIFX Cloud

Instructions on using native LIFX scenes with Home Assistant.

Overview

The LIFX Cloud integration allows you to activate the scenes that LIFX smartphone apps store in the LIFX cloud.

Getting an API token

You create your API token on the LIFX website: 1. Sign in to the LIFX Cloud 2. Click on your email address and select _Personal Access Tokens_ 3. Now click _Generate New Token_ 4. Enter a meaningful label, such as 'Home Assistant' 5. Click _Generate_ 6. Copy the token that now appears 7. Paste the token into the Home Assistant configuration file

Configuration details

The domain used to identify LIFX Cloud in Home Assistant is lifx_cloud.
