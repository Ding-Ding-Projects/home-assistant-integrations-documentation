Configuring a filter

By default, no entity will be excluded. To limit which entities are exposed to Splunk, you can use the filter parameter.

Removing the integration

1. Remove the splunk: section from your configuration.yaml file. 2. Restart Home Assistant.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Splunk.

The reauth confirm configuration step lists token.

The reconfigure configuration step lists host, name, port, ssl, token, verify_ssl.

The user configuration step lists host, name, port, ssl, token, verify_ssl.
