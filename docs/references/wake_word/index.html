Wake-word detection

Detect a wake word in streaming audio.

Overview

A wake-word-detection entity allows other integrations or applications to detect wake words in streaming audio.

Wake word detection states

The state of a wake word detection entity is a timestamp showing the date and time when the wake word was last detected. Home Assistant stores the timestamp in UTC, for example, 2026-01-01T12:00:00.123456+00:00. The Home Assistant interface shows it in your local date and time format.

Configuration details

The domain used to identify Wake-word detection in Home Assistant is wake_word.
