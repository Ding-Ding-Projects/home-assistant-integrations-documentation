Integration reference

ecosmart

Instructions on how to integrate ecosmart wholesale electricity prices into Home Assistant.

Overview

The ecosmart integration brings that price into Home Assistant, so you can move consumption into the cheap half hours.

Prerequisites

You need an ecosmart electricity account with at least one connected property, and an API key that you create yourself.

Replacing the API key

Creating a new key in the ecosmart app disables the one Home Assistant is using. You do not need to remove the integration. Give Home Assistant the new key in either of these ways:

Data updates

The integration polling polls the ecosmart API for each grid exit point rather than for each ICP, so several properties behind the same substation share one request.

Price availability

The sensor does not guess. When it does not have a value it can stand behind, it reports unavailable, and your automations should handle that.

Energy dashboard costs

The spot price is in cents per kWh, and it is the wholesale price only. Don't use it as the electricity price in the Energy dashboard. The dashboard would treat the value as dollars per kWh, so costs would come out 100 times too high, and they would still leave out line charges, losses, and fees.

Adding or removing a property

New properties on your ecosmart account are added when you reload the integration. A property that leaves your account keeps its device in Home Assistant until you remove the integration and add it again.

Symptom: The API key has no connection points

During setup, the form reports that the key has no connection points yet. The key is valid, but no property is attached to it. This is normal while a switch to ecosmart is still in progress.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for ecosmart.

The reauth confirm configuration step lists api_key.

The reconfigure configuration step lists api_key.

The user configuration step lists api_key.
