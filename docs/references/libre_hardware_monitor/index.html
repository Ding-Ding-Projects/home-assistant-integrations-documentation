Libre Hardware Monitor

Instructions on how to integrate Libre Hardware Monitor within Home Assistant.

Overview

The Libre Hardware Monitor integration uses your Libre Hardware Monitor installation as a source for sensors to display that system information in Home Assistant.

Supported devices

Any hardware that Libre Hardware Monitor detects is supported, such as CPUs, GPUs, motherboards, memory, storage drives, and network adapters.

Data updates

The integration polling polls data from Libre Hardware Monitor every 10 seconds.

Libre Hardware Monitor version is not supported

During integration setup, the form might show this message:

Integration stops working

Make sure the IP address of the system you are monitoring has not changed. Ideally, set a static IP address for that system in your router.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Libre Hardware Monitor.

The reauth confirm configuration step lists password, username.

The reconfigure configuration step lists host, port.

The user configuration step lists host, port.
