Ambient Weather Station

How to integrate Ambient Weather station within Home Assistant.

Overview

The Ambient Weather Station integration retrieves local weather information via personal weather stations from Ambient Weather.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Ambient Weather Station.

The user configuration step lists api_key, app_key.
