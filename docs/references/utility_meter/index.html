Utility Meter

Instructions on how to integrate the Utility Meter into Home Assistant.

Overview

The Utility Meter integration provides functionality to track consumptions of various utilities (e.g., energy, gas, water, heating).

Advanced configuration for DSMR users

When using the DSMR integration to get data from the utility meter, each tariff (peak and off-peak) has a separate sensor. Additionally, there is a separate sensor for gas consumption. The meter switches automatically between tariffs, so an automation is not necessary in this case. But, you do have to set up a few more instances of the utility_meter integration.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Create helper, and search for Utility Meter.

The user configuration step lists always_available, cycle, delta_values, name, net_consumption, offset, periodically_resetting, source, tariffs.
