Numato USB GPIO Expander

Instructions on how to integrate a Numato GPIO expander into Home Assistant.

Overview

The Numato USB GPIO Expander integration is the base for all related GPIO platforms of the

Binary sensor

The numato binary_sensor platform allows you to operate the GPIOs of your

Sensor

The numato sensor platform allows you to operate some GPIOs of your USB GPIO expander in analog input mode.

Switch

The numato switch platform allows you to operate the GPIOs of your

IO ports

The IO port numbers used in this configuration refer to the port numbers printed on the PCB. Note that the Sensor platform can be configured on ports 1-7 only. These are the only ports on the 32 port device equipped with an ADC.

Device IDs

This integration uses an internal device ID to identify the device, which is _not_ the Linux device path. The Linux device path (e.g., /dev/ttyACM0) can change, for example, when you disconnect and re-connect the device or if you connect the device to a different USB port.

Configure the Device ID

Configure your Numato device's ID with the following steps. Though you can use any terminal emulator to connect to and communicate with your device, the following steps are based on using _GNU Screen_. On a Debian or Ubuntu-based OS install _Screen_ like sudo apt install screen.

Configuration details

The domain used to identify Numato USB GPIO Expander in Home Assistant is numato.
