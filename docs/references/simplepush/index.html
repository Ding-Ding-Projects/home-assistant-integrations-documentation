Simplepush

Instructions on how to add Simplepush notifications to Home Assistant.

Overview

The Simplepush integration uses Simplepush to deliver notifications from Home Assistant to your Android and iOS device. Unlike similar apps the Simplepush app requires no registration and supports end-to-end encryption.

Notifications

Simplepush can send a notification by calling the notify action.

Examples

Send a notification with a title and event.

Configuration details

In Home Assistant, open Settings → Devices & services, choose Add integration, and search for Simplepush.

The user configuration step lists device_key, event, name, password, salt.
