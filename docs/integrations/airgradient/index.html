Using AirGradient

Overview

The AirGradient integration will fetch data from your AirGradient devices. AirGradient creates indoor, outdoor, and portable air quality monitors that enable you to know if the air quality is healthy or not. They measure metrics such as PM2.5, CO2, TVOCs, and NOx. Both the software and hardware are open-source, allowing you to customize or extend the device functionality.

Works with Home Assistant certified devices

Devices using the legacy local API require firmware version 3.1.1 or later to be set up or discovered by Home Assistant. This minimum version does not apply to the portable monitor, AirGradient Go.

Updates

The AirGradient integration provides an update entity that checks for firmware updates for your AirGradient device. To install the update, the device needs to be rebooted.

Data updates

This integration uses local polling, meaning it checks for changes to all entities by regularly communicating with the AirGradient device.

Actions

This integration does not provide additional actions. All actions available for this integration are provided by their respective entities.
