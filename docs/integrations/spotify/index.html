Using Spotify

Overview

The Spotify integration lets you control your Spotify account playback and browse the Spotify media library from Home Assistant.

Create a Spotify application

For Home Assistant to communicate with Spotify, we need to create an application at Spotify using the Spotify Developer website. This will provide you with the Spotify application credentials Home Assistant needs to allow you to log in with your Spotify account.

Data updates

The integration polling polls at least every 30 seconds. If the track that is playing ends in less than 30 seconds, the integration will poll again after the track has ended to update the state again.

Using multiple Spotify accounts

This integration supports multiple Spotify accounts at once. You don't need to create another Spotify application in the Spotify Developer Portal. Multiple Spotify accounts can be linked to a _single_ Spotify application.

Selecting output source

To play media Spotify first needs a device selected for audio output known as the source.
