Using GIOŚ

Overview

The GIOŚ integration uses the GIOŚ web service of the Polish Chief Inspectorate of Environmental Protection (Główny Inspektorat Ochrony Środowiska) as a source for air quality data for your location. The integration provides the current pollutant concentrations and air quality indices measured by a selected measuring station in Poland.

Supported functionality

The GIOŚ integration provides the following entities. Which entities are created depends on the pollutants measured by the selected measuring station.

Sensors

The index sensors become unavailable when GIOŚ does not publish an index for the related pollutant.

Data updates

The GIOŚ integration polling polls data from the GIOŚ web service every 30 minutes. The GIOŚ terms of service allow downloading data no more than twice an hour, so this interval cannot be changed.

Symptom: "Failed to connect"

When you try to set up the integration, Home Assistant shows the message "Failed to connect", or the list of measuring stations does not load.

Description

Home Assistant cannot reach the GIOŚ web service, or the web service does not respond in time.

Resolution

1. Check that Home Assistant has a working internet connection. 2. Check whether the GIOŚ website is available. The web service may be temporarily down for maintenance. 3. Try again later.

Symptom: "Invalid sensors' data for this measuring station."

When you select a measuring station, Home Assistant shows the message "Invalid sensors' data for this measuring station."
