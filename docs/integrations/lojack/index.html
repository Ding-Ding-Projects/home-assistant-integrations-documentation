Using LoJack

Overview

The LoJack integration connects Home Assistant to vehicles equipped with LoJack by Spireon GPS tracking hardware. After you authenticate with your Spireon/LoJack account credentials, the integration automatically discovers every vehicle registered to your account and creates a device for each one, with a device tracker entity that shows the vehicle's current or last known GPS location on the map.

Entities

The LoJack integration provides the following entities for each vehicle.

Device tracker

Each vehicle gets a device tracker entity named after the vehicle. It uses GPS as its source type and reports home, not_home, or a zone name based on the vehicle's GPS coordinates.

Sensors

Each vehicle also gets the following sensors. For example, sensor.2021_toyota_camry_odometer.

Data updates

The LoJack integration polling polls data from the Spireon cloud API every 5 minutes by default. Each poll retrieves the latest vehicle data (location and telemetry) cached on the Spireon server. It does _not_ command the vehicle's hardware to obtain a new GPS fix. The server-side cache is updated whenever the vehicle's LoJack hardware periodically reports in (the reporting interval is determined by the LoJack hardware and firmware and is not configurable).

Symptom: "Failed to connect to LoJack servers"

When trying to set up or use the integration, you see a "Failed to connect to LoJack servers" error.
