Using OpenEnergyMonitor WiFi Thermostat

Overview

This integration supports the ESP8266 based "WiFi MQTT Relay / Thermostat" sold by OpenEnergyMonitor (archived page, no longer for sale). The underlying library only supports this single relay variant of the original device.
