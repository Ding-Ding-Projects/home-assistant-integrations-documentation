Using Volkszaehler

Overview

The Volkszaehler integration is consuming the system information provided by the Volkszaehler API.

Migrating from YAML configuration

If you previously configured this integration in configuration.yaml, the configuration is imported automatically when Home Assistant starts. A repair issue is created to remind you that YAML configuration is deprecated.
