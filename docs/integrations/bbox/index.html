Using Bbox

Overview

The Bbox integration uses the Bbox Modem Router from the French Internet provider Bouygues Telecom. Sensors are mainly bandwidth measures.

Presence detection

The bbox integration offers presence detection by looking at connected devices to a Bbox based router from Bouygues, which is one of the main Internet provider in France.
