    Using Folder

    Overview

    The Folder integration monitors a folder on the system running Home Assistant. It creates a sensor that shows the total size of the files in that folder, so you can, for example, get notified when a backup or recordings folder grows too large.

    Prerequisites

    The folder you want to monitor must be in the list of folders Home Assistant is allowed to access. The www folder inside your configuration folder and your media folders are allowed by default. For any other folder, add it to allowlist_external_dirs and restart Home Assistant before you add the integration.

    Supported functionality

    Each folder you add appears as a service named after the folder. For example, /media/recordings appears as recordings.

    Sensors

    The sensor also has the following attributes:

    Data updates

    The integration checks the folder every minute.

    Symptom: "Configured path is not in allowlist"

    When adding the integration, the form shows the message "Configured path is not in allowlist".

    Description

    Home Assistant is not allowed to access the folder you entered.

    Resolution

    1. Add the folder to allowlist_external_dirs. 2. Restart Home Assistant. 3. Add the integration again.

    Symptom: "Configured path is not a directory" or "Configured path is not readable"

    When adding the integration, the form shows one of these messages.

    Removing the integration

    This integration follows standard integration removal. No extra steps are required.
