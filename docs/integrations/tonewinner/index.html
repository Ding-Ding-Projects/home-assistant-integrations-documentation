Using Tonewinner

Overview

The Tonewinner integration allows you to control Tonewinner AV processors, receivers, and amps from Home Assistant over an RS-232 serial connection.

Supported devices

The integration is known to work with the AT-500, but should work with other Tonewinner devices as well.

Change the serial port

To connect the receiver to a different serial port later, select Reconfigure on the integration page and choose the new port.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
