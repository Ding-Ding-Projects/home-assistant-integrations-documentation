Using Vogel's MotionMount

Overview

The Vogel's MotionMount integration allows you to control the position of your TVM 7675 Pro SIGNATURE MotionMount from Vogel's.

Removing the integration

This integration follows standard integration removal. No extra steps are required.

Data updates

The MotionMount pushes new data to the integration. The only exception is the presets. Changes to the presets are polling polled, by default every 60 seconds.

Known limitations

The integration does not provide the ability to configure the MotionMount. All settings, including configuring presets, should be done via the MotionMount app.

Unsupported devices

The following devices are *not* supported:

Can't connect to device

1. Make sure the device is powered on. 2. Make sure the device is connected to the same network as Home Assistant. 3. Make sure the IP address of the MotionMount is configured correctly.
