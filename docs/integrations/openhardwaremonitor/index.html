Using Open Hardware Monitor

Overview

The Open Hardware Monitor integration uses your Open Hardware Monitor installation as a source for sensors that will display system information.

Setup

OpenHardwareMonitor must be running on the host, with "Remote web server" active. You also need to open inbound port (TCP 8085) on the host..
