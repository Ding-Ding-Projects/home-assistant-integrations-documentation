Using qBittorrent

Overview

The qBittorrent integration allows you to monitor your downloads with qBittorrent from within Home Assistant and setup automations based on the information. You can control the alternative speed via the Alternative speed switch.

Setup

This sensor requires the qBittorrent Web UI enabled. The official reference describes how to set up the Web UI.
