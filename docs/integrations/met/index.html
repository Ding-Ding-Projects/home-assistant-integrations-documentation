Using Meteorologisk institutt (Met.no)

Overview

The Meteorologisk institutt (Met.no) integration uses the Met.no web service to retrieve meteorological data for your location. The Norwegian Meteorological Institute and NRK provide the weather forecast. The service is free and does not require an API key.

Supported functionality

The integration creates one weather entity per configured location. Each entity provides the current weather, a daily forecast, and an hourly forecast.

Data updates

The integration polling polls weather data every 55 to 65 minutes. The polling interval is randomized to spread load across the Met.no API.

Known limitations

The integration uses the free Met.no public API. Usage is subject to the Met.no terms of service, which include fair-use policies and attribution requirements.

Removing the integration

This integration follows standard integration removal.
