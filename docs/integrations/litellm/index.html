Using LiteLLM

Overview

The LiteLLM integration allows you to use a LiteLLM proxy as a conversation agent or speech-to-text service in Home Assistant.

Adding a conversation agent

Adding a speech-to-text service

The service appears as a speech-to-text entity named after the model. Select it in an Assist pipeline. Home Assistant sends the pipeline language without its region. For example, en-US is sent as en.

Supported functionality

For each conversation agent you add, you can use it in Assist like any other conversation agent. Speech-to-text entities can be selected in an Assist pipeline.

Removing the integration

This integration follows standard integration removal, no extra steps are required.
