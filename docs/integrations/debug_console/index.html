    Using Debug console

    Overview

    The Debug console integration adds a Python console to Home Assistant, much like the console in the developer tools of a web browser. You can run Python code inside your running Home Assistant, with full access to its live internals.

    Configuration

    To enable the debug console, add the following to your configuration.yaml file, and restart Home Assistant afterwards:

    Supported functionality

    Variables and imports are kept per browser tab, also when you reload the page. Going to another page and back keeps what the console showed as well; reloading the page starts with an empty console. A session is removed 30 minutes after its browser tab disconnected, and when Home Assistant restarts.

    Disabling the debug console

    To disable the debug console, remove debug_console: from your configuration.yaml file, and restart Home Assistant.
