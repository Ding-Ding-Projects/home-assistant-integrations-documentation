Troubleshooting

For troubleshooting or when reporting an issue, please enable debug logging and restart the integration. As soon as the issue reoccurs stop the debug logging, which will trigger the download of the debug log file. Enabling debug logging has a slight performance impact on the system and is not recommended for long-term use.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
