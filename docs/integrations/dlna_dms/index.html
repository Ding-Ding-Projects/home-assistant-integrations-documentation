Using DLNA Digital Media Server

Overview

The DLNA Digital Media Server integration allows you to browse and play media from a DLNA Digital Media Server. Configured DMS devices act as a Media Source and can be browsed in the Media panel.

Media source URIs

URIs generated while browsing will look like the Object ID form above. However, all three forms will work with the media_player.play_media action.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
