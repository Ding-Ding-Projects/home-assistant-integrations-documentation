Using LG TV via Serial

Overview

The LG TV via Serial integration lets you control LG TVs by connecting to their RS-232 serial port. Because Home Assistant talks straight to the TV, control is local, fast, and works on TVs without smart features or a network connection.

Data updates

LG TVs do not report changes on their own over RS-232, so Home Assistant polling polls the TV every 5 seconds for its power state, input source, volume, and mute state. Changes made with the TV's own remote are picked up at the next poll.

If the serial connection is lost, the entity becomes unavailable and Home Assistant automatically reconnects. Check the cable and, for network serial proxies, the network connection between Home Assistant and the proxy.
