Using Epion

Overview

Integrates Epion Air sensors into Home Assistant.

Prerequisites

1. Log in to Epion. 2. Select Integrations in the left menu. 3. To create a new token, if you don't see one already, select Generate new Token. 4. Copy your generated token. The token is a set of alphanumeric characters separated by hyphens. It starts with "a/".
