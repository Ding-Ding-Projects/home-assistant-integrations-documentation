Using Bitcoin

Overview

The Bitcoin integration shows you details about the Bitcoin network, such as the current exchange rate, the network hash rate, and how busy the network has been over the last 24 hours. The data comes from the public blockchain.com API, so you do not need an account or an API key.

Supported functionality

The Bitcoin integration provides the following entities. All of them are created and filled from the same two API calls. If you only need a few, hide or disable the others in the entity settings.

Sensors

Two names are used twice. Trade volume and Miners revenue each exist once in BTC and once in USD, so one of each pair gets a _2 suffix in its entity ID. When you set Bitcoin up from the UI, sensor.trade_volume is the BTC one and sensor.trade_volume_2 the USD one, while sensor.miners_revenue is the USD one and sensor.miners_revenue_2 the BTC one. If your setup was imported from YAML, the sensors you already had keep their entity IDs, so a pair can be the other way round.

Data updates

The Bitcoin integration polling polls blockchain.com every 5 minutes. One poll refreshes every entity. This interval is not configurable.

Known limitations

Both Miners revenue sensors report 0, and Total fees reports a negative value. These numbers come straight from the blockchain.com statistics API, which currently returns them incorrectly.

Troubleshooting

If no tip here resolves your issue, feel free to open a bug and make sure to include the debug logs.

Symptom: "Failed to connect"

When you try to add the integration, the form shows the message "Failed to connect".

Description

Home Assistant asks blockchain.com which currencies it quotes before it shows you the form. If that request does not succeed, there is nothing to offer you in the currency list, so the setup stops.
