Using Honeywell String Lights

Overview

The Honeywell String Lights integration lets you control a Honeywell radio frequency (RF) remote-controlled string light set from Home Assistant.

Prerequisites

The transmitter must support 433.92&nbsp;MHz OOK transmissions. For example, you can use an ESPHome device with an OOK transmitter.

Assumed state

Because RF transmission is a one-way broadcast, Home Assistant cannot confirm whether the lights actually turned on or off. The integration therefore uses the assumed state pattern: the state is the last state Home Assistant set, and it is restored across restarts.

Supported devices

The integration has been tested with the Honeywell String Lights sold with a 433.92&nbsp;MHz OOK remote.

Removing the integration

This integration follows standard integration removal.
