Using Ollama

Overview

The Ollama integration lets you run AI locally, on your own hardware. Ollama is a server that runs AI models on a computer in your home, instead of in a cloud service. The integration connects Home Assistant to your Ollama server and adds conversation agents and AI tasks that use its models.

Prerequisites

1. Install the Ollama server on a computer in your network. This computer runs the AI models. Ollama is available for macOS, Linux, and Windows. For the steps, refer to the Ollama download instructions. 2. Make the Ollama server accessible over your network, so that Home Assistant can reach it. For the steps, refer to How can I expose Ollama on my network? in the Ollama FAQ.

Configuration options

The integration adds conversation agents and AI tasks as separate entries on the integration page. When you set up the integration, it doesn't add any of them yet.

Setting up an Ollama assistant with Device control

With the Device control set of AI tools, an Ollama conversation agent can control your devices, tell you their state, and run your exposed scripts. For details, refer to Sets of AI tools. It can only reach the entities that you expose to Assist.
