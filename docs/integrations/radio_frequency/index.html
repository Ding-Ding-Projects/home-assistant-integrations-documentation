    Using Radio frequency

    Overview

    The Radio Frequency integration allows you to use Home Assistant to send commands to radio frequency-controlled devices, or to receive signals from radio frequency remotes. The integration acts as an abstraction layer between the following components:

    Radio frequency states

    A radio frequency entity has no on or off state. Its state is a timestamp showing when the entity was last active:

    Device class

    The device class tells Home Assistant whether a radio frequency entity is a transmitter or a receiver. Home Assistant uses the device class to choose the icon and the default name.

    List of available device classes

    Each item shows the name you see in the Home Assistant interface, followed by the device class as Home Assistant stores it.
