    Using Device automation

    Overview

    There is no device automation-specific configuration. Instead, device automations are configured as part of regular automations.

    Device trigger

    The Device trigger starts an automation when something happens to a device, such as a button press on a remote. In most cases, you don't need it. Use a purpose-specific trigger instead, such as Light turned on. For more information on the difference, refer to How the Device trigger differs from other triggers.

    Using device automations in YAML

    If you need YAML for an automation that is not managed in the UI, create the trigger in the visual automation editor first, then copy the YAML from the trigger. For examples, refer to the Device trigger page.
