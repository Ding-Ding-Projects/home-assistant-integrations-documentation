Using TechnoVE

Overview

The TechnoVE integration lets you monitor and control your TechnoVE smart EV charging station directly from Home Assistant using the station's local API. No cloud account or internet connection is required. Everything communicates over your local network.

Supported devices

The integration supports all Wi-Fi enabled EV charging stations released by the TechnoVE brand.

Data updates

The TechnoVE integration polling polls data from the charging station every 5 seconds over the local network. This frequent polling interval ensures that status changes (such as plugging in or unplugging the vehicle) are reflected promptly in Home Assistant.
