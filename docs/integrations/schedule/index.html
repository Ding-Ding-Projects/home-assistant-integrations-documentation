    Using Schedule

    Overview

    The Schedule integration lets you create a weekly schedule entity in Home Assistant from time blocks with defined start and end times. The schedule is active when a time block starts and becomes inactive when it ends, so you can use it as a trigger or condition in automations and scripts.

    Attributes

    A schedule entity exports state attributes that can be useful in automations and templates.

    Behavior at block boundaries

    Time blocks use an inclusive start and an exclusive end. A block from 09:00 to 12:00 is active from 09:00:00.000 up to but not including 12:00:00.000.
