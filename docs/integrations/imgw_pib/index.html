Using IMGW-PIB

Overview

The IMGW-PIB integration uses hydrological data from the Institute of Meteorology and Water Management - National Research Institute to present information about rivers and water reservoirs in Poland.

Supported functionality

IMGW-PIB automation examples

Automation: Create a hydrological alert notification

Use the Hydrological alert sensor to create a persistent notification with the content and probability of a hydrological alert. Replace the entity ID in the example with the entity ID of your station's Hydrological alert sensor.

Data updates

The IMGW-PIB integration polling polls data from the IMGW-PIB API every 30 minutes by default.

Description

Home Assistant cannot reach the IMGW-PIB API, or the API does not return data for the selected hydrological station.

Resolution

1. Check that Home Assistant has a working internet connection. 2. Wait for the next data update. The integration retries automatically every 30 minutes, and the entities become available again when the IMGW-PIB API returns data.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
