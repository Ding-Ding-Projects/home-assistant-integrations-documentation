Using AirTouch 5

Overview

The AirTouch 5 integration allows you to control ducted air conditioning systems that are using the AirTouch 5 controller.

Climate

The integration will create a climate entity for each AC unit and each zone.

Cover

Each zone has a cover entity to represent the state of the damper.
