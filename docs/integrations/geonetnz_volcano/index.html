Using GeoNet NZ Volcano

Overview

The GeoNet NZ Volcano integration lets you use a GeoJSON feed provided by New Zealand's GeoNet with information about volcanoes in the New Zealand region. It shows information of those volcanoes filtered by distance to Home Assistant's location.
