Using WLED

Overview

implementation of an ESP8266/ESP32 webserver to control NeoPixel LEDs (like WS2812B, WS2811, SK6812, and similar) and SPI based chipsets (like WS2801 and APA102).

Prerequisites

This integration requires a WLED device running WLED 0.14.0 or newer.

Supported functionality

The WLED integration provides the following entities.

Lights

This integration adds the WLED device as a light in Home Assistant. Home Assistant treats every segment of the LED strip as a separate light

Using WLED segments

WLED can split a single LED strip into multiple segments. These segments can be controlled separately in WLED and in Home Assistant as well.
