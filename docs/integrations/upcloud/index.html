Using UpCloud

Overview

The UpCloud integration allows you to access the information about your UpCloud servers from Home Assistant.

Setup

Set up your API user credentials in your UpCloud control panel.

Binary sensor

A binary sensor entity is set up for all discovered servers.

Switch

A switch entity is set up for all discovered servers. You can use the switch to control (start/stop) them.
