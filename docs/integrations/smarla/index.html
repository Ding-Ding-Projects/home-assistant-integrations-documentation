Using Swing2Sleep Smarla

Overview

The Swing2Sleep Smarla integration enables Home Assistant to integrate Swing2Sleep (Smarla) motorized cradles. This integration will allow you to control your Smarla device.

Registration

1. Follow the instructions in the Swing2Sleep app. 2. Connect the device to your Wi-Fi network. 3. Follow the steps for Configuration until the access token field appears 4. In the Swing2Sleep app, generate an access token under Settings. 5. Copy the access token and continue with the Configuration.

Provided entities

The Swing2Sleep Smarla integration provides one switch entity for each configured Smarla device as its main feature, allowing you to toggle the cradle's oscillation. The firmware of each device can be monitored and updated through an update entity available on the device page.

Removing the integration

This integration follows standard integration removal.
