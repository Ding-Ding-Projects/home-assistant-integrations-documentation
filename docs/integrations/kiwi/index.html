Using KIWI

Overview

The KIWI integration allows you to open your KIWI Smart Locks and Smart Entry Devices. All you need to get started is a KIWI account. Register at the KIWI website.

Configuration

To enable the KIWI integration, add it to your configuration.yaml file.
