    Using AI Task

    Overview

    The AI Task integration lets your automations, scripts, and the Home Assistant interface use AI for a single job. For example, to describe what a camera sees, to generate an image, or to decide whether a delivery driver is at the door.

    Ways to use AI tasks

    You can use AI tasks in the following ways:

    AI tasks, AI tools, and conversation agents

    AI tasks and AI tools work in opposite directions:

    Choosing the preferred AI task entities

    When an action doesn't name an AI task entity, Home Assistant uses the preferred one. The Suggest button also uses the preferred AI task entity for data generation. You can choose a different one for each kind of task. For example, a fast model to generate text, and another model that can generate images.

    AI task states

    The state of an AI task entity is a timestamp showing the date and time when the AI task was last used. Home Assistant stores the timestamp in UTC, for example, 2026-01-01T12:00:00.123456+00:00. The Home Assistant interface shows it in your local date and time format.

    Automation: thank a delivery driver at the front door

    When someone rings the doorbell, use Evaluate to check a camera snapshot for a delivery driver. If the estimated probability is at least 90%, use Speak to play a thank-you message through the doorbell speaker.

    Template sensor: count chickens in the coop

    This template sensor uses Generate data to count the chickens in a camera snapshot of your coop. It updates when Home Assistant starts and every 5 minutes. It uses your preferred AI task entity for data generation.

    Script: create a weather and indoor comfort report

    This script uses Generate data with a structure. The AI task returns two separate fields: a funny description of the weather and an assessment of the indoor comfort. The script then shows both fields in a notification.

    Automation: notify when the garage door is left open

    When the garage door has been open for 10 minutes, this automation uses Generate data to write a funny reminder. Without a structure, the AI task returns plain text. The automation then shows the text in a notification.

    Template image: show the current weather as a picture

    When the weather changes, and every hour, this automation uses Generate image to create a picture of New York in the current weather. It then fires an event with the image URL. A template image entity reacts to that event and shows the new picture. The example uses your preferred AI task entity for image generation.
