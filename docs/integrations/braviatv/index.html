Using Sony Bravia TV

Overview

The Sony Bravia TV integration allows you to control a Sony Bravia TV from Home Assistant. You can turn the TV on and off, change the volume and the input source, open apps, switch TV channels, and send remote control commands, for example from a dashboard or an automation.

Prerequisites

The integration connects to your TV over your local network. Before you add the integration, allow remote control on the TV and choose how Home Assistant authenticates with it.

Supported functionality

The Sony Bravia TV integration provides the following entities.

Media player

The media player entity shows whether the TV is on or off, the current input source, the volume level, and the TV channel that is currently playing. You can use it to:

Media browser

Using the media browser, you can view a list of all installed applications and TV channels and launch them. You can access the media browser from the Media section in the Home Assistant side menu or by selecting the Browse media button on the media player card.

Opening apps and channels in automations

To open an app or switch to a TV channel from an automation or a script, use the Play specified media action and select your Bravia TV media player as the target.

Remote

The remote entity lets you turn the TV on and off and send remote control commands to it, like pressing the buttons on the TV remote. Use the Send remote command action to send commands.
