Using Radio Browser

Overview

The Radio Browser integration brings the worldwide directory of internet radio stations from Radio Browser into Home Assistant. It adds Radio Browser as a media source, so you can browse thousands of stations and play them on your media players, like a speaker in the kitchen or a Cast device in the living room.

Prerequisites

There is nothing to configure. The Radio Browser integration has no options, and you can add it only once.

Supported functionality

Radio Browser does not add any entities. Instead, it adds a media source you can browse from the media browser and from the Play media action.

Examples

You can also start a station from an automation or script. The easiest way is to create the automation in the UI: add the Play media action, browse the Radio Browser directory, and select a station. The station identifier is filled in for you. This lets you, for example, start your favorite station on the kitchen speaker every morning.

Data updates

Radio Browser does not poll in the background. The station directory is fetched live from the Radio Browser service each time you browse it, so you always see the current listings.

Cannot connect during setup

If you see a "Failed to connect" error during setup, Home Assistant could not reach the Radio Browser service. Check that Home Assistant has a working internet connection, then try again. Radio Browser runs on community servers, so it may be down for a while. If it is, try again later.

A station does not play

The stream of a station can be down, or in a format your media player does not support. Try playing the station on another media player. Many stations are listed more than once, in different formats or qualities, so searching for the station by name may also turn up a version that does play.

The details of a station are wrong

The station data comes from Radio Browser, which has no way to edit a station. Corrections for wrong streams, logos, or names are collected in the python-radios library that this integration uses; see its contributing guide to suggest one.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
