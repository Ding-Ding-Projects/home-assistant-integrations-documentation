Using Cloudflare R2

Overview

The Cloudflare R2 integration allows you to use Cloudflare R2 buckets with Home Assistant Backups.

Prerequisites

This integration requires an existing R2 bucket and admin access to the bucket so you can create a Secret Access Key.
