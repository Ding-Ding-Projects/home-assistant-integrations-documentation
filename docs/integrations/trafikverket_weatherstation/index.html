Using Trafikverket Weather Station

Overview

Showing weather information provided by Trafikverket weather stations in Sweden.

Prerequisites

Please click here and register to obtain the API key.

Reconfiguration

You can change the API key or switch to another weather station without removing the integration.

Weather stations

To get a map of valid weather stations, open the trafikverket website. Once you have found a station, copy its name as shown in the picture below and paste it in the Station field.

Data updates

The integration polling polls the Trafikverket API every 10 minutes.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
