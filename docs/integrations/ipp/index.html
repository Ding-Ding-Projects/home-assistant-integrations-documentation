Using Internet Printing Protocol (IPP)

Overview

The Internet Printing Protocol (IPP) integration allows you to read current data from your networked printer that supports the Internet Printing Protocol.

Sensors

In addition to the printer state and the ink or toner levels, the integration provides the following diagnostic sensors. Home Assistant adds each sensor only if your printer reports the corresponding IPP counter. If your printer does not report these counters, you will not see these sensors.

Data updates

The integration polling polls the printer every 60 seconds to update the printer state, the remaining ink or toner levels, and the page counters.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
