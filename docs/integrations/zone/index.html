    Using Zone

    Overview

    Zones allow you to specify certain regions on a map. They enable zone presence-detection. This information can be used in automations. For example, to start the vacuum after you left home or start the heating at home when you leave the office.

    About the home zone

    During the onboarding process, Home Assistant asked for your home location. You either entered this manually or asked Home Assistant to detect it automatically. This location was used to create the home zone with a 100&nbsp;m radius. The home zone is a special, pre-defined zone with a few characteristics that set it apart from other zones.

    Adding a new zone or editing zones

    If you have configured the zone or some of the general settings in YAML, as described in editing zones in YAML and in editing the general settings in YAML, you cannot edit them using the UI.

    Editing zones in YAML

    Zones can also be configured via configuration.yaml. If you define these settings in YAML, they cannot be edited in the UI. They will appear greyed out.

    State

    The state of a zone is a number, which represents the number of persons that are currently in a zone.

    Supported functionality

    Zones provide triggers, conditions, and actions for automations. You can use them to react when people or tracked devices enter or leave a zone, or to check whether a zone is occupied.
