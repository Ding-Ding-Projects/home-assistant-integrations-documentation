Using Solarman

Overview

The Solarman integration enables direct local communication between Home Assistant and your Solarman devices. This solution provides real-time monitoring of energy production and consumption while enabling device control, all through secure local communication.

Supported devices

Currently, the integration supports the following devices:

Prerequisites

1. Connect your Solarman device and Home Assistant to the same local network. 2. Ensure the Solarman device is powered on and has acquired a network IP address. You can get the IP from the app or from your router. 3. Enable the device's API through the app.

Supported functionality

The Solarman integration mainly provides sensors about what your device is measuring.

Automation: Notify when the voltage exceeds a threshold

When the reading from a Solarman voltage sensor stays above your chosen threshold for 5 minutes, this blueprint creates a persistent notification. After importing the blueprint, select a voltage sensor with a unit of V and set your threshold.

Data updates

The Solarman integration polling polls data from the device every 30 seconds.

Known limitations

The integration does not provide the ability to configure the devices, which can instead be done via the manufacturer's app.
