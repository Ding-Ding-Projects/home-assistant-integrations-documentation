Using ISEO Argo BLE Lock

Overview

The ISEO Argo BLE integration connects Home Assistant to ISEO Argo smart locks over Bluetooth Low Energy. ISEO is an Italian security manufacturer specializing in high-security cylinders and electronic access control, widely used in residential and commercial buildings across Italy and Switzerland.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
