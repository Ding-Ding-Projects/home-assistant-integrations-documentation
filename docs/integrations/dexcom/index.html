Using Dexcom

Overview

The Dexcom integration allows you to view your CGM data from Dexcom in Home Assistant.

Prerequisites

You will need to set up the Dexcom Share feature in your Dexcom G6 or G7 app to use this integration. Enabling the Dexcom Share service requires setup of at least one follower. The integration will use the Dexcom user's credentials, not the follower's credentials. If you want to access a dependent's data, use the dependent's own credentials. Home Assistant cannot select a dependent profile when you sign in with a parent or manager account.
