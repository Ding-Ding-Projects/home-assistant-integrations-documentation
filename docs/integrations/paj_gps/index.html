Using PAJ GPS

Overview

It provides entities for tracking the location of your PAJ GPS devices, monitoring their speed, and checking the battery level of battery-powered devices.

Supported functionality

The PAJ GPS integration provides the following entities.

Device tracker

The PAJ GPS integration will track the location of each device registered to your account. The integration provides real-time GPS coordinates (latitude and longitude) for your PAJ GPS devices.
