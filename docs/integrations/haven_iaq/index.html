Using HAVEN IAQ

Overview

The HAVEN IAQ integration connects supported HAVEN IAQ air quality monitors to Home Assistant over your local network. Depending on the device, the integration provides indoor air quality and airflow measurements.

The integration supports the following HAVEN IAQ products:

Prerequisites

Home Assistant discovers compatible devices automatically. If a device is not discovered, you can add it manually by entering its hostname or IP address.

Supported functionality

Data updates

This integration uses local polling. Home Assistant requests updated data from the device once per minute.

The device is not discovered

1. Confirm that Home Assistant and the HAVEN IAQ device are connected to the same local network. 2. Confirm that Home Assistant is enabled for the device in the HAVEN app. 3. Confirm that the device runs a supported firmware version. 4. Add the integration manually and enter the device's hostname or IP address.

Entities are unavailable

1. Confirm that the HAVEN IAQ device is powered on and connected to Wi-Fi. 2. Confirm that Home Assistant remains enabled for the device in the HAVEN app. 3. Confirm that Home Assistant can still reach the device at its configured hostname or IP address. 4. If a manually entered IP address changed and the device is not rediscovered automatically, remove and add the integration again using the new address.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
