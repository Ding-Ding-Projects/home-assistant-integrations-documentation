    Using Illuminance

    Overview

    This integration provides automation triggers and conditions for binary sensors with device class light and for sensor and number entities with device class illuminance. There are no configuration options for this integration.

    Illuminance and brightness

    A common pattern is to combine them: use an Illuminance crossed threshold trigger to react when ambient light drops, then use the Light integration's Turn on light action to set the lamps to the brightness level you want.
