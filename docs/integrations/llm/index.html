    Using LLM

    Overview

    The AI tools are grouped into sets. You choose which sets each conversation agent can use, in its AI tools option. AI apps outside Home Assistant can use the same sets through the Model Context Protocol integration.

    Sets of AI tools

    Each set contains related AI tools. Home Assistant has two built-in sets:

    What the Home Assistant AI tools can reach

    The Home Assistant AI tools can read the state of every entity, the status of your integrations, your logs, and the history of your sensors. For the full list, refer to List of Home Assistant AI tools.

    Who can use the Home Assistant AI tools

    Only administrators can use the Home Assistant AI tools. Home Assistant checks the user account that each request comes from. When you talk to a conversation agent in Assist in Home Assistant or in the Home Assistant Companion app, the request comes from the user account that is signed in.

    Adding the Home Assistant AI tools to your conversation agent

    Use this procedure if only administrators use your conversation agent. Afterwards, you can ask it why an integration isn't working, or which errors are in the logs. The conversation agent then no longer works for voice satellites or for users who aren't administrators. For details, refer to Who can use the Home Assistant AI tools.

    Setting up a separate assistant for the Home Assistant AI tools

    Use this procedure if voice satellites or users who aren't administrators use your assistant. Your current assistant stays as it is for them. You get a second assistant that you can ask why an integration isn't working. For details, refer to Who can use the Home Assistant AI tools.

    List of Home Assistant AI tools

    You don't call these tools yourself. When you ask the conversation agent something, it decides which tools to call. You can't select single tools. You give the conversation agent the entire set, as described in Adding the Home Assistant AI tools to your conversation agent.
