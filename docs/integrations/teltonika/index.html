Using Teltonika

Overview

The Teltonika integration integrates Teltonika Networks routers with Home Assistant, allowing you to monitor cellular signal quality, modem temperature, and network connectivity.

Supported devices

Most Teltonika routers running RutOS are supported, including:

Prerequisites

To improve security, create a dedicated user and user group in RutOS for Home Assistant instead of using an account with broad access. The group needs read permissions for device, system, and modem information. If some sensors are missing, check the group's read permissions in RutOS.

Automatic discovery

Teltonika routers are automatically discovered via DHCP.

Data updates

Data is polled from the router every 30 seconds.

Connection issues

Verify the router is reachable on your network and the web interface is accessible. Check that you're using the correct IP address and credentials.
