Using IRM KMI Weather Belgium

Overview

The Royal Meteorological Institute of Belgium integration integrates the weather data from IRM KMI (meteo.be) with Home Assistant.

Supported features

The integration provides a weather entity along with weather forecast services.

Limitations

2. The trends for 14 days are not shown.

Data updates

The integration polling polls weather data every 7 minutes by default.

Removing the integration

This integration follows standard integration removal.
