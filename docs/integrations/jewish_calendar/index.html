    Overview

    Calendars

    The Jewish Calendar integration provides three calendar entities, each focusing on a different type of Jewish calendar event. You can customize which event types are displayed in each calendar through the integration's configuration options.

    The daily events calendar shows time-based events that occur every day, such as the Hebrew date and halachic prayer times. The following event types can be configured:
