Using Xiaomi Home

Overview

The Xiaomi Home integration supports the following devices:

Prerequisites

Most Xiaomi Home devices are configured using the Home Assistant UI. The Xiaomi device tracker and Xiaomi IR Remote require manual YAML configuration.

Symptom: The device is not discovered

Your Xiaomi Home device is not discovered when it is on a different subnet or VLAN from Home Assistant.

Description

Xiaomi Home devices might not communicate across subnets or VLANs.

Resolution

For network requirements and possible solutions, see the python-miio troubleshooting guide.

Symptom: The vacuum is not discovered

Your Roborock vacuum is not discovered by the Xiaomi Home integration.

Symptom: The device is intermittently unavailable

The device periodically stops responding in Home Assistant.

Xiaomi Gateway

The Xiaomi Home integration allows you to control the gateway and its connected subdevices.

Retrieving connected subdevices through Xiaomi Home

Some gateways, such as lumi.gateway.mieu01, cannot retrieve connected subdevices locally. To add their subdevices, use the Xiaomi Home service.
