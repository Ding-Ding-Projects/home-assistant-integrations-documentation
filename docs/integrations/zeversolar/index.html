Using Zeversolar

Overview

The Zeversolar integration uses the local device IP to get information like the current power and today's total energy production. This integration allows you to collect and save data providing a historical overview of your Zeversolar production.

Prerequisites

You need a Zeversolar inverter connected to your solar panels and Wi-Fi. Furthermore, you need to get the Zeversolar IP address.
