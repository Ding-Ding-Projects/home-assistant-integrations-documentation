Using ThingSpeak

Overview

The ThingSpeak integration makes Home Assistant communicate with the ThingSpeak API. For now, it records exactly one entity at once, which is great for testing purposes. For long-time storage you should rely on the InfluxDB integration.

Configuration

You will have to create a new channel on ThingSpeak and grab your Write API Key from the "API Keys" tab of the channel you want to use.
