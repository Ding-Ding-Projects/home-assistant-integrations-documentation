Using Tesla Wall Connector

Overview

The Tesla Wall Connector integration allows you to integrate your Gen 3 Tesla Wall Connector with Wi-Fi into Home Assistant.

Configuration options

Single-phase / Split-phase electrical service:

Supported functionality

The Tesla Wall Connector integration provides sensors and binary sensors that you can show on dashboards, use in automations, and add to the Energy dashboard.

Device information

The device page shows the Wall Connector model, model ID, serial number, and firmware version.

Data updates

The Tesla Wall Connector integration polling polls the device every 30 seconds.

Energy dashboard

Energy usage can be added to the built-in Energy dashboard using the Lifetime energy sensor.
