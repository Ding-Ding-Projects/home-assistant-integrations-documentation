Using Ukraine Alarm

Overview

The Ukraine Alarm integration uses the siren.pp.ua API, a public wrapper for the Ukraine Alarm web service, to provide air-raid siren notifications. The integration creates 8 binary sensors for your selected region in Ukraine:

Air alert levels

The service reports a danger level for air alerts, where red is the more severe level and yellow the less severe one:

Limitations

You can monitor up to 5 regions to not hit the API rate limit.
