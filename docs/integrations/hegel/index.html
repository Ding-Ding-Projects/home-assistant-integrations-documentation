Using Hegel Amplifier

Overview

The Hegel integration allows you to control your Hegel Music Systems amplifiers from Home Assistant. It uses Hegel's official IP control protocol over TCP and supports real-time push updates for a responsive experience.

Static IP recommendation

For best reliability, configure your Hegel amplifier with a static IP address or DHCP reservation to prevent connection issues if the IP address changes.

Setup issues

1. Verify the amplifier is powered on and connected to the network 2. Check that UPnP/SSDP is enabled on your router 3. Ensure Home Assistant and the amplifier are on the same network segment 4. Try manual setup using the amplifier's IP address

Connection problems

1. Check network stability between Home Assistant and amplifier 2. Verify the amplifier has a static IP or DHCP reservation 3. Check router logs for connection drops 4. Consider network infrastructure issues (Wi-Fi range, switch problems)

Control issues

1. Ensure you selected the correct Hegel model during setup 2. Different models have different available inputs 3. You can reconfigure the integration to change the model 4. Entity names can be customized in Home Assistant's device settings
