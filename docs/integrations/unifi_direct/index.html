Using UniFi AP

Overview

This integration allows you to detect presence by looking at devices connected to a UniFi AP. This device tracker differs from Ubiquiti UniFi because it doesn't require the UniFi Network application.

Supported functionality

The integration creates a device tracker entity for each device known to your UniFi AP. You can use these entities to track the presence of people in your home. For more information on how to assign tracked devices to people, see the device tracker integration page.

Data updates

Home Assistant polling polls your UniFi AP every 30 seconds to retrieve the list of connected devices and update their connection status.
