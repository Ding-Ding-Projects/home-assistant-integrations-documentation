Using Foreca

Overview

The Foreca integration uses the Foreca Weather API to provide weather forecasts for any location worldwide. Foreca is an independent weather company that has produced forecasts for consumer and business services since 1996.

Prerequisites

You need a Foreca Weather API key, from either subscription.

Weather

The integration creates one weather entity per location, providing the current conditions, a daily forecast for the next 10 days, and an hourly forecast for the next 48 hours.

Data updates

The integration polling polls the Foreca Weather API every 30 minutes. Each update uses three requests per location, around 144 requests per day for one location, which stays well inside the Freemium plan's daily limit of 2,000 requests. Every location you add polls separately, so that limit allows around 13 of them. Because the integration polls continuously, a Freemium key used this way does not go idle.

Description

The integration marks entities unavailable when the API cannot be reached or the daily request limit is exceeded.

Resolution

Check your remaining requests on the My API page.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
