    Using Keyboard Remote

    Overview

    The Keyboard Remote integration lets you use a USB or Bluetooth keyboard, remote control, or any Linux evdev-compatible input device to trigger automations in Home Assistant. Instead of creating entities, the integration fires events whenever a key is pressed, released, or held down. You can listen for these events in your automations to control lights, media players, or anything else in your smart home.

    Events

    The integration does not create any entities. Instead, it fires events on the Home Assistant event bus that you can use as triggers in your automations.

    Keyboard remote command received

    The keyboard_remote_command_received event is fired whenever a key event occurs that matches your configured event types.

    Keyboard remote connected

    The keyboard_remote_connected event is fired when a configured device is detected or reconnected. This is useful for Bluetooth devices that turn off automatically to save battery.

    Keyboard remote disconnected

    The keyboard_remote_disconnected event is fired when a configured device is disconnected or removed.

    Migrating from YAML configuration

    YAML configuration for the Keyboard Remote integration is deprecated and will be removed in Home Assistant 2027.4.0. When you upgrade, your existing YAML configuration is automatically imported as one integration entry per device. Please remove the keyboard_remote key from your configuration.yaml after confirming the import was successful.
