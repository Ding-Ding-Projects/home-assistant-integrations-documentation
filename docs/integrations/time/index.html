    Using Time

    Overview

    The Time integration is built for controlling and monitoring times on devices.

    Time states

    The state of a time entity is a time, stored in the format HH:MM:SS, for example, 07:30:00. If the time includes fractions of a second, they follow the seconds, for example, 07:30:00.500000. The Home Assistant interface shows the time in your local time format.
