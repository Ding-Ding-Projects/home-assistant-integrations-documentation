Using Fuelprices.dk

Overview

The Fuelprices.dk integration uses the Fuelprices.dk API as a source for fuel price data from Danish fuel companies.

Companies currently supported

To view a list of currently supported companies, refer to Fuelprices.dk Companies.

Prerequisites

To set up the integration, you need a valid Fuelprices.dk API key.

Sensors

For each station you add, Home Assistant automatically creates one price sensor for every fuel product Fuelprices.dk reports for that station.

Data updates

The integration polling polls Fuelprices.dk every hour.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
