Prerequisites

You need an API key for the HortOS Automation API. Request one from your Ridder account manager; it is not something you can generate yourself in the HortiMaX Pro interface. The API key and the API are Ridder's; obtaining and using them is separate from installing this integration.

Devices and entities

The integration mirrors the two levels of the HortOS data model:

Data updates

The integration polls the HortOS API once a minute per controller, which matches how often a controller publishes changed readouts. A readout whose value does not change keeps its previous timestamp for up to five minutes.

The integration cannot connect

Check that the API key is still valid and that the HortOS API is reachable from your Home Assistant instance. The API allows 100 requests per 15 seconds per key; if you use the same key elsewhere, the two can interfere.

Where to ask for help

Ridder supports the HortOS Automation API, not this integration. Take questions about the API — including how to obtain an API key or why a controller reports a particular value — to your Ridder account manager.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
