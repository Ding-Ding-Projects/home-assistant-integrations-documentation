    Using Pico TTS

    Overview

    The Pico TTS integration uses Pico TTS library to read out text with natural sounding voices. Pico TTS is a powerful open-source engine that runs locally (cloudless) so it can work even without an internet connection.

    Supported functionality

    The Pico TTS integration provides the following entities.

    Text-to-speech

    The Pico TTS integration adds a text-to-speech entity for your configured language. To convert text to speech, you can use the Text-to-speech (TTS): Speak (tts.speak) action.
