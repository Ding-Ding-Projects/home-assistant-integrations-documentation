Using Energenie Power Sockets

Overview

The Energenie Power-Sockets integration allows you to include Energenie USB Power-Sockets into your Home Assistant setup.

Troubleshooting

If you are running a Home Assistant Container installation: Depending on your system configuration, it may be necessary to grant explicit user access rights to the USB device by creating an udev rule.
