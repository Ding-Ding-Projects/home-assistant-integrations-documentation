Using Epson

Overview

The Epson integration allows you to control a Epson projector from Home Assistant.

Configuration

This integration supports connecting to an Epson projector via LAN or Serial.

LAN connection

Connect the projector to your LAN and enter the IP address of the projector when prompted, selecting either HTTP or TCP depending on what the projector model supports. The iProjection app by Epson can be used to test if it is working.

Serial connection

Connect projector directly to Home Assistant via a serial cable, or ser2net can be used as a Serial to network proxy.
