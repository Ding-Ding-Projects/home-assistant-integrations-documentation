    Using Speech-to-text (STT)

    Overview

    A speech-to-text (STT) entity allows other integrations or applications to stream speech data to the STT API and get text back.

    Speech-to-text states

    The state of a speech-to-text entity is a timestamp showing the date and time when the entity was last used to process speech. Home Assistant stores the timestamp in UTC, for example, 2026-01-01T12:00:00.123456+00:00. The Home Assistant interface shows it in your local date and time format.
