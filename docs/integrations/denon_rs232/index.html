Using Denon RS-232

Overview

The Denon RS-232 integration lets you control Denon receivers by connecting to their RS-232 serial port. Because Home Assistant talks straight to the receiver, you get local control with push-based state updates.

Supported functionality

The integration adds media player entities as an entity for your receiver.

Media player controls

For supported receivers, you can use Home Assistant to:

Zones

If your receiver supports additional zones, Home Assistant adds separate media player entities for those zones.

Source selection

The available input sources depend on the receiver model you select during setup.

Selecting tuner presets and frequencies

On the main zone, you can tune the receiver to a stored tuner preset or directly to an FM frequency. This works from the media browser, which lists the tuner presets, or by calling the media_player.play_media action with a media_content_type of channel.
