    Using Assist pipeline

    Overview

    The Assist pipeline integration provides the foundation for the Assist voice assistant in Home Assistant.

    Debug recordings

    If Assist doesn't understand you or doesn't react to the wake word, you can save the audio of your voice commands and listen to what Home Assistant received.

    Recording voice commands for debugging

    1. In your configuration.yaml file, add debug_recording_dir under assist_pipeline:

    Turning off debug recording

    1. In your configuration.yaml file, remove the debug_recording_dir line. 2. Restart Home Assistant. 3. Delete the folder with the recordings.
