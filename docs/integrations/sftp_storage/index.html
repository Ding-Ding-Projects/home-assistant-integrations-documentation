Using SFTP Storage

Overview

The SFTP Storage integration works with the core Backup integration. When you enable SFTP Storage in the Locations section of your Backup integration settings, Home Assistant automatically stores manual and automatic backups on your remote SSH/SFTP server.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
