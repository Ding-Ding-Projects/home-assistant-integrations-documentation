Using Knocki

Overview

The Knocki integration allows you to trigger your favorite automations simply by tapping custom patterns (such as triple taps) on ordinary surfaces.

Prerequisites

1. Open the Knocki Mobile App. It’s a free download on iOS and Android. 2. Using the app, log-in or create a new Knocki account. 3. From the app’s home screen, select a Knocki or add a Knocki. 4. On the app’s device screen, select a gesture or add a gesture. 5. Next, select the add a task option. 6. Scroll down the task menu and select Home Assistant. 7. Follow the in-app instructions to add the Home Assistant task.

Automation example

4. Select Add action and choose whatever action(s) you’d like the automation to trigger. 5. Finally, test the action by tapping the associated gesture pattern.

Data updates

The integration keeps a WebSocket connection to the Knocki cloud, so knocks reach Home Assistant as they happen. It reads your triggers when it starts, and updates the list when you add or delete a trigger in the Knocki app.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
