Using Bluetooth LE Tracker

Overview

This integration discovers new devices on boot and in regular intervals and tracks Bluetooth low-energy devices periodically based on interval_seconds value. It is not required to pair the devices with each other.

Setup

This integration requires the Bluetooth integration to be enabled and functional.
