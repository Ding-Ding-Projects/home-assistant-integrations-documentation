Using Edifier Infrared

Overview

The Edifier Infrared integration lets you control an Edifier speaker using any infrared transmitter previously configured in Home Assistant.

Prerequisites

For example, you can use an ESPHome device with an IR LED pointed at your Edifier speaker.
