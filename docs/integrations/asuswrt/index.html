Using ASUSWRT

Overview

The ASUSWRT integration can connect Home Assistant to a ASUS router that runs on ASUSWRT firmware.

Padavan custom firmware (The rt-n56u project)

The rt-n56u project does not store dnsmasq.leases in /var/lib/misc/, where asuswrt stores the file used to track connected devices. However, this integration can still be used with the rt-n56u project by setting the dnsmasq option to /tmp.
