Using OpenAI

Overview

The OpenAI integration adds conversation agents, AI tasks, speech-to-text, and text-to-speech powered by OpenAI to Home Assistant.

Prerequisites

This integration works only with the official OpenAI API endpoint and does not support OpenAI-API-compatible third-party services, proxies, or alternative backends. If you need support for other providers, consider using the OpenRouter integration as an alternative.

Talking to Super Mario over the phone

You can use the OpenAI integration to talk to Super Mario and, if desired, have it control devices in your home.

Description

OpenAI rejected the API key when Home Assistant started the integration. For example, this happens when the key was deleted in the OpenAI portal.

Resolution

1. In the OpenAI organization settings, select Verify Organization, and follow the steps. 2. Wait up to 15 minutes. It can take that long until OpenAI gives you access to the model. 3. Talk to the conversation agent again, or run the AI task again.

Removing the integration

This integration follows standard integration removal. No extra steps are required.
