Using VLC media player via Telnet

Overview

The VLC media player via Telnet integration allows you to control a VLC media player using the built in telnet interface.

Actions

When using the media_player.play_media action, only the "music" media type is supported for now.

VLC app for Home Assistant

You can run a VLC Media Player on your Home Assistant installation using the official VLC app. Using it you can play files on the local network, Internet or files and playlist locally saved to the /share and /media folder of your Home Assistant installation.
