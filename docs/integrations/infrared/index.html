    Using Infrared

    Overview

    The Infrared integration allows you to use Home Assistant to send commands to infrared-controlled devices, or to receive signals from infrared remotes. The integration acts as an abstraction layer between the following components:

    Infrared states

    An infrared entity has no on or off state. Its state is a timestamp showing when the entity was last active:

    Device class

    The device class tells Home Assistant whether an infrared entity is an emitter or a receiver. Home Assistant uses the device class to choose the icon and the default name, and to show the type of each adapter in the list of infrared remote adapters.

    List of available device classes

    Each item shows the name you see in the Home Assistant interface, followed by the device class as Home Assistant stores it.

    Troubleshooting

    For problems with infrared control, such as a device that does not respond to commands, refer to Troubleshooting infrared control.
